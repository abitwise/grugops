----------------------------------------------------------------------------------------
CLASS A / SC1 — path-form command modifier escapes the raw-token prefix-skip
----------------------------------------------------------------------------------------
Root cause: isCommandPrefix(value) (admission-guard.ts:367) tests the RAW token, and the
prefix-skip loop (isAdmitInvocation :437) never basenames/de-quotes the MODIFIER tokens —
effectiveCommandWord + stripQuotedRuns are applied only to the FINAL resolved command word
(:445), never to the leading-run modifiers. So a path-form `/usr/bin/env` / `/usr/bin/nice`
is NOT recognized as a command-modifier (its basename `env`/`nice` is), the prefix-skip
stops, and the trailing `node` reads as an argument — the segment resolves to a non-launcher.

[A path /usr/bin/env]            => ALLOW  (bypass live)   /usr/bin/env node scripts/context-io.js admit my-task NOTE
[A path /usr/bin/nice]           => ALLOW  (bypass live)   /usr/bin/nice node scripts/context-io.js admit my-task NOTE
[A path /usr/bin/env -S]         => ALLOW  (bypass live)   /usr/bin/env -S node scripts/context-io.js admit my-task NOTE
[A path /usr/bin/xargs]          => ALLOW  (bypass live)   /usr/bin/xargs node scripts/context-io.js admit my-task NOTE
[A path ./nice]                  => ALLOW  (bypass live)   ./nice node scripts/context-io.js admit my-task NOTE
[A doubled env+nice]             => ALLOW  (bypass live)   /usr/bin/env /usr/bin/nice node scripts/context-io.js admit my-task NOTE

----------------------------------------------------------------------------------------
CLASS B / SC1 — a $( … ) / backtick command word fails OPEN (asymmetric with $X)
----------------------------------------------------------------------------------------
Root cause: `$(` opens a fresh segment at the INNER word (admission-guard.ts:313), exposing
`echo` as the command word, and backticks are unhandled (:355 extends the token). The OUTER
command word the shell forms (`$(echo node)` → `node`) is dynamically produced and never
recognized. `$X …admit` already fails CLOSED (isEnvIndirectedWord) but `$(…) …admit` and
`` `…` …admit `` fail OPEN — the asymmetry this class exploits.

[B $(echo node)]                 => ALLOW  (bypass live)   $(echo node) scripts/context-io.js admit my-task NOTE
[B backtick echo node]           => ALLOW  (bypass live)   `echo node` scripts/context-io.js admit my-task NOTE
[B $(printf node)]               => ALLOW  (bypass live)   $(printf node) scripts/context-io.js admit my-task NOTE
[B $(basename /usr/bin/node)]    => ALLOW  (bypass live)   $(basename /usr/bin/node) scripts/context-io.js admit my-task NOTE

routine admit first then a high-severity admit: the matcher fires, but the classifier reads

runs un-gated through the un-forgeable primary tier.
