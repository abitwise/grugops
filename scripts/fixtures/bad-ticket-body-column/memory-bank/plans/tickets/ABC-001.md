# ABC-001 fixture ticket (a `column:` line in the body, none in the region)

The single mutation in this fixture: the frontmatter region is well formed and
carries NO column key, while the prose body below carries one — and a fenced
block carries a second. A reader bounded to the region answers "this ticket
names no column at all". A line-anchored reader with no region bound answers
with the first key line it meets anywhere in the file, which is the prose one.

column: Phantom Column

```yaml
column: Another Phantom
```

`Phantom Column` is not a heading in plans/board.md, so an unbounded reader
reports the membership error and a region-bounded reader reports nothing. The
region's status is the kebab of `Phantom Column`, so the separate
status-versus-column rule stays silent either way and this fixture isolates
exactly one disagreement.
