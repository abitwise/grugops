# ABC-001 fixture ticket (no frontmatter region at all)

The single mutation in this fixture: the document carries no `---` delimiter
line anywhere, so it has no frontmatter region. Its two key lines sit in plain
prose instead:

column: In Development
status: in-development

Both values are legitimate — `In Development` is a heading in plans/board.md and
`in-development` is its kebab — so a reader that accepts a document with no
region finds nothing to report about it. A reader that requires the region
refuses the document with `no-opening-delimiter` and evaluates neither rule.
