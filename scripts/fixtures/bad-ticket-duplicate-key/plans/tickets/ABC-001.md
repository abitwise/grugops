# ABC-001 fixture ticket (the column key written twice)

The single mutation in this fixture: the frontmatter region carries the column
key twice, with a different value each time, so the document expresses two
values for one key. A reader that takes the first match silently reports
`In Development` and says nothing about the second line. A reader that refuses a
document expressing two values for one key refuses this one with
`duplicate-key`.
