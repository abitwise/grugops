## The fix that was available and was refused

Four weakenings would each have cleared all 38 findings without a single row being written. The
gate's own remedy text names them, and so does `README.md:112-115`:

1. **narrowing the watched corpus** — this file would simply stop being watched, and every future
   rewrite of the kit's own quality gate would be admitted without being looked at;
2. **adding an override tier** — a per-file hatch, which would then require auditing every change
   already admitted under the strict rule to find which ones would have taken it;
3. **moving the recorded base commit forward** — the finding disappears because the evidence for it
   is no longer in the comparison; `00-base.md`'s own body says outright that moving this SHA is not
   a remedy for a red gate;
4. **loosening the clause comparison** — the clauses stop being derived at the granularity that found
   them, which clears these 38 and every future one of the same shape.

**None was taken.** `git diff --exit-code -- docs/audit/29-style-dispositions/00-base.md
agent-factory/` exits 0 across this plan: the base document is untouched and not one byte of any
watched document was edited to reach this result. The only file this plan adds to the repository's
prose is this one.
