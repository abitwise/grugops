# Plan 31-18 style dispositions (CR-11 / WR-17 / WR-18)

Every clause plan `31-18` changes in the watched corpus is recorded here, one row per clause, per the
contract in this directory's `README.md`. `scripts/check-diff-disposition.js` reads this directory on
every run and refuses any changed clause that has no row.

## Why this file changed

Plan `31-18` closes `CR-11`, `WR-17` and `WR-18` from `31-REVIEW.md`, all three reproduced live
against the committed `.js` in `31-VERIFICATION.md` round 4. All three change what
`agent-factory/workflows/18-context-compaction.md` step 4 prescribes, so the prose is a live defect
rather than a documentation lag — an agent following the file as written would name an ordinary
directory as an origin, carry a `human:NAME` stamp into a repository whose dial gates nothing, and
have no way to know that promoting onto an occupied id used to destroy the note already there.

- **Step 4** described the re-binding route as proving the origin note live and byte-identical. It now
  also states which origins the route accepts, that the destination's dial decides whether a human
  disposition means anything there, and that neither route ever replaces a note.
- **`## Stop conditions`** gained one condition per new refusal family, each with its legitimate next
  action, because a refusal an agent cannot act on becomes a workaround.
- **`## Trace updates`** claimed compaction leaves the trail unchanged. That was false while a
  promotion could delete a note, and incomplete while a re-binding could land a human-disposed
  finding in a repository whose ledger recorded nothing about it.
- **`## Done condition`** could not be falsified by the defect the round found, so it gained the two
  clauses that can falsify it.

The `§14-gate` stamp is written without its `#<id>` suffix throughout, preserving the spelling choice
`31-09` recorded and `31-14` carried forward: `guard_context_writes` reads the `>` of `<id>` as a
shell redirect when a `.grugops/context/` path shares the line, and the prose moves rather than the
guard.
