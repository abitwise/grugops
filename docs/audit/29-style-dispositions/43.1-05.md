# Phase 43.1 plan 05 style dispositions (the production hard floor's credential precondition, D693)

Plan 43.1-05 closes deferred item D693 in Workflow 12. Its When-to-use paragraph called the git host's production
deployment environment the hard floor with no condition. GitHub documents that an environment's secrets reach only the
jobs that reference the environment, and only after a required reviewer approves
(docs.github.com/en/actions/reference/workflows-and-actions/deployments-and-environments), so the reviewer gates a deploy
only when the deploy credentials are reachable solely through that environment. Decision D-04 of phase 43.1, chosen by
the human on 2026-11-19, states that precondition in every place that names the floor. The hard-floor sentence now says the
environment is the hard floor only when the deploy credentials live solely in its secrets, and a new sentence after it
says that a credential held anywhere else can deploy without that reviewer. Nothing else on the line changed.

**The base commit is `e8d7802ccf8ebf428a47703f6001327325e3aea3`**, read from `00-base.md`. This change
does not move it. `before` is the gate's removed side at that base and `after` is its added side in
the working tree. `—` is an empty side.
