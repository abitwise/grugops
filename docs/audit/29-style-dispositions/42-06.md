# Plan 42-06 style dispositions (design-system files are user artifacts)

Plan 42-06 adds the amended SKILL-04 rule in three places. `agent-factory/roles/designer.md` and `agent-factory/roles/frontend-ui.md`
each gain one `## Hard limits` sentence: design-system files in the user's repo are user artifacts the role reads and never writes.
Step 1 of `agent-factory/workflows/14-ui-design-to-build.md` gains five sentences: read the files, never write them, the files win
over the Designer's notes, align the notes, and record each conflict for the human (D-19, D-23, Phase 40 D-05). The source is
`42-CONTEXT.md`, `42-EVALUATION.md` § Ratification and § Kit decisions (ratify-none, no kit change), and the plan's own target text.

**The base commit is `e8d7802ccf8ebf428a47703f6001327325e3aea3`**, read from `00-base.md`. This plan does not move it. `before` is
the gate's removed side at that base and `after` is its added side in the working tree. `—` is an empty side. An unchanged sentence
on a rewritten line is one row with identical sides, as in `40-20.md`. `line` is the working-tree line.
