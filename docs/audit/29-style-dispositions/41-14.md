16 findings, and each has one row. The sentence the tier 4 line keeps word for word has the same text on both sides, because the
gate compares whole lines. `WF16 names the stop.` drew no finding, and it has a row because this file records every clause the plan
changed.

the diff. The clauses in `## Stop conditions` of Workflow 16 are frozen, so each of those rows also fills its `companion` cell.
