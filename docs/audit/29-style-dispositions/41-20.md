sentences that say which route retires a green verdict or a gated finding, where no route exists, and what a reader does with a

test 7 on 2026-11-11.

is the gate's removed side at that base and `after` is its added side in the working tree. `—` is an empty side.

## How these rows were made

The gate was run as `node scripts/check-diff-disposition.js` with no row in this file, and its output was read from a file. It gave
6 findings, all on line 31 of Workflow 16, and each has one row. No other line of a watched file changed.
`agent-factory/contracts/context-note.md` and `CHANGELOG.md` are not in the watched corpus, so the gate gives no finding for
their new sentences; they say the same thing as rows 1 to 3 in fewer words.

Each row is about what retires a verdict or a gated finding, or about a duplicate verdict, so it reads `pending (named human):`
followed by the agent's comparison. That comparison is advice. The disposition is the named human's, and it stays pending until
the named human reads the row against the diff. No clause sits in a frozen section: line 31 is in step 3, not in
`## Stop conditions` or `## Commit`. So every `companion` cell is `—`.

The S4 message in `admit()` is code, not a watched clause, so it has no row here. It now ends `the evidence is refused and
nothing is written. Run the gate again: the new run mints a new id, and evidence names that run.` Row 6 is the same route, and
the human check of this plan reads that message beside the rows.
