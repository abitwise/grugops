`tools/grugops/test-skip-integrity.js`, a name Node's default `node --test` glob `**/test-*.js` matches, so a
host's own plain `node --test` ran it and failed. The installed name is now `tools/grugops/skip-integrity.js`
(the phase context locks the D66 rename and leaves the exact name to Claude's discretion). Workflow 05's
test-integrity step names the program that is installed; nothing else in the step changed.

does not move it. `before` is the gate's removed side at that base and `after` is its added side in
the working tree. `—` is an empty side.
