## How these rows were made

The gate was run as `node scripts/check-diff-disposition.js` with no row in this file, and its output was read from a file. A
temporary script outside the repository took each finding, asked `changedClauses` which sides carry the clause, and read the raw
fragment from the base or the working tree. The gate compares whole lines, so a sentence that stayed word for word on an edited
line also owes a row: its `before` and `after` are the same text. A reworded sentence takes two rows, one per side.

The gate proves that each changed clause has a row. It does not prove that a disposition is right: a named human reads these
rows against the diff.
