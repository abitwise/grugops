## A measurement this file must not overstate

`scripts/check-diff-disposition.js` **does not report a verdict over this recipe today.** Its watched
corpus is the 40-file LANG-03 safety-surface union — 36 derived kit files (17 roles + 19 workflows),
3 registry-arm residue entries and 1 uncounted register row — and
`agent-factory/checklists/browser-uat-recipe.md` is in none of those four parts. Measured, not
assumed: the eight clauses below were added to the recipe and the gate's finding count stayed at
**80 findings over 39 elements**, the same number `31-31` recorded, with no finding naming this file.

So this file is a **record**, not a companion edit the gate demanded. It is written anyway, for the
reason the directory exists: a clause added to a published boundary belongs beside its disposition
whether or not a gate is watching that file this week. Claiming the gate accepted it would be the
fabricated-green this phase exists to prevent.

## Why the recipe changed

`WR-35` of `31-REVIEW.md` names `SKIPPED_DIRECTORIES` as the walk's input boundary for **every host
repository** the installer materializes the runnable into at `tools/grugops/uat-spec-integrity.js`.
Neither floor in `reportMeasured` can see a directory that set removes, because `expected` and
`visited` shrink together.

**Measured before the edit, not asserted.** Six probe repositories were driven against the committed
`.js` at the round-7 base — one with nothing hidden, and five with a uat spec hidden under one
boundary member each:

```
[none]         EXIT=0  stdout=58B  stderr=0B
[.temp]        EXIT=0  stdout=58B  stderr=0B
[node_modules] EXIT=0  stdout=58B  stderr=0B
[.git]         EXIT=0  stdout=58B  stderr=0B
[dist]         EXIT=0  stdout=58B  stderr=0B
[tools]        EXIT=0  stdout=58B  stderr=0B
```

No reader can tell the six runs apart. The indistinguishability is the finding.

`D-33 (5)` disposes it as **disclosure, never a revert**: `.temp` was put in the set by `D-30`
sub-decision 3 in a named human's own words, and the runnable now emits one line on stderr naming
each skipped directory and its hit count. The recipe publishes that boundary because this phase's
rule is that a claim and its mechanism are written down together.

**Sentence length.** The added sentences are short because the Phase 29 writing profile bounds a
procedural sentence at 20 words. `npm run check:imperative-lexicon` is green over the edited
section: `0 findings over 19/19` steps elements and `0 findings over 48/48` sentence-form elements.
