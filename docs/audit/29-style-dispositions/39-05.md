# Plan 39-05 style dispositions (TIER-01; the Tech Lead role)

Plan 39-05 adds one watched document, `agent-factory/roles/tech-lead.md`. It enters the LANG-03 watched
corpus by existing: its Table A row in `docs/audit/28-disposition-register.md` carries
`safety_surface: yes`, and `npm run generate:safety-surface` added it to
`docs/audit/28-safety-surface-exclusions.md` in the same commit. Every clause in it is new, so every
row below is an **added** row with an empty `before` cell.

The role body is drafted in plain English (Phase 39 boundary). The caveman fence stays, as it does in
every role until the Phase 40 flip. The config line, the orientation read and the three footer
pointers are copied verbatim from `agent-factory/roles/architect-design.md`.

The role's `## Hard limits` section is new, so no earlier safety text is reworded. The frozen-set
contract still applies to it: each of its clauses carries a `companion` cell naming the section and
the reason. Because the section runs to the end of the file, the three footer pointers fall inside it
and carry the same companion cell.

One wording choice in that section is driven by the gate, and it is recorded here so a later reader
does not "fix" it back. The frozen set is keyed by normalized clause, kit-wide. A first draft ended
`## Hard limits` with `Humans hold merge and deploy.`, which froze that clause, and it made six
already-dispositioned edits of the same clause in workflows 04, 14 and 15 read FROZEN without a
companion. The sentence now reads `Merge and deploy stay with humans.`: the same rule, stated as a clause
the kit does not already carry.

`agent-factory/checklists/complexity-rubric.md` is new in this plan too. It is not in the watched
corpus (it is a checklist, not a role or workflow), so it owes no row here; the lexicon gate governs
it instead.

**The base commit is `4d2b8f079cc43d7d6184729966492789fb4dc05e`**, read from `00-base.md`. It is not
moved by this plan. The gate reported 767 findings with the new file and no rows, and 721 (the
pre-phase count) once these rows were written.
