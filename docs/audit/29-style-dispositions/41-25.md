# Plan 41-25 style dispositions (a host with only a scripted install has no gate stamp, and a plugin install counts as a host)

Plan 41-25 scopes the missing gate stamp in Workflows 05, 16 and 17 to a host repository with only a scripted install. It also
says that a Claude Code plugin install counts as a host and carries `scripts/context-io.js` and its `emit-verdict` verb, so a
gate stamp there is no proof that a gate ran. The threat is T-41-100 of
`.planning/phases/41-orchestrator-flow-guidance/41-SECURITY.md`, and the decision behind the host text is D-41 of phase 41. The
ruling on T-41-100 of 2026-11-12 chose option (a) at the execute-phase security gate: a plugin install counts as a host, and the
text says so. That ruling was a menu selection without a typed name. Task 3 of plan 41-25 asks a named human to accept the
plugin-install limit by name, and no row here records that acceptance.

**The base commit is `e8d7802ccf8ebf428a47703f6001327325e3aea3`**, read from `00-base.md`. This plan does not move it. `before`
is the gate's removed side at that base and `after` is its added side in the working tree. `—` is an empty side.

## How these rows were made

The gate was run as `node scripts/check-diff-disposition.js` with no row in this file, and its output was read from a file. It gave
20 findings, all on the added side: 6 on line 53 of Workflow 05 (Task 1), 8 on line 31 of Workflow 16, 2 on its line 37, 1 on its
line 41 and 3 on line 62 of Workflow 17 (Task 2). Each has one row. The sentences plan 41-25 replaced were written by plan 41-23
after the base, so the gate gives no removed-side finding for them; their earlier rows stay in `41-23.md`. `CHANGELOG.md` and
`docs/audit/41-residuals.md` are not in the watched corpus, so the gate gives no finding for them.

`node scripts/check-imperative-lexicon.js` gave no finding on the new text, so no sentence was split for WP-02 or WP-03. One
sentence differs from the plan's text. The plan wrote "A Claude Code plugin install counts as a host too" for step 6 of
Workflow 17. A pin of plan 41-04 (RUN-04) holds that Workflow 17 names a host only in its Platform section and its operator tips,
so step 6 says "A plugin install counts as a host too". grugops ships its plugin for Claude Code only
(`.claude-plugin/marketplace.json`), so the sentence names the same install form.

Each row was written as `pending (named human):` followed by the agent's comparison with the code or a test. That comparison is
advice. The disposition is the named human's, and it stayed pending until the named human read the row against the diff. Olger
ruled the rows in 41-UAT.md test 14 (2026-11-14); each row's prefix records the ruling. Every changed line sits in `## Steps`, not
in `## Stop conditions` or `## Commit`, so each `companion` cell is `—`.
