# Plan 43-11 style dispositions (README.md becomes the short front door)

Plan 43-11 rewrites README.md as the short front door. It opens with the header art, the tagline and a
plain story; it retires the old tagline (C-28-002), the `grug-brained` sentence (C-28-003) and the
"Go deep" step (C-28-008); it moves C-28-001 to `docs/concepts.md`; and it drops the Claude Code
start fence, whose content is the start table in `docs/usage.md`. The human decisions are D-01 to
D-06, D-25 and D-26 of phase 43 (`.planning/phases/43-story-and-layered-docs/43-CONTEXT.md`).

**The base commit is `e8d7802ccf8ebf428a47703f6001327325e3aea3`**, read from `00-base.md`. This plan
does not move it. `before` is the gate's removed side at that base and `after` is its added side in
the working tree. `—` is an empty side.

## How these rows were made

When C-28-001 moved, `docs/concepts.md` became a safety-claim home and joined the watched corpus, and
README.md, which no longer holds a safety claim, left it (`docs/audit/28-safety-surface-exclusions.md`).
The README.md rows below were made while README.md was still watched.

The gate was run as `node scripts/check-diff-disposition.js` after each task's edit, with no row for
that edit in this file, and its output was read from a file. Each finding got one row. The `before`
and `after` cells hold the gate's normalized clause, which normalizes to itself.

The gate proves that each changed clause has a row. It does not prove that a disposition is right: a
named human reads these rows against the diff.
