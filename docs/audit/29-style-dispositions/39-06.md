# Plan 39-06 style dispositions (TIER-05; the Designer role)

Plan 39-06 adds one watched document, `agent-factory/roles/designer.md`. It enters the LANG-03 watched
corpus by existing: its Table A row in `docs/audit/28-disposition-register.md` carries
`safety_surface: yes`, and `npm run generate:safety-surface` added it to
`docs/audit/28-safety-surface-exclusions.md` in the same commit. Every clause in it is new, so every
row below is an **added** row with an empty `before` cell.

The role body is drafted in plain English (Phase 39 boundary). The caveman fence stays, as it does in
every role until the Phase 40 flip, and no line of it is copied from `frontend-ui.md`'s fence. The
config line, the orientation read and the three footer pointers are copied verbatim from
`agent-factory/roles/tech-lead.md`.

The role's `## Hard limits` section is new, so no earlier safety text is reworded. The frozen-set
contract still applies to it: each of its clauses carries a `companion` cell naming the section and
the reason. Because the section runs to the end of the file, the three footer pointers fall inside it
and carry the same companion cell.

As in plan 39-05, one wording in that section is chosen for the gate, and it is recorded here so a
later reader does not "fix" it back. The frozen set is keyed by normalized clause, kit-wide, so a
`## Hard limits` clause the kit already carries elsewhere would freeze every dispositioned edit of
that clause in other files. The Designer's last sentence reads `Merge and deploy remain human
decisions.`: the same rule as `Merge and deploy stay with humans.` in `tech-lead.md` and as the kit's
other wordings, stated as a clause no other file carries.

**The base commit is `4d2b8f079cc43d7d6184729966492789fb4dc05e`**, read from `00-base.md`. It is not
moved by this plan. The gate reported 755 findings with the new file and no rows, and 721 (the
pre-phase count) once these rows were written.
