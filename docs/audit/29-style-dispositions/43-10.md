## How these rows were made

The gate was run as `node scripts/check-diff-disposition.js` after each move, with no row for that
move in this file, and its output was read from a file. Each finding got one row; a clause the gate
reports at more than one line (for example `roles load one at time`, once per table row) gets one row,
because a row matches by file and clause. The `before` and `after` cells hold the gate's normalized
clause, which normalizes to itself.

The gate proves that each changed clause has a row. It does not prove that a disposition is right: a
named human reads these rows against the diff.
