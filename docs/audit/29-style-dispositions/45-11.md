# Plan 45-11 style dispositions (TRC-01, BR-02, BR-04, BR-06; build requests in planning, the sweep and session start)

Plan 45-11 wires three workflows to the build-request procedure that plan 45-10 wrote in
`agent-factory/workflows/20-upstream-sources.md` (Workflow 20). Each edit points to Workflow 20 and
restates no rule.

`agent-factory/workflows/03-epic-to-tickets.md` gains two sentences at the end of step 8: cite each
upstream ID a ticket implements as an `upstream:` ref, or state `none (build-internal)` under
`## Upstream`. `## Trace updates` gains one sentence.

`agent-factory/workflows/09-daily-sweep.md` gains a `## Inputs required` bullet for
`upstream.escalation_days`, one sentence in step 7 that skips a bullet naming an open or carried build request, four
sentences in step 9 for the `requests` report, one `## Metrics emitted` sentence, one pointer
sentence in the tagged `escalate_stale_blocker` stop bullet, and one `## Done condition` clause. The
tag keeps its text and its place, and no stop bullet is added, so `WORKFLOW_STOP_BULLET_COUNT` does
not move. The phrase that states the exemption, and the words `per bullet`, stay in Workflow 20
alone.

The Inputs bullet is a new line of its own. It leaves the `.grugops/factory.config.json` bullet
untouched, because that bullet's first clause matches a claim-registry anchor clause, and editing
the line would owe a registry edit for a sentence that did not change. Each other edited line is
read by `git diff` as removed and added again, so every unchanged clause on it has a **kept** row
whose `before` and `after` cells are the same text. The `## Stop conditions`
rows and the `## Done condition` rows carry a `companion` cell naming the section and the reason.

**The base commit is `e8d7802ccf8ebf428a47703f6001327325e3aea3`**, read from `00-base.md`. It is not
moved by this plan. The rows were generated from the gate's own clause segmentation
(`changedClauses`, `readDispositionRows`, `rowMatches` and the `segmentClauses` split), so each
`after` cell is the clause the gate derives. Where a clause rewords an earlier one, the `before`
cell gives the earlier text.
