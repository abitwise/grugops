# Plan 31-19 style dispositions (WR-21)

Every clause plan `31-19` changes in the watched corpus is recorded here, one row per clause, per the
contract in this directory's `README.md`. `scripts/check-diff-disposition.js` reads this directory on
every run and refuses any changed clause that has no row.

## Why this file changed

Plan `31-19` closes `WR-21` of `31-REVIEW.md`, reproduced independently by the round-4 verification.
`31-15` gave `trustedRepoRoot()` a four-step resolution order whose third step walks upward from the
working directory. Its only stop conditions were a configuration found, an ancestor carrying `.git`,
the filesystem root, and 64 ancestors. **None of those is the user's home directory** — while the
function's own docstring said the walk "never continues past" a boundary so a resolution "can never
reach a user's home directory", and `agent-factory/workflows/16-context-read-write.md:32` repeated
the claim to every reader of the protocol.

The prose was a live defect rather than a documentation lag, in the direction that matters most: it
asserted a bound the mechanism did not have. Measured against the committed `scripts/context-io.js`
before any source change, with both project-directory variables removed and a working directory
three levels below a home-directory-shaped ancestor carrying `.grugops/factory.config.json` and no
repository marker anywhere on the path, `trustedRepoRoot()` returned the planted ancestor and read
its `human_admission: "all"`. A second probe drove an admission from the same shape and the GOV-02
event landed in the planted directory's own `.grugops/audit/admissions.jsonl`.

Two sentences therefore had to move, and one section had to arrive:

- **The stop sentence** stated a bound the code did not have. It is replaced by a pointer to the one
  place the stop conditions are now stated, rather than by a corrected restatement — a second
  spelling of the rule in prose is what let the first one drift.
- **The step-3 sentence** named only the nearest-ancestor rule. `31-19` also decided WR-21's second
  half: a repository root's own configuration outranks one nested inside it, so a vendored kit's
  in-repo configuration no longer lowers a host repository's dial for any process whose working
  directory sits under it.
- **`## Where the upward governance-root search stops`** is new. Its six bullets are quoted from
  `TRUSTED_ROOT_STOP_CONDITIONS` in `scripts/context-io.ts`, and `scripts/context-io.test.ts`
  asserts the two set-equal in **both** directions, with a watched-fail control that seeds an extra
  stop on each side and shows the equality break. That assertion is the structural half of the fix:
  correcting a sentence without binding it leaves the next drift unobserved, which is how WR-21 came
  to be documented as impossible. The section is a LEVEL-TWO heading placed after
  `## Stop conditions` rather than a subsection of `## Steps`, because a bullet inside `## Steps` is
  a STEP: the writing profile requires it to open with an approved imperative verb, and a stop
  condition is a statement of fact rather than an instruction to follow.

The section is written in CLEAR voice. The project's voice discipline reserves the caveman register
for text that is not a safety explanation, and where a governance root resolution stops is one.

## What this file does NOT cover

Ten further clauses in `agent-factory/workflows/16-context-read-write.md` are reported by
`check:diff-disposition` and are **not** rows here. They are plan `31-15`'s — the sentences naming
steps 1, 2 and 4, the dial paragraph and the degradation paragraph — which this plan does not
change and cannot state a `before`/`after` for. Writing rows for another plan's clauses would put a
reason in the register this plan cannot vouch for, which is the precedent
`.planning/phases/31-autonomous-manual-testing/deferred-items.md` already records for the same gate.
They are added to that file instead.

Measured counts: `npm run check:diff-disposition` reported **65** findings before this plan (all of
them naming `05-pr-quality-gate.md`, `06-uat-pack.md` or `17-task-claim.md`) and **85** with this
plan's workflow edits in the tree and no rows written. With these 16 rows it reports **75** — the 65
pre-existing plus the 10 inherited `31-15` clauses named above, and **0** owed for the clauses this
plan changed.
