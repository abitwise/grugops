# Plan 31-27 style dispositions (CR-17 / S1 / R-31-19-07 / D-29)

Every clause plan `31-27` changes in the watched corpus is recorded here, one row per clause, per the
contract in this directory's `README.md`. `scripts/check-diff-disposition.js` reads this directory on
every run and refuses any changed clause that has no row.

## Why this file changed

Plan `31-27` closes `CR-17` of `31-REVIEW.md` — the PreToolUse wrapper's own unbounded manifest reads,
independently reproduced by `31-VERIFICATION.md` round 6 at EXIT=124 with zero bytes on both streams —
and lands structural fix `S1`, which adds a HOST-DELIVERED **tier 0** to the governance-root resolution
order and re-scopes `TRUSTED_ROOT_RESIDUALS` by host. Decision **D-29** records both.

`agent-factory/workflows/16-context-read-write.md` is one of the three places that must agree about the
resolution order. Before this plan it published that order only inside step 3's paragraph, as five
sentences a reader had to reconstruct into a precedence. That was already a documentation shape this
project has learned not to trust: `TRUSTED_ROOT_STOP_CONDITIONS` is asserted equal to its prose in both
directions precisely because a restated rule drifts from the rule it restates.

Adding a tier to the program without a published order would have made the drift certain, so this plan
adds a `## The governance-root resolution order` section whose five numbered tier lines are asserted
EQUAL to the exported `TRUSTED_ROOT_TIERS` in both directions — every tier the program publishes appears
in the prose, and every numbered tier line in the prose is one the program has. A sixth tier therefore
cannot arrive in prose alone, and a program tier cannot arrive undocumented.

The section also states what tier 0 does NOT establish, because the closure is host-scoped: the channel
it rests on exists on the Claude Code hook path and on no other host, and it closes nothing about an
agent invoking `scripts/context-io.js` directly from its own Bash tool. A closure claimed globally when
it holds on one host of five is the shape "never fake a passing gate" refuses.

**Scope note.** The rows below cover the clauses this plan ADDED, at lines 50-60. Clauses reported at
lines 22, 32, 64, 66 and 67 are pre-existing prose whose line numbers shifted because this plan inserted
a section above them; they are dispositioned by the plans that wrote them and are not re-claimed here.
