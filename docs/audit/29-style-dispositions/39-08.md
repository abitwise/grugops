# Plan 39-08 style dispositions (TIER-01, TIER-04; the Tech Lead in the ticket flow)

Plan 39-08 edits two watched documents, `agent-factory/workflows/04-ticket-to-pr.md` and
`agent-factory/roles/orchestrator.md`.

- **Workflow 04** gains the Tech Lead step right after the Definition of Ready step, the named
  dispatch step, the board-move sentences and new `## Stop conditions` bullets. The steps after the
  new ones are renumbered; renumbering changes no clause, so it owes no row.
- **The Orchestrator's routing block** now names the Tech Lead and the Designer. The file must not
  grow (it was 7,359 bytes and past its warn tier), so the `Definition of Ready` bullet under the WIP
  gate is removed. That bullet restated workflow 04 step 1, which the Orchestrator still reaches
  through `## Responsibilities` step 6 and its `## Reads` entry for the checklist. Nothing in
  `## Hard limits` changes.

A workflow paragraph is one source line, so when one clause on that line changes, the gate reports
every clause on it. Those unchanged clauses carry a row whose `before` and `after` cells are equal.

`## Stop conditions` is FROZEN by heading. Every row in it carries a `companion` cell that names the
section and the reason.

The routing block uses `Brownfield|Greenfield Mapper`. A pipe would split a table row here, so the
cells write it as `Brownfield/Greenfield Mapper`. Both forms normalize to the same clause.

**Task 2** writes the escalation path into workflow 04: three new steps after the QE and
Security/NFR steps, one board-move sentence and three new `## Stop conditions` bullets. Two of those
bullets carry a checkpoint tag. Each reuses an existing id, so the workflow 05 human stop is met
from workflow 04 and not lowered.

**The base commit is `4d2b8f079cc43d7d6184729966492789fb4dc05e`**, read from `00-base.md`. It is not
moved by this plan. The gate reported 758 findings after the Task 1 edit with no rows, 745 after the
Task 2 edit with only the Task 1 rows, and 721 (the pre-phase count) once all these rows were
written.
