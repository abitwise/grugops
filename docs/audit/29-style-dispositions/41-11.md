## How these rows were made

The gate was run as `node scripts/check-diff-disposition.js` with no row in this file, and its output was read from a file. A
temporary script outside the repository took each finding and read the raw fragment from the base or the working tree. The gate
compares whole lines, so a sentence that stayed word for word on an edited line owes a row too: its `before` and `after` are the
same text. A reworded sentence takes two rows, one per side. The file is regenerated whole after each task, so its line numbers
stay true. A sentence plan 41-04 added and this plan rewrites leaves that plan's row stale, and the base clause, if it has one,
has its row here.

A row for a sentence about the `human:` stamp, admission or a stop reads `pending (named human):` followed by the agent's
comparison. That comparison is advice. The disposition is the named human's, and it stays pending until the named human reads the
row against the diff. `## Stop conditions` and `## Commit` of Workflows 16 and 17 did not change, so they owe no row.
