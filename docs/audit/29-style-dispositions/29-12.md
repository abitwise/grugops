# Plan 29-12 style dispositions

The thirteen shipped seed templates and the two contracts put on the writing profile — the last part
of the governed corpus — and the sixth and final occurrence of vocabulary for a mechanism this
project deleted two milestones ago corrected.

**The judgement is written here; the table below is only its coverage.** A row proves that a changed
clause was considered. It proves nothing about whether the consideration was right — that is a named
human reading these rows against the diff, which is what LANG-03's manual verification is.

## What this plan found, stated before what it did

The seed and contract parts opened at **thirteen findings**, every one `guard_sentence_form`
`bare-demonstrative-subject` (WP-06) — seven in the seed templates and six in the contracts. No other
arm had a single finding in either part: no sentence exceeds its bound, no `and/or` appears, no modal
sits in a procedural step.

`guard_imperative_lexicon` opened at **zero over both parts, and the zero is an EMPTY DENOMINATOR
rather than a clean bill.** **No seed template and neither contract carries a `## Steps` heading**, so
`deriveElements()` derives no bullet from either part and the imperative predicate never runs over
them. Every one of the 139 bullets in the corpus figure is a workflow's. Recorded explicitly, on
29-11's precedent: a predicate reporting zero over zero elements and a predicate reporting zero over
a full denominator are different facts, and only one of them is a verdict.

The honest reading of "zero findings over the full visited denominator" for these two parts is
therefore **zero `guard_sentence_form` findings over 350 seed sentences and 254 contract sentences,
and no imperative denominator at all.**

## The fix that was available thirteen times and refused thirteen times

Every one of the thirteen findings clears instantly by swapping the demonstrative for the pronoun
`it`. `it` is not a member of `DEMONSTRATIVES`, the closed token set the predicate enumerates, so the
swap moves the text **outside the predicate's reach** while leaving the defect WP-06 exists to catch
exactly where it was — a reader still cannot resolve the subject without the previous sentence.

**It was not taken once.** Every correction supplies the head noun the demonstrative was missing, or
re-narrates the sentence onto a named actor. This is 29-11's bar, which refused the same swap four
times; 29-10's, which refused to delete a safety floor to clear a duplication finding; and 29-08's,
which refused to move a period outside a quotation mark to defeat a splitter boundary rule.

**No predicate was widened and no scan set was narrowed.** `git diff -- scripts/ package.json` is
empty for this plan. `GOVERNED_CORPUS_COUNT` is still 47, `TECHNICAL_NAMES` still 76,
`APPROVED_STEP_VERBS` still 43 — no verb was added.

## D-46 — the sixth and last occurrence

Phase 24 deleted the seventeen static relay templates and the shared verified context replaced the
relay. 29-11 corrected four occurrences, recorded a fifth as a named leave-alone, and **named this
one as 29-12's so its six-occurrence arithmetic would close rather than leave a reader wondering
which file it lost.** This is that file.

| field | value |

| after | `\| Ready for Dev \| analysis and design recorded as typed notes per Workflow 16, ticket sized \| Orchestrator \| 6 \|` |
| the deleted artifact | the static handoff packet — the v1.x relay artifact Phase 24 deleted |
| the flow that replaces it | the shared verified context, per `agent-factory/workflows/16-context-read-write.md` |

**Why it survived two audits, structurally rather than accidentally.** `scripts/check-kit-refs.ts`
**deliberately excludes `agent-factory/seed/`** — its own source states the reason: the bundled seed
files are STATE TEMPLATES whose references resolve in the TARGET repo, not against the kit root
(D-03 exclusion). The Phase 28 vocabulary audit covered the roles and the workflows, and this is
neither. And none of `dead-vocabulary.ts`'s three literals matches the bare plural `handoffs`, so no
consumer of that one authority could see it either.

**This matters more than the other five did, because the file is a SHIPPED TEMPLATE.** Every project
bootstrapped from grugops inherited a board whose `Ready for Dev` column could only be entered by
producing an artifact that no longer exists — a gate nobody could pass honestly.

**The replacement was re-narrated, not noun-swapped.** `agent-factory/workflows/03-epic-to-tickets.md`
already reads *"Record the clarified behavior as typed notes per Workflow 16 — the `In Analysis`
exit"*, and `02-idea-to-epics.md` and `00-bootstrap-greenfield.md` use the same
`recorded as typed notes per Workflow 16` spelling. The replacement uses the kit's own existing
vocabulary rather than minting a second spelling for the same flow (WP-09). It is a lowercase noun
phrase in the same form as its twelve neighbouring criteria, and it is 12 words against the 25-word
descriptive bound.

**The vocabulary authority's boundary was obeyed.** `scripts/dead-vocabulary.ts` is byte-unchanged,
no new literal was declared, and no execution-topology text was deleted anywhere — only the
memory-relay half is retired.

## The board template's other change, and what it is not

`board.md:25` carried `… as work moves, e.g. (this is a comment, NOT a live row — …)`. The splitter
treats `e.g.` as a sentence terminator, so `(this is a comment …` became a sentence-initial bare
demonstrative.

Re-wrapping the line so `(this is` no longer sits at a fragment head was available and **refused** —
that is clearing a finding by moving text out of the predicate's reach. The sentence was instead
given the head noun it was missing, in **the kit's own existing spelling for this exact concept**:
`agent-factory/seed/plans/nfr-catalog.md:16` and `agent-factory/seed/plans/traceability.md:12` both
already read `Example row shape (this is a comment, NOT a live table row — …)`. The board now reads
the same way, so no third spelling was minted and the antecedent is inside the sentence, which is
what WP-06 actually asks for.

## Placeholders were left as placeholders

A seed template is mostly headings, placeholder prose and tables an agent later fills. **A
placeholder line is not a procedural step**, and none was improved into an imperative. Scope was
decided by section anchor exactly as the guard decides it, and since no seed file carries a `## Steps`
heading there is no procedural surface in this part at all. Six of the thirteen seed templates are
**byte-unchanged** — `10-project-brief.md`, `20-product.md`, `30-architecture.md`,
`40-contributing.md`, `70-runbook.md` and `80-glossary.md`. Every per-file sentence denominator is
equal before and after, in all thirteen.
