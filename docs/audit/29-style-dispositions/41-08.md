## How these rows were made

The gate was run as `node scripts/check-diff-disposition.js` with no row in this file, and its output was read from a file. Each
finding got one row, and the raw fragment came from the base or the working tree.

Line 1 of the precedence list did not exist at the base, because plan 41-02 added it. Its earlier wording, "never the human stop",
is therefore on no removed side, so the row for line 1 has an empty `before` and names that wording in its comparison. On line 3,
`Dispatch a later revert hand-off on the same ticket without waiting.` stayed word for word, and row 41-02 still matches it, so the
gate raised only the added sentence.

These rows change or sit beside a stop rule, so each reads `pending (named human):` followed by the agent's comparison. That
comparison is advice. The disposition is the named human's, and it stays pending until the named human reads the row against the
diff.

The gate proves that each changed clause has a row. It does not prove that a disposition is right: a named human reads these
rows against the diff.
