# Plan 45-02 style dispositions (ARCH-01, ARCH-02; architecture as input)

Plan 45-02 makes an upstream architecture an input to the build. It changes two watched documents.
`agent-factory/workflows/00-bootstrap-greenfield.md` gains one `## Inputs required` bullet and a new
step 1, in which the Greenfield Mapper applies upstream stack decisions over `default_stack`. Steps
2 to 11 are the old steps 1 to 10, renumbered and kept word for word. `git diff` reads each
renumbered line as removed and added again, so each of those clauses has a **kept** row whose
`before` and `after` cells are the same sentence.
`agent-factory/workflows/20-upstream-sources.md` gains two `## Agents involved` bullets, the new
`## Upstream architecture` section, one `## Stop conditions` bullet and one `## Done condition`
sentence. All of these are new, so their rows are **added** rows with an empty `before` cell.

The new stop bullet sits in a frozen section. Its row, and the row for the sentence "The floor does
not move." (which the stop bullet repeats), carry a `companion` cell naming the section and the
reason. The `## Done condition` row carries one too, as the plan asks. No earlier stop or done text
is reworded.

**The base commit is `e8d7802ccf8ebf428a47703f6001327325e3aea3`**, read from `00-base.md`. It is not
moved by this plan. The gate reported 55 findings with these edits and no rows, all in the two
workflows and 3 of them frozen, and 0 once these rows were written. The rows were generated from the
gate's own clause segmentation (`changedClauses` and `segmentClauses`), so each `after` cell is the
clause the gate derives.
