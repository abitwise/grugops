# Plan 34-30 style dispositions (phase 34 D-26; G-34-2, the documentation of the kit route)

Plan 34-16 (D-20, WR-06) placed a caveat in `README.md` Quickstart step 2 and in `agent-factory/README.md`
after the `C-28-026` note: after a scripted install, whether a host other than Claude Code finds the
kit is `UNKNOWN - verify`. That was true when it was written. Plans 34-27 to 34-29 then built the
marker route the human chose at plan 34-27 Task 1 (D-26):

- `KIT_ROUTE` in `install/host-tools.ts` names the kit root as the `kitRoot` field of
  `.grugops/install.json`, which `writeMarker` in `install/install.ts` writes on every install;
- the kit's `AGENTS.md` "Kit vs state" rule, the `CLAUDE.md` block (`CLAUDE_PTR`), the Copilot
  pointer (`COPILOT_PTR`) and the Pi template (`PI_PROMPT_TEXT`) carry it;
- `install.js --check` follows it (`kitRouteFindings`, `carrierFinding`) and prints one `reach` line
  per `HOST_TOOLS` row.

So the caveat's open question is answered for the files, and only the live host runs remain unknown.
Each corrected sentence now says where the kit is, names the marker field, keeps the live run on a
host other than Claude Code `UNKNOWN - verify` (D-25 point 4: the re-run is the human's UAT item), and
points at the install guide's new section "How a host finds the kit after a scripted install", where
the full statement lives once.
