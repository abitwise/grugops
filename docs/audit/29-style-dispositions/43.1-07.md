## How these rows were made

The gate was run as `npm run check:diff-disposition` after each task's edits, with no new row in this file, and its
output was read from a file. After Task 1 it reported 6 findings: the generated pointer line in `AGENTS.md` and in
`agent-factory/README.md`, each once on its removed side and twice on its added side (the new line has two
sentences). Each file has one row whose `before` and `after` match the old sentence and the first new sentence, and
one row with an empty `before` for the second new sentence. The rows that `docs/audit/29-style-dispositions/30-10.md`
wrote when the pointer was added stay as they are; they record the line as it was added. The other changed lines in
`agent-factory/README.md` are the registered verbatim of C-28-023; their companion edit is the registry change in
the same commit, which rewrites the row's verbatim, `line` and `mechanism`, and the gate admitted them without a row.

The gate proves that each changed clause has a row. It does not prove that a disposition is right: a
named human reads these rows against the diff.
