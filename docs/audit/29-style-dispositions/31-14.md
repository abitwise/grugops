# Plan 31-14 style dispositions (CR-08 / IN-07)

Every clause plan `31-14` changes in the watched corpus is recorded here, one row per clause, per the
contract in this directory's `README.md`. `scripts/check-diff-disposition.js` reads this directory on
every run and refuses any changed clause that has no row.

## Why this file changed

Plan `31-14` closes `CR-08` from `31-REVIEW.md`, reproduced live in `31-VERIFICATION.md` round 3.
`31-09` correctly made `appendNote` consult the admission authority unconditionally. But
`compactor.promote` is a thin pass-through to that writer, and this workflow names it as the only
prescribed promotion route — so a note a named human had already legitimately disposed at the origin
was refused, unchanged, at the destination by the frozen D-04 arm.

The prose is a live defect rather than a documentation lag, and in two directions at once:

- **Step 4** stated one route and one posture. Under D-19 there are two, and which one a promotion
  takes decides whether a human's adjudicated disposition survives the compaction.
- **Step 5** said the unstamped kinds "carry no stamp and pass through". With the authority consulted
  for every kind, an unreadable governance configuration refuses those kinds too (`IN-07`, D-14).
- **Step 6** prescribed honest degradation without scoping it. Read as written, an agent would
  downgrade a faithful promotion of a human-adjudicated security, architecture or release finding to
  an unverified claim on every compaction while the dial is active — in exactly the regulated-team
  posture the governance dial exists to serve.
- **`## Stop conditions`, `## Trace updates` and `## Done condition`** each restated the single-route
  claim, so all four had to move together or the file would disagree with itself.

The `§14-gate` stamp is written without its `#<id>` suffix throughout, preserving the spelling choice
`31-09` recorded: `guard_context_writes` reads the `>` of `<id>` as a shell redirect when a
`.grugops/context/` path shares the line, and the prose moves rather than the guard.
