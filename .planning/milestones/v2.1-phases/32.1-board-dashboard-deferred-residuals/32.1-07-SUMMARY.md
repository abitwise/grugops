## Decisions Made

- **A tagged template, not a helper.** A helper a caller MAY wrap a value in is a discipline to remember at every new sentence; the fix that introduced `visible()` derived its site set over the binding `line`, so the sites it did not name were invisible to the derivation as well as to the author. A tag puts the escaping in the constructor.
- **`TICKET_CONTROL` untouched.** Widening the grammar's admitted class to the C1 block would change which ticket documents are readable at all — DASH-01's decision, deferred by CONTEXT.md. Asserted, not promised: two permanent cases require `TICKET_CONTROL.test(U+0085) === false` with the reason.
- **The census's denominator is bounded by the RECEIVER position.** A blanket rule over all 171 substitutions would pull in the renderer's frame lines, whose substitutions carry ANSI introducers that escaping would corrupt — and those are not sentences a reader adjudicates. Bounding by the measured write position keeps the rule total over the class it is about.
- **A method call's provenance is its receiver.** `line.slice(0, 60)` asked about `slice` answers `lib.es5.d.ts`, which would class a quoted source line as library text — the fail-open direction, and F-14's own shape one register over.
- **The `ticketId` field is not escaped.** It is data a consumer joins on, scrubbed on the way out by `scrub()`/`sanitizeCell`, not a sentence a human reads; D-07 scopes the builder to "every interpolation into a published sentence". Named as a residual (below) rather than closed silently.
