## Decisions Made

See `key-decisions` in the frontmatter. The two worth reading in prose:

**The errno class.** `insideRoot` returns `err.code` straight off a caught `ErrnoException`, so the set of errno spellings it can return is OPEN. An equality over an open set is unwritable, and a containment check ("the contract names a subset") is the one-directional shape that let WR-01 happen. Collapsing every errno to one class token `<errno>` makes the comparison an equality again: the contract names at least one example, and the example stands for the class. `EACCES` and `ELOOP` both map to it, so the contract may name either, both, or a third, and the equality holds.

**The memoised walk.** The first run reported 7 refusal sites against a text-derived 5. The cause was the derivation's own route, not the code: `insideRoot` propagates `anchorAbsentTarget`'s codes, and `anchorAbsentTarget` is also walked directly, so its two sites were counted twice. That is exactly the failure a second derivation exists to catch, and it caught it on the first run.
