## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| repository source → `ts.createSourceFile` / `ts.createProgram` | author-controlled source enters a recursive-descent parser inside the test process | source text (repo-owned) |
| committed `.js` build output → Node ESM loader | committed output executed for real by the loader oracle (bounded child, 60 s, SIGKILL) | module graph |
| `git` subprocess output → test assertions | command output crosses into derivations that decide a pin | paths, porcelain status |
| ticket / context content → published board sentences (model, stderr frame, `--json` document) | content-derived interpolation reaches a terminal or a JSON consumer | ticket ids, titles, paths (may carry control bytes) |
| hook stdin (PreToolUse JSON) → `hooks/guard.js` | agent-issued Bash command evaluated by the mechanical prod-deploy guard | tool_input.command |
| live e2e lane → real `claude` CLI | a human's credential and spend are consumed by a test lane | tokens, wall clock |
| `.planning/WINDOWS.md` / ledger → completion equality | residual register and ledger decide phase closure | counts, dispositions |
