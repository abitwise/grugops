===================================================================================================

The mirror re-runs the whole pipeline — program, type checker, declaration resolution — over one
module served from mutated text at the compiler host's `getSourceFile`. Nothing on disk is touched.
It was generalised over the MODULE it seeds, because it had only ever been watched fail on
`board-model.ts`: a control exercised in one module says nothing about the module where the next
unbuilt sentence will land. The new seed is the `no-at` claim-record sentence, which carries exactly
ONE substitution, so the owned count moves by exactly one.

The seed's UNIQUENESS is now asserted rather than its mere presence. `String.replace` with a string
pattern rewrites the FIRST occurrence, so a seed matching twice would un-own a site chosen by source
order and the count assertions would silently be about a different sentence.
