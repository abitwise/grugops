**One `adapterDestHazard()` predicate, consumed by both `materializeAdapter()` and the `--check` doctor, that refuses a target adapter destination which is a symlink or resolves outside the target — closing CR-01, WR-04, IN-03 and VERIFICATION.md truth 10, with every measured shape re-attacked against the built artifact.**

## Accomplishments

- **The write path now asks what `dest` IS before it reads, compares or writes it.** `materializeAdapter()` previously `writeFileSync`d a destination nothing had bounded; on the ordinary re-run — which D-07 and D-15 made the documented way to deliver a `models` edit — a link at that path carried the write to whatever it pointed at, anywhere on disk, at exit 0.
- **Two arms, one authority.** Arm 1 (lstat) catches a live OR dangling leaf link. Arm 2 (resolved containment) catches a destination reached through a symlinked ancestor directory, where every leaf is a regular file and a leaf-only guard answers false.
- **The doctor stopped reading through links.** `--check` over a target holding 17 links and zero real adapters printed a bare `ALL CHECKS PASSED` before this plan; it now names all 17 in the existing NO VERDICT grammar, and `--check --strict` exits 1 where it exited 0.
- **IN-03 closed.** The doctor's target-side catch no longer collapses every read error to "absent from the target"; ENOENT keeps `absent`, everything else is reported as present-but-unreadable.
- **WR-04 closed.** The `linkOrCopy` fallthrough in the agents write loop — whose success outcome was 17 dangling links into a deleted temp mirror, reported as `linked` at exit 0 — is now a hard refusal.
- **Nine adversarial shapes re-attacked** against the freshly built `install/install.js` from a scratch directory outside the repository, pre-fix vs fixed, with observed output recorded below.
