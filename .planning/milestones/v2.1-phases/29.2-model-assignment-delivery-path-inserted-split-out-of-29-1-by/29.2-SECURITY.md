## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| target repository → installer | `TARGET/.grugops/factory.config.json` is user-authored; the installer copies it and a spawned generator parses it | JSON config, low sensitivity, untrusted shape |
| installer → spawned generator | child process started with `process.execPath`; stdout/stderr relayed into the run report | argv (fixed), relayed text |
| installer → filesystem (temp mirror) | mkdtemp tree created, written, executed from, removed | kit copy, rendered adapters |
| target filesystem → installer write path | destination shape (file / symlink / ancestor symlink / directory) is target-controlled and crosses into `writeFileSync` | adapter bytes |
| target filesystem → `--check` doctor | doctor reads target bytes to produce a verdict; a link makes it report on the wrong file | adapter bytes |
| kit prose → installed user | shipped docs are read as authoritative and cannot be corrected in the reader's tree | claims |
| phase records → next verifier | disposition table and ledger are the only evidence of what was decided vs not looked at | audit trail |
| host OS temp dir → run exit code | an OS-level cleanup failure must not author the verdict | exit code |
| CI green badge → "proven" | a platform that cannot run a case must not read as a pass | test results |
