<objective>
Close the round's second finding class: **a proof that cannot fail.**

Round 3's verifier deleted the ubuntu-block reader's right bound outright — `return rest`, the
pre-fix shape — and ran the file. It came back **263 passed (263)**. Nothing in this tree can tell
the bounded reader from the unbounded one, because the block is the last step in `ci.yml` and both
branches of `next === -1 ? rest : rest.slice(0, next)` return a string that cannot contain the step
marker. The case's own comment claims the property is "asserted rather than inherited from the
coincidence that this block happens to be the last step today". It is inherited from exactly that
coincidence, and the same tautology sits in the sibling reader and, at lower stakes, in a third file.

The remedy this round's own lesson prescribes is not another assertion. It is: **assert the
verification harness's own premise, and give the assertion an input on which it can fail.** So the
bound is proven over a synthetic workflow that HAS a following step, and — the part that makes the
proof permanent rather than a one-off transcript — the same synthetic input is read twice, once with
the bound and once without, with the two results asserted to DIFFER. On a tree where the bound is
deleted, that control fails on every run, not only in the session where someone thought to try it.

Three smaller items in the same family travel with it. `(r-class)` certifies two readers that are
**not the same slice** — measured on this tree, one returns 21 command entries and the other 20,
and the extra entry is the step name itself. `(o-one-consumer)` decides a census by a fixed 300-byte
window, so a second consumer that assembles its pattern into a local first is invisible to the
residual count it publishes. And a hand-typed `10` inside a NEGATIVE assertion pins
`CANONICAL_SCHEMA`'s cardinality by hand, so an eleventh key makes that assertion vacuously true
forever.

Output: three deleted tautologies, three bound proofs that discriminate on every run, a member set
derived from a prefix rather than an exact name, a census predicate that sees the shape it was
written to bound, and one negative assertion whose own premise is asserted.
</objective>
