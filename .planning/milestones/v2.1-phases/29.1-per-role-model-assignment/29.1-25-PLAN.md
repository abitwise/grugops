<objective>
Rule on the one governance question round 4 raised, apply the ruling, and close the round.

**A ratified decision was reversed in a comment.** D-06 says an unknown key in `roles` is refused,
naming the key and the valid set, and the module argued in the same breath that "is this key a real
role" belongs to the configuration reader alone — so `resolveModels` skipped an override for a stem it
did not cover. Plan 29.1-21 converted that skip into a refusal on two measurements, and the
measurements are sound. What is missing is the record. `git diff 6f8411e..HEAD -- CHANGELOG.md` is
EMPTY across the whole phase; the `overrides` docstring still described the argument as
already-validated until plan 29.1-23 corrected it; the reversal's only standing record is a source
comment plus `.planning/WINDOWS.md` row 86. In a repository whose stated value proposition is an
auditable requirement-to-release trail, a ratified decision reversed inside one file is invisible to
every consumer of that trail.

**Whether that is a defect is a judgement, not a predicate.** The new refusal branch is unreachable
from production — both call sites hand the configuration reader and the resolver the same stems — so
nothing measurable turns on it today. Whether a disclosure ledger substitutes for a decision record in
a pre-1.0 internal contract is the user's call, and this plan opens by putting it to them with the
measured facts and the options rather than with a recommendation wearing a finding's clothes.

**Then the round closes the way the previous four should have.** One disposition table, derived from
the two round-4 documents rather than remembered, with its item count asserted; the three still-open
human items carried forward verbatim and unclosed; and one final adversarial pass in which all three
round-4 blockers are re-reproduced against the final tree and each is watched failing where it
previously passed.

Purpose: the decision trail carries the decision, and no round-4 item leaves this round without a
disposition.
Output: a ruling, the record the ruling calls for, a derived and counted reconciliation, and a final
green gate set with three watched red reproductions beside it.
