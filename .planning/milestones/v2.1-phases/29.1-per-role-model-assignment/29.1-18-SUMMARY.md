## One extraction, read once

The mention accumulator and the predicate it counts for, on adjacent lines:

```ts
    const allResolve =
      named.length > 0 &&
      named.every((base) => isConfigSibling(siblings, base));
    if (inConfigDir && allResolve) {
      exempt.push(hit);
      // The MENTION count comes from the SAME `named` array the predicate one line above decided
      // on. One extraction, read once, feeding both the decision and the number the gate publishes
      // about it …
      exemptMentions += named.length;
      files.add(file);
```

`named` is built once, from `line.matchAll(CONFIG_NAMED_PATH)`; the predicate and the published number read the same array. The sibling set is likewise derived once, through the gate's own `walk()`, with no second `readdirSync` and no second `statSync` at the call site:

```ts
function configSiblingFiles(): string[] {
  const dirPrefix = join(CONFIG_SELF_REF_DIR) + sep;
  return walk(CONFIG_SELF_REF_DIR, [])
    .filter((rel) => rel.startsWith(dirPrefix))
    .map((rel) => rel.slice(dirPrefix.length))
    .filter((base) => !base.includes(sep))
    .sort();
}
```

`existsSync` no longer decides whether a captured basename is a self-reference. The replaced predicate, before and after:

```ts
// BEFORE
named.every((base) => existsSync(abs(join(CONFIG_SELF_REF_DIR, base))))
// AFTER
named.every((base) => isConfigSibling(siblings, base))
```

## Decisions Made

- **The canonical form, not the reviewer's deny-list.** `29.1-REVIEW-round3.md` §CR-02 proposed `if (base === "." || base === "..") return false;` plus a `statSync().isFile()` probe. That is a deny-list of two spellings and would have left the subdirectory shape open (`sub` is neither `.` nor `..`, and `statSync().isFile()` on `join(dir, "sub")` is false only because the probe happens to also answer the depth question — for a *file* directly under a subdirectory it never gets asked). Membership in the derived set answers all four shapes with one rule, which is what the plan's prohibition required.
- **The gate publishes its denominator.** Asserting the sibling set's premise from the harness otherwise required a second implementation of the derivation rule in the test file — the exact set-literal-drift class this file's own scan-set derivation was written to delete. Reading a published count follows the `reportedMarkerSites` precedent already in this file.
- **`CONFIG_SELF_REF_HITS` keeps its identifier and gains its unit.** Inside this module a "hit" *is* a line, so the name is precise where it lives. Outside it is not, so the failure text says `exempt LINES` and the pass line says `line(s)`.
