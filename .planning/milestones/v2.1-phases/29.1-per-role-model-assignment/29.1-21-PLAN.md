<objective>
Close the round's last three items and close the round.

**The refusal path throws out of itself.** `resolveModels`' module header says returning a result
rather than throwing is what lets one reader serve all three consumers, because a catch is where a
refusal quietly becomes a default nobody chose. Both floors build their reason by serialising the
rejected value, which throws on a circular object and on a BigInt — so the value that reaches the
refusal is the value that prevents the refusal from being returned. The round-3 verifier reproduced
all four shapes against the committed `.js` and got four TypeErrors. R2-WR-01 closed the ITERATION
throw one round ago and left this one open, and it is latent in exactly the sense that one was.

The fix the round-3 review names is structural and this plan takes it verbatim: **one authority for
quoting a value into a refusal, and that authority is total.** There are currently two spellings of
one operation in a module that argues against exactly that; one of them already carries a docstring
claiming totality it does not have. Making the authority total makes that docstring true and deletes
the second spelling in the same change.

**A docstring wider than its mechanism, in the same module.** The anchored-line reader's docstring
says trailing whitespace is trimmed off the line and never off the captured value. Measured: the line
is trimmed before the value is sliced from it, so a trailing run is trimmed off the value too. The
anchoring itself is correct and the practical effect is benign — the values are members of a closed
set — but this module's stated posture is that a published claim wider than its mechanism IS the
defect, and this round found the same shape in four other places.

**A record falsified by the round that falsified it.** A comment in the public-docs vocabulary gate
makes a standing claim about another gate's scan-set constant, and plan 29.1-17 moved that constant.
The executor disclosed it, declined to edit a file outside its declared scope and asked for a ruling.
**The ruling is in: it is in scope and it is fixed here.**

Then the round closes: every round-3 item reconciled against a derived list with an asserted count,
the ledger rows that are now satisfied closed, and the fourteen-command phase gate block run in CI's
order.

Output: a refusal path that returns on every input, a docstring that describes its mechanism, a
record that states what is true, and a round with nothing dropped.
</objective>

| a published docstring → the reader who relies on it | A claim wider than its mechanism is trusted at exactly the moment it is wrong |
