under a describe block titled for every input. That is this module's own named defect, a totality
claim strictly wider than the axis its corpus measures, appearing inside the case written to close
it. Rule 5 of this round exists for exactly this: when a fix makes a claim TOTAL, widen the corpus to
the axis the claim names.

the same authority the alias already goes through, so one function renders every value interpolated
into a refusal and there is no position in either sentence that is un-guarded. Because the authority
renders a string through the serialiser, every legal key's wording stays byte-identical and only the
shapes that threw change behaviour.

**Two records ride along, because both are the same class this phase exists to close.** WR-02: a case
argues its corpus is measured against a denominator that is not this file's to choose, then hand-types
that denominator three lines later — so deleting one corpus entry and its matching result string in
one edit leaves the case green. WR-04: a scan claiming to prove one spelling *in this module* reads
the `.ts` and not the committed `.js` hosts execute, and its comment strip drops whole-line comments
only without saying so.
