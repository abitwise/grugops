<objective>
Discharge the project's oldest open item, in one commit, against one captured run.

GAP-D1 has been open since 2026-06-16 and has been re-confirmed as a standing deferral twice. It
waits on exactly one thing: a captured live dual-path run with a date and a verdict. Plan 33-10
either produced that capture or produced a diagnosis; this plan performs the flip in the first case
and records the hold in the second.

D-17 rates this one-way: the flip changes requirement status across four milestones' records, and
undoing it is a second manifest-driven edit plus a status reversal, not a revert. It therefore sits
behind a decision checkpoint, and it is performed against the manifest plan 33-07 declared and the
gate plan 33-07 built — so the commit is checkable rather than trusted.

Purpose: close the oldest item with evidence, or hold it honestly.
Output: one flip commit over exactly the declared set, every cell cited, and the gate green over it.
</objective>

## Trust Boundaries

| Boundary | Description |

| a captured run -> four milestones' requirement records | One artifact's authority propagates across records that were closed years of project-time apart |

| a ledger's three representations -> a hand edit | A hand edit desynchronises a counter block, a table and a JSON appendix |
