<objective>
Build the instrument that makes the GAP-D1 flip checkable before the flip happens.

D-17 requires one commit touching exactly one declared set, and a check asserting that no
`pending human` cell or GAP-D1 deferral sentence survives outside it. RESEARCH found that check
unsatisfiable as written: 116 such lines across 43 files repo-wide, most of them historical records
that describe a past state truthfully and must not be rewritten. The planner re-measured the
suffix-exclusion rule RESEARCH proposed and found it insufficient as well — after excluding plan,
summary, research, review, context, pattern and superseded-round documents, 20 files still carry the
phrase and 22 carry the deferral token, and most of those are verification records, UAT records,
discussion logs, milestone audits and research notes that are also truthful history.

So the scope is an ALLOW-LIST OF DERIVED PARTS, not an exclusion of suffixes — the same shape the
banned-claim scan already uses, with a per-part vacuity floor and a pinned total whose refusal text
says that moving the pin is how you acknowledge a change, not how you make a failure go away.

Purpose: the flip is refusable before it is performed, and the residual rule has a bounded
denominator.
Output: a committed manifest with its exclusion rule written down, and a gate that reads it.
</objective>

    - Given the committed manifest and a commit whose changed-file set equals the manifest's declared

    - With the manifest in its pre-capture state, the same surviving cell does NOT fail the gate —
      before the flip, those cells are correct.

      exit non-zero and name the cell.

      gate exit non-zero and name the missing section.
    - A live-surface part deriving zero members makes the gate refuse a verdict and name the part.
    - A derived total differing from the pinned total makes the gate refuse, with the refusal text
      naming every part's member count.
    - An input the gate cannot derive — an unreadable manifest, a failed git invocation — makes the
      gate report NO verdict and say so, rather than reporting a clean result.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| the manifest (declared) -> the commit (actual) | A declared set that drifts from the commit lets a surface flip unchecked or an unrelated file ride along |
| a flipped cell -> the capture summary | A citation that names a section the summary does not contain is a fabricated trace |
| the derived live-surface set -> the residual rule | An unbounded denominator makes the rule either vacuous or a refusal of truthful history |
