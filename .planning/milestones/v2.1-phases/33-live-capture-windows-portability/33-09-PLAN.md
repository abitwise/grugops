<objective>
Measure CAP-02 on the only instrument that can answer it: a pushed CI run, both legs.

Every local command in plans 33-02 through 33-06 runs on one developer machine on one operating
system. CAP-02's literal bar is a matrix leg exiting 0, and D-13 reads it as BOTH legs, because the
step that is red on the Windows leg is the same step that is red on the ubuntu leg. Nothing short of
a pushed run answers it.

This plan also discharges the phase's remaining dependency for the live capture: the head sha under
test must be pushed before plan 33-10's go can be asked for (D-05), and the measured starting state
was seven commits ahead of the remote.

The push crosses a line this project holds mechanically rather than by prose — humans decide, agents
execute — so it sits behind a blocking checkpoint that stops in every mode.

Purpose: turn an assumption about two legs into a measurement with a run id.
Output: a filed CI measurement, the ledger rows this run disposes, and a pushed sha plan 33-10 can
cite.
</objective>
