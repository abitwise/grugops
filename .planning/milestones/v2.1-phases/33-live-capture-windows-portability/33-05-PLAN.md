<objective>
Turn four host-capability absences from spawn errors and false premises into named, counted skips —
and fix the one refusal that never reaches the arm under test.

D-16 is the rule: a fixture that cannot be created for want of a privilege emits the `SKIPPED:`
line the in-repo chmod idiom already uses and is counted in the platform-shape remainder, never
silently passed. RESEARCH found four absences on the Windows runner, each with an in-repo idiom to
port rather than invent: the loader interpreter (one sibling file already resolves it correctly),
the named-pipe constructor (the shape corpus already returns false rather than throwing), the
symbolic-link privilege (the shape corpus already declares it non-portable with a reason), and
mode-0 enforcement (the kit-model test already has the named-skip branch).

It also found the one place where a literal contradicts the measurement: a test asserting the
remainder is empty, on a platform where the correct remainder is two.

Purpose: every absence is visible and counted; no absence is a green.
Output: four ported skip idioms, a derived remainder expectation, and the not-a-regular-file
refusal reaching its own arm.
</objective>
