<objective>
Make the live lane a wrapper around the runner, and bring two safety documents into line with what
the code now does.

D-08 moves the driving into `scripts/capture-live.ts` and keeps the lane's keystone: the loud skip,
its test-of-the-test, the derived per-test bound and the cleanup discipline. Everything else in the
file becomes an invocation of the runner plus assertions over its summary. The same decision
requires correcting a stale claim in this file's docblock, which is the subject of an open ledger
row: the default test script does not keep this lane out of the green path, and a safety-relevant
docblock asserting otherwise is exactly the kind of sentence this project refuses to leave standing.

RESEARCH disproved one CONTEXT claim that matters here: the deny matcher does NOT apply unchanged
to a hook event LINE. Its extractor is string- and escape-aware, so a deny escaped inside a JSON
string value fails closed — by design and by its own header. The function stays untouched; what
changes is that its header enumerates only two input classes, and plan 33-01 now feeds it a third:
the decoded standard-output field of a CLI-emitted hook response. That is a point-of-effect channel,
the class the header already calls sound. Leaving the omission would make the module's own
documentation contradict the use the phase makes of it.

Purpose: one driver, one bound, and no safety document that contradicts the code.
Output: a thin wrapper, a corrected docblock, and an amended matcher header.
</objective>
