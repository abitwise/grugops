# Phase 34.1 Plan 58: CR-08 and WR-39 (D-45) Summary

**`--check` now reports a moved kit home only when the given kit home's own kit-home record names the recorded one (by real path) and nothing is left at the recorded path, so its "move it back" remedy can no longer target a second repository's kit home; and the uninstaller asks how it read the marker before asking whether anything is at its path, so a `.grugops` file or dangling link never yields "marker not present" after a fix-by-hand verify.**
