# Phase 34.1 Plan 26: The unusable-marker remedies name this run's agents, and an unknown installed set is called unknown Summary

**When a marker has no target or no install ledger, uninstall now prints the same two steps the moved-target case got in plan 34.1-25: `reinstallCommand()` (this run's agent flags, the kit home, and `--symlink` when the marker records it), then `rerunCommand()`. A flag-less run adds one shared clause that says what install does with no agent flag. Over any marker it cannot use, uninstall says which agents are installed is unknown, where it used to say "none". Rows R26, R27, R28 and R34 follow these remedies as printed, and each has a mutation proof.**
