# Phase 34.1 Plan 59: DI-25 pre-write refusal Summary

Install now writes nothing over a `.grugops/install.json` it cannot record into: a user's own JSON object, any
unreadable marker, and (D-46) install's own marker whose install ledger is malformed. It exits 3, says why in the
owner's wording, offers no removal, and names no next step after a foreign read. One owner, `installRefusal`, makes
the decision, and install asks it once, before the `--migrate` pre-steps, the run banner and the kit copy.

## What the refusal prints

A foreign read (scratch probe, `{"mine":1}`, `install --codex`, HOME and GRUGOPS_HOME under the session scratchpad; exit
3, the target holds only `.grugops/`, HOME stays empty):

```
-- install marker (read before any write) --
  verify         .grugops/install.json is a JSON object but could not be used as install's marker (it holds none of install's fields: grugopsHome, kitRoot, installMode, target, ledger), so nothing was installed: install records every file it writes in .grugops/install.json and cannot record into this one, so it wrote nothing in the target or the kit home. .grugops/install.json was not written by install (the file holds none of install's fields: grugopsHome, kitRoot, installMode, target, ledger); if it is yours, leave it.
  skipped        .grugops/install.json (left unchanged — it holds none of install's fields, so it was not written by install; if it is yours, leave it; see the verify line above)

== install INCOMPLETE — 1 item(s) need verification ==
  Nothing was written in the target or the kit home.
```

A malformed install ledger (D-46; closing-claims R2, one ask-rules entry without createdAsk):

```
  verify         .grugops/install.json — the install ledger is malformed (entry 23: it lacks createdAsk), so nothing was installed: install records every file it writes in .grugops/install.json and cannot record into this one, so it wrote nothing in the target or the kit home. Fix .grugops/install.json by hand (the install ledger is malformed, entry 23: it lacks createdAsk: correct that entry or field of the install ledger to what install wrote, for example from version control or a backup); never delete the marker: it is the one record install keeps of the agents installed here, so without it no uninstall can undo what install made; then re-run the installer.
  skipped        .grugops/install.json (left unchanged — its install ledger is malformed; see the verify line above)

== install INCOMPLETE — 1 item(s) need verification ==
  Each `verify` line above names what was NOT installed and the remedy for it.
  Once each is fixed, `GRUGOPS_HOME=<kit> INSTALL_MODE=copy GRUGOPS_SRC=<checkout> node <checkout>/install/install.js --target <t> --claude --codex --antigravity --opencode --copilot --pi` installs for the same agents again (add any other option this run was given).
```
