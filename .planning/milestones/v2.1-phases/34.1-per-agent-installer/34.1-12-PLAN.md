<objective>
Add the interactive checkbox list (D-02): at a terminal, with no agent flag and no `--yes`, the installer asks which
agents to install for, pre-checking the installed and detected ones; an empty or cancelled answer refuses like D-03.

Purpose: the human's direction (G-34-R3-2): "ask during installation which coding agent the person will use". Measured
in research (Node v26.11.0, macOS, under `script`): raw mode plus the synchronous readSync loop returns one chunk per key,
so the picker fits the installer's synchronous flow.

Output: the pure picker module and its tests, the raw-mode shell wired into the selection, a pty case, the module-count
pin, and the install guide's paragraph. The real-terminal feel is a human check.
