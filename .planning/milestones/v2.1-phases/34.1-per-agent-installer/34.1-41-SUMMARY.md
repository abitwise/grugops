# Phase 34.1 Plan 41: the unbound remedies name where their install step puts the kit Summary

**Over a marker that is not this directory's record, uninstall.js's two remedies and both arms of the doctor's WARN now say where the printed install step puts the kit, for example `it copies the kit into /home/u/.grugops, writes a marker for this directory ...`.
