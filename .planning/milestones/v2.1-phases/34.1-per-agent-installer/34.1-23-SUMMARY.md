# Phase 34.1 Plan 23: Every command install.ts prints carries the run's context Summary

**All ten agentCommand calls in install.ts now pass COMMAND_CONTEXT. A printed install command names install.js by its absolute path, starts with `GRUGOPS_HOME=<dir>` when the run used another kit home, and carries `--symlink` when the run was a symlink install. A printed uninstall command names uninstall.js by its absolute path and carries neither. Row R33 runs the INCOMPLETE banner's command of a `--symlink` run as printed, from a scratch directory: it finishes the install, and the install stays a symlink install.**
