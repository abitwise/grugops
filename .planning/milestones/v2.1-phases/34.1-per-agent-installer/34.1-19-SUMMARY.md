# Phase 34.1 Plan 19: CR-03 keep-without-record split Summary

**A per-agent uninstall no longer tells the user to delete `.grugops/install.json`, which still records the agents that stay. The kept `left` line and the KEPT_FOR banner now get the alternative from one function, keepWithoutRecord. On a partial run it names the per-entry ledger edit, the finishing command and the staying agents. Only a flag-less run still offers deleting the marker.**

## Accomplishments

- `keepWithoutRecord(held, where)` in install/uninstall.ts (beside finishCommand). On a FULL run it returns the delete-the-marker text. The line form keeps today's words, and the banner form keeps today's "(uninstall then has no record of them and changes nothing more)". On a partial run with held items it returns "or, to keep it/them, take its entry/their entries out of the install ledger in .grugops/install.json by hand, then run `<finishCommand>`; never delete the marker: it is still the record of <STAYING>". The banner form says "... and run that command; never delete .grugops/install.json: ...". On a partial run with nothing held it returns the empty string.
- The kept `left` line ends with "`<finishCommand>` finishes the reversal" plus "; " and keepWithoutRecord(held) when that is not empty. The KEPT_FOR banner builds its alternative from keepWithoutRecord(heldPaths(), "banner").
- R19 turns the verifier's CR-03 reproduction into a test. The steps: install --claude --codex, edit the shared skill, uninstall --codex, take the entry out of the ledger with withLedger, run the printed command, then uninstall --claude.
- R20 covers the FULL branch: a flag-less kept uninstall offers deleting the marker. After the marker is deleted, a further flag-less uninstall exits 0 and leaves the edited file alone.
- install/README.md and CHANGELOG.md now say the same thing as the code.
