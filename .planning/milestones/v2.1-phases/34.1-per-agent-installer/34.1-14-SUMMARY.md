## Decisions Made

- finishCommand on a partial run never falls back to the flag-less command. When UNFINISHED is empty it names the
  flags this run named. See DI-07 for the one case where that command does nothing.
- The INCOMPLETE banner's finishing line prints for the outcome kind `kept`, and for `kept-for-agents` only when the
  rewrite was `not-rewritten`. In that case the marker still records the agents this run set out to remove. A partial
  clean run that did rewrite the record has no per-agent work left to finish.
- The unbound-marker verifies keep the phrase "re-run install.js here, then uninstall". Two existing tests match it
  (installer-never-installed, ledger). The phrase is extended with the printed command and the note that any agent
  flag will do.
