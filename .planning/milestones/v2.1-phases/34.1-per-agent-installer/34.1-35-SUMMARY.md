# Phase 34.1 Plan 35: commandContextFromRecord, the doctor's printed kit home and mode from the record Summary

**host-tools.ts commandContextFromRecord takes a printed command's kit home and install mode from an `ok` install marker (never an `unbound` one) and from the run otherwise. install.ts builds COMMAND_CONTEXT through it from the doctor's one marker read. A `--check` run without the custom GRUGOPS_HOME or `--symlink` now prints `GRUGOPS_HOME=<K> node .../install.js [--symlink] --target <t>`. Followed as printed, that command writes no second kit and leaves the install where it was.**
