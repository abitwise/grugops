# Phase 34.1 Plan 08: Per-agent install writes Summary

**Install now writes only the chosen agents' entries plus the shared footprint: the Claude Code kit, CLAUDE.md block and ask rules only for `--claude`, the Copilot block only for `--copilot`, each whole-file entry only for its agents. Agents not named keep their files and ledger entries byte for byte (the ask-rules entry is carried verbatim). A non-Claude install's marker names the kit home it copied, and the closing notes give each chosen agent's recorded entries and documented invocation (`$grugops` for Codex).**

## Accomplishments

- **Gates.** `SELECTED_KINDS` (the adapter kinds of SELECTION) gates:
  - the kit block (no kit plan is built; a `skipped` line names the reason) and the nested-adapter refusal on `claude-kit`;
  - the CLAUDE.md block on `claude-kit` (a `skipped` line otherwise);
  - the Copilot block on `copilot-pointer`;
  - the whole-file entries, now `wholeFileEntryRels(SELECTION)`.
  - AGENTS.md, the kit copy, seedState, materializeRunnable and writeMarker run on every install.
- **Ask rules.** `askRulesStep` runs `writeAskRules` only for Claude Code (`ASK_RULES_RAN`). Otherwise:
  - the outcome is `not-chosen`, and the notes say "No ask rule was written in this run: Claude Code is not chosen.";
  - `nextLedgerEntries` carries the previous ask-rules entry verbatim;
  - an unreadable marker is still a counted verify.
- **Kit fields.** When Claude Code is not in AGENTS_AFTER, `writeMarker` writes this run's grugopsHome, kitRoot and installMode, and reads kitVersion from the kit home. The "kitVersion kept" note prints only while Claude Code stays installed.
- **--migrate.** The pre-check builds the kit plan and takes KIT_WRITE only when Claude Code is chosen. The config carry and the in-repo kit backup run as before.
- **Registry.** Every `HostTool` row carries `invoke`, with its documentation source in a comment. Codex: "type `$grugops <request>`, or pick it from `/skills`". Copilot's text carries `UNKNOWN - verify`.
- **Closing notes.** The retired "get documentation only." line is replaced by:
  - one line per chosen agent: name, the entries the install record holds for it (via `entryOwners`), and its `invoke`;
  - one line saying the invocations were not run on a live host (`UNKNOWN - verify`);
  - when installed agents were not chosen, one line naming them, saying install never removes an agent's files, and giving `node install/uninstall.js --target <TARGET> <its flag>` with each flag.
- **Route notes.** `noteStrandingCarriers` names only agents installed after the run.
- **Tests.**
  - The `--codex` tracer.
  - "install only adds (D-04)" (a)-(d).
  - The invoke and closing-line cases.
  - `AGENT_VARIANTS` and `deriveAgentWriteSets`, which share `writeOneVariant` with `deriveWritePaths`.
  - The per-agent write-set class test over 6 rows, with the union equality.
- **README.** `install/README.md` lists:
  - the shared footprint;
  - each agent's entries (the Pi template "written when Pi is chosen", no longer "in every install");
  - install only adds;
  - per-agent usage examples, with no all-agents flag.
