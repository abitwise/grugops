GRUGOPS_HOME names another repository's kit home; following the printed "Move K2 back to A" then breaks the second
repository (reproduced by the verifier and by the human). Per D-45 the doctor says "moved" only when the given kit
home's own record proves it (its kit-home record is `unbound` and names the recorded kit home) and nothing is at the
recorded path; otherwise the observed FAIL on the absent kit stands.

read the marker as unusable, so with `.grugops` a regular file or a link to nothing one uninstall run says "never
delete the marker" and then "marker not present". Per D-45 the read is asked first, the reader-state matrix gains both
shapes, and the CHANGELOG sentence about a `.grugops` link is made true. The UAT gap's missing list (from review
WR-39's fix) also names the doctor's "is present" subject for a reader that stopped on the way; it is the same
finding and is fixed here.
