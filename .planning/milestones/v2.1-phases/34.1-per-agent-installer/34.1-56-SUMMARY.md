# Phase 34.1 Plan 56: WR-37, `--check` names a kit home moved by hand Summary

**When `--check` is given a moved kit home through GRUGOPS_HOME, the kit-root cross-check no longer prints "sources agree". It prints one `kit home moved:` FAIL that names both kit homes. The remedy is done by hand and writes no kit: move the kit home back, then run the printed check command. The line also says that the install commands on the doctor's other lines copy a kit to the recorded home. R54 follows that remedy as printed and ends with exactly one kit. The comments, CHANGELOG and README now say this, and the "writes no second kit" claim is retired.**
