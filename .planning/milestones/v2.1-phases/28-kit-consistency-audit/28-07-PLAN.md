## The rubric, restated

Identical to 28-06's. Six categories, all asked of every file, every finding naming the one it came
from, category 6 record-only and deferred to Phase 29.

| # | Category | The question |
|---|---|---|
| 1 | Factual correctness | Does this file describe the architecture that ships? |
| 2 | Reference integrity | Does every path, role, workflow, checklist and config key it names resolve on disk? |
| 3 | Claim honesty | Is anything unproven stated as fact? Is `UNKNOWN - verify` present where warranted? |
| 4 | Internal consistency | Do counts, versions, tier names and config keys agree with the schema and with sibling files? |
| 5 | Strangeness | Vestigial sections, contradictions, dead options, text with no remaining reader? |
| 6 | Instruction determinism | Would two agents reading this step reach the same act? **RECORD-ONLY — deferred to Phase 29.** |

Workflows are where category 6 bites hardest — they are step sequences an agent executes, and LANG-02
governs exactly this surface. Expect this category to be the largest finding set in the phase, and
record each one with a step reference precise enough that Phase 29 acts without re-reading.
