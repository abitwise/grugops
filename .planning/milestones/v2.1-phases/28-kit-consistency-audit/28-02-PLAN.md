<objective>
Close the fail-safe residuals that get more expensive if deferred, refresh the third-party pins by
measuring rather than inheriting, and size the two unsized residuals so the phase knows what it is
committing to.

Per D-19 the posture is defects fixed, prose recorded. This plan carries the defect half: the
non-terminating oracle (item 7), the pin refresh (item 6), and the investigate-and-size pass over
items 1 and 2. Items 3 and 5 are one-line fixes that land beside their owners in later plans; item 4
is irreducible and becomes a claim-registry row in 28-04; item 8 is record-only per D-07.

Per D-20 the acceptance bar for the oracle is three things, not one: consuming anchors so the
predicate is linear, a permanent regression control that was RED before the fix and GREEN after, and
a loud named input bound. The third exists because anchoring makes the predicate linear but does not
stop the oracle reading arbitrarily large agent-written prose — `WR05_SCAN` includes `STATE.md`, an
unbounded narrative the GSD workflow appends to on every state update, and the exact file whose
527 KB line produced the original non-termination. This repository's terminal lesson is to ask what
the predicate's INPUT is assembled from.

Per D-23 AUDIT-04 is satisfied by re-measuring at execution time. The requirement says versions are
verified at the time of change and recorded rather than assumed; pinning the roadmap's pre-named
numbers because the roadmap says so is exactly the assumption it forbids.

Per D-21 and D-22 the byte-round-trip adjacency residual is fixed in this phase with a red-team pass
if it reaches the canonical admission reader. This plan does not run that round. It measures whether
the round is owed.

Purpose: convert a hanging gate into a failing one, convert an inherited number into a measured one,
and convert an unsized risk into a decision the human can see before it is paid for.
