prerequisite for reasoning soundly about CR-01, because CR-01's fix decides membership of a line in an
anchored block by index.

channel on the floor. `PUBLIC_DOCS_CORPUS_PARTS` is evaluated at import time, so a refusal raised while

missing `agent-factory/README.md` — lands in the OTHER module's private array and is never printed by the
gate that is running. The verdict stays fail-closed; the diagnosis is wrong. This is directly load-bearing
for plan 29-53, which adds a sixth derived part: a new part with a channel nobody reads repeats it.

- **A green suite is not proof for a safety invariant.** Every closure claim is reproduced on a hermetic

  attempts, with a clean-mirror control run and the mirror's own premise asserted green BEFORE any plant.

  professional voice.
