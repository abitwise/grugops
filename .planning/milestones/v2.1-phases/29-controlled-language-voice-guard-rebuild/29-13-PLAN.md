<objective>
Re-baseline the byte ceilings once, prove no ceiling rose, and record what the profile actually cost in
bytes.

D-25 keeps the ceiling table hand-maintained rather than derived, and the reason still holds: it is a
per-file measurement baseline, not a discovery set, and it already fails closed on a role it does not
know. Deriving it would turn a fail-closed table into one that widens silently whenever a file grows.

D-26 makes the re-baseline a single act in a dedicated final plan, and makes the mid-phase rule
unnegotiable: a red ceiling meant trim or split, never edit the table. That rule had to be plan-level
rather than a note, because "the rewrite legitimately needed the bytes" is a persuasive-sounding reason
to raise one, and it is available in every single content plan.

D-27 chooses the proof. A permanent fixture pinning the old values would be a second place to edit and a
second thing to keep true; a one-shot measured before-and-after transcript, compared against the
git-previous table, is the honest control when the "before" build stops existing once the edit lands.

D-28 is the other half of the phase's honesty. No ceilings are invented for workflows, checklists, seed
templates or contracts — nothing external forces one, and nineteen-plus new hand-measured baselines
would be exactly the set-literal surface this milestone exists to eliminate. Instead the growth is
measured and recorded, per file and per part, so a later phase decides on evidence. A single aggregate
corpus budget was rejected for the reason per-file ceilings exist at all: it lets one file balloon while
others shrink.

The edit is one-way. Once the table is edited and the phase closes, the previous baseline exists only in
git history and in this plan's transcript; a later phase cannot re-derive what the pre-rewrite
measurement was. That is why a human confirms the transcript before the table moves.

Purpose: close the phase with a measured, once-only re-baseline and a growth record a later phase can
reason from.
Output: an edited ceiling table, a before-and-after transcript, a corpus growth document, and a fully
green gate set.
</objective>
