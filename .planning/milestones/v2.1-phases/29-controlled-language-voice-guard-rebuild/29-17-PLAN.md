<objective>
Close CR-03 and the two remaining vacuity call sites in `guard_imperative_lexicon` and
`guard_sentence_form`.

CR-03 is a POSITION bug, and the distinction matters because the project's standing question is not
which characters a predicate accepts but at which positions it is even asked. The list-marker pattern
admits at most three leading spaces. A CommonMark sub-bullet under a numbered step is indented four or
more, so it is not counted as a `## Steps` bullet at all — invisible to the lexicon guard, absent from
its denominator so the loss leaves no trace, reclassified as descriptive so it is measured against the
25-word bound instead of the 20, and skipped entirely by the modal rule and the one-instruction rule.
The guard's own banner asserts "every `## Steps` bullet begins with a verb from the closed approved
set at position zero". That is not what it measures, and LANG-04 is precisely the requirement that a
guard be named for exactly the decidable subset it checks. Same lines, same class: a `### ` sub-heading
under `## Steps` currently releases every bullet after it.

WR-02 is the shared vacuity rule receiving, at both of this gate's call sites, a denominator derived
from the very array the loop counts — so its second branch can never fire and the only live floor is
the zero check. This module's sibling `kit-model.ts` makes exactly this argument in its own words:
once both sides read the same object, the comparison compares an object with itself and can never
fail, so it is documentation of intent rather than a check. The concrete consequence here is that a
governed corpus in which 17 of 47 files stopped producing step bullets is indistinguishable, in the
gate's output, from one in which all 47 do.

Every one of these fixes is behaviour-preserving on the live corpus — measured, not assumed. That is
exactly why each one's proof must be a planted adversarial input rather than a moved number.

Purpose: make the guard enforce the subset it is named for, and make its published numbers capable of
failing.
Output: a depth-independent step grammar, a sticky section anchor, two independent denominators with
named set refusals, a fence-aware table locator, and four planted fixtures.
</objective>
