WHAT THE PAIR SAYS THAT NEITHER FILE SAYS ALONE.

The RED baseline removed the pre-pass from the committed build and measured six
corpus rows changing disposition, three of them into `row`. This run measures
those same six rows landing where the contract puts them. Between the two, the
`blanked` bucket is shown to be a consequence of the pre-pass and of nothing
else — which is the claim the D-03 case has been making since plan 32-01 without
any evidence behind it.

The vacuity case in the last block is deliberately asserted GREEN in both runs.
All three transcribed documentation blocks yield zero columns whether the
pre-pass runs or not, so that measurement is stable across the mutation and is
recorded as a standing fact rather than as a regression. It is the reason the
mutation half exists.
