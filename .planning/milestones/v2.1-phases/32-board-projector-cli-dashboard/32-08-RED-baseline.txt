1. EVERY FAILURE IS AN ASSERTION ON THE PLANNED BEHAVIOUR, NOT A CRASH
---------------------------------------------------------------------------------------------------

The distinction is the whole point of a baseline: a syntax error, a failed import or a fixture crash
also exits non-zero, and none of them authorises the GREEN that follows. Each line below is the
runner's own text.

    AssertionError: the Blocked heading must normalize to `Blocked`, so a ticket in it is IN a

      'ALL CHECKS PASSED\n  SCOPE    governa…' to match

The first two are BEHAVIOURAL, measured end to end against the spawned validator on a hermetic kit,
and each is one of the two deliberate deviations D-06 requires to be named rather than discovered:

    DEVIATION 1   `## Blocked (visible, time-tracked)` — the old strip removed `\s*\(WIP[^)]*\)\s*$`
                  and nothing else, so the column name stayed `Blocked (visible, time-tracked)` and
                  a ticket with `column: Blocked` was reported as being in NO board column. The
                  kit's own board carries that heading, so the defect shipped to every install.
    DEVIATION 2   `## Columns (spec §6.1)` — the old strip removed nothing and the trim kept the
                  whole string, so the validator believed in a phantom column of that literal name
                  and a ticket could claim it and pass membership. The kit's own board carries that
                  heading too.

The last four are STRUCTURAL: a behavioural case can prove the validator AGREES with
`scripts/board-model.ts` today, but it cannot prove the validator holds no second copy that merely
happens to agree. The negative greps run over the comment-stripped source, so the explanatory prose
that necessarily quotes the deleted spelling cannot satisfy them.

4. WHAT THIS SWEEP CAN AND CANNOT SEE
---------------------------------------------------------------------------------------------------

Recorded here rather than left for a reader to discover: all eight fixture boards carry the SAME
four headings — `## Ready (WIP 0/8)`, `## In Development (WIP 0/3)`, `## In Review (WIP 0/3)`,
`## Done (WIP unlimited)`. Every one of the four is legal under both the old strip and D-05's three
forms. So neither named deviation can appear in this sweep: no fixture board carries a Blocked
heading or a non-canonical `##` suffix.

That makes the expected post-extraction sweep byte-identical in all sixteen blocks, and it makes the
sweep a REGRESSION instrument rather than a deviation instrument. The two deviations are measured by
the two behavioural cases in section 1, on boards built for the purpose. Reading a zero-difference
sweep as "the deviations did not happen" would invert what it measures.
