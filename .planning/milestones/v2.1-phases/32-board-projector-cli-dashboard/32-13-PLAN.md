## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| board and ticket file content → stderr → the operator's terminal emulator | File contents are written by agents and land in `readErrors[].message`, which is written to stderr on every frame. A terminal emulator executes what it is sent. |
| argv → stderr | The `repoRoot` argument is echoed in the root-refusal line before anything has validated it. |
| stdout → a `--json` consumer | The published document's framing is a contract a pipeline is written against. |
