6. THE REACHABILITY ANSWER — how the `foreign` branch is REACHED, not only what it refuses
-------------------------------------------------------------------------------------------------

The project's recorded lesson is that asking only what a predicate refuses leaves the positions it
is never ASKED at unexamined. So: the `foreign` branch of `classifySpecifier` is evaluated at TWO
call sites, and both are reached by the SAME gate command. The first is `moduleSpecifiers` in
scripts/js-import-closure.ts, called once per module by `jsImportClosureFacts`, whose input is every
quoted specifier the three emitted import forms carry in the bytes of a committed `.js` after
comments and template-literal text have been blanked; a `foreign` answer there sends the specifier
into `foreignEdges`, which `jsImportClosure` — the entry point all seven production callers and
`copyImportClosure` use — turns into a thrown `ImportClosureError` naming every module and
specifier. The second is `noteSpecifier` in scripts/board-readonly.test.ts, called from
`collectSpecifiers` at each of the three module-identity positions the TypeScript AST exposes
(import declaration, export-from declaration, dynamic-import-or-require call), whose input is the
same committed `.js` parsed rather than scanned; a `foreign` answer there lands in both
`ModuleFacts.foreignSpecifiers` and `ModuleFacts.acquisitions`, and `analyzeClosure` — which calls
the NON-throwing `jsImportClosureFacts` precisely so this census stays reachable — unions them with
the walk's own refused edges. Under `npm run check:dashboard-readonly` both sites run over the live
tree on every invocation: the walker site through the closure the premises walk and through every
`withLiveMirror` mirror, the census site through every `analyzeClosure` call. Neither position can
be reached without the other being reachable, and § 4 P5 is the one measured case where they
disagree — a `require("…")` specifier the AST reads and the byte scan does not — which is recorded
there as a named residual rather than left for a later round to find.
