<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository markdown -> `parseFrontmatter` | Any tracked `.md` file's frontmatter region is untrusted input to the spawn-grant predicate; a contributor, a generator or a merge can put arbitrary YAML there. |
| `frontmatter.ts` -> `check-foundation-guards.ts` | The guards trust the parser's verdict completely; a silent no-grant is indistinguishable from a genuine no-grant at the guard's own boundary. |
| committed `.js` -> host machine | Hosts run the committed build with no toolchain; a `.js` that has drifted from its `.ts` is executed as-is. |
