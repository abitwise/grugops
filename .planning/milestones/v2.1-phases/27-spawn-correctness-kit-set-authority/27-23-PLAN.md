<objective>
Close WR-03, IN-01 and IN-02 — the generator's second frontmatter grammar, the freshness gate's leaked
temp mirror, and the two gates still wired at one end only.

WR-03 is this project's first named systemic failure class in the surface that matters most.
`frontmatter.ts` declares itself the single authority for what a file's frontmatter SAYS. The
generator, in the same diff's dependency graph, keeps its own: a key charset excluding digits and
hyphens, a `\s*` that accepts a colon with no space where the authority deliberately refuses, and a
duplicate key that silently keeps the LAST value where the authority retains all of them precisely
because discarding one is a bypass. Every divergence lands in a fail-closed branch today — which is
why the review rated it a warning — but this is the code path that composes the shipped `tools:` line,
the spawn grant itself, from a grammar nothing tests.

IN-01 leaks `<tmpdir>/grugops-adapters-fresh-*` on any uncaught throw, because `cleanup()` runs only
on the `die()` paths and the two tails while three `cpSync` calls and one `readFileSync` sit
unguarded.

IN-02 is pre-existing and the user has scoped it in: `check-kit-refs.js` and
`validate-agent-factory.js` run in CI solely as a side effect of their `.test.ts` files spawning them
inside the vitest step. That is the state `adapters-freshness` was in minus the missing test, and it
is one exclude pattern away from being un-gated.

Purpose: one grammar for one predicate, a gate that cleans up after itself, and both ends wired.
Output: the generator reading through the authority with byte-identical output, a cleanup registered
on exit, and two new CI steps.
</objective>
