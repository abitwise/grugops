## What is wrong, stated as one sentence

`stripComment` (`scripts/frontmatter.ts:650-679`) asks "may a node begin here?" and answers it from a
branch chain in which the entry separator and the explicit-key indicator are gated on `depth > 0`, and
the mapping separator is gated on `depth > 0` **and** a following whitespace. YAML gates none of those
three the way this chain does. The union of the chain's arms is therefore not the set of YAML's
node starts, which is the same sentence this phase has now written nine times about nine different
predicates.

## Why this is not a fifth arm

| the explicit-key indicator at depth 0 | a `depth > 0` condition REMOVED and replaced by the structural condition YAML actually states (line start) |
| the mapping separator at depth 0 | a `depth > 0` condition REMOVED; the separation condition YAML states (whitespace or end of line) is already there and is kept |

| compact nested sequence | the EXISTING item rule re-entered once per dash; the regex is byte-unchanged |

No spelling is enumerated. Three conditions leave, one fact arrives, and the fact is computed where it
is observable.
