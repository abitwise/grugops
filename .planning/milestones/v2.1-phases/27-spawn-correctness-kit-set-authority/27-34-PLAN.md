## Decisions this plan implements

- **D-40** — derive the plugin-form skill set and pin its relationship to the standalone tree. A byte-mirror
  assertion ALONE is not available: measured, the six command skills differ from their standalone twins by
  exactly the value of the `name` key, and `skills/grugops/SKILL.md` differs by 446 bytes because the
  standalone form legitimately carries a kit-root resolver block the plugin form does not need. So the set
  is derived AND the pair rule is asserted with that one file exempted by name. Reversibility: **costly** —
  the pair rule becomes the documented contract for how the two distribution forms relate, and changing it
  later means re-cutting the guard, the recorded exemption and the packaging documentation together.
- **D-41 item 4** — the name-floor message must not assert that a document carries no `name` key when the
  parse returned zero keys for the whole document. Reversibility: **reversible**.
