## The rule, stated once

```
legal enumeration character set = letters, digits, underscore, hyphen, period, comma, space
                                  (comma is the separator; the rest are name content)
LEGAL     = every character of the captured enumeration is in that set
REFUSE    = any other character, naming the first one and its code-point label
```

This is one predicate, stated positively, with a finite legal set. It **subsumes** both round-4 checks: an
opening parenthesis and both quote characters are outside the legal set, so the two enumerated checks are
deleted rather than kept beside it. It also subsumes every flow-collection delimiter, every YAML indicator,
and every character no finding has yet named — which is the whole point.

**False-red risk, and how it is bounded.** Every enumeration this repository ships is kebab-case role names
separated by comma-space, so the legal set costs nothing today. That must be *measured*, not asserted: the
control runs over every scoped grant in all 33 `SPAWN_GRANT_SCAN` members.

**Decision: `promote`.** D-47 item 2 is a promote, not an add-alongside. The general representation (a
finite legal character set, with everything outside it refused and named) is promoted, and the specific one
(two checks each naming a shape a prior finding happened to report) is **demoted and deleted**. The
allowlist is strictly broader than both, so keeping them would be a pair of predicates where one suffices —
and a pair whose union is assumed to be a complement is exactly the shape that produced this round's
blocking finding one function away in the same file.

**Rationale:** the two checks are a denylist that grows one reported spelling at a time. Round 4 added two
members; round-5 IN-04 reported a third class; a fourth is only ever a report away. Promoting to a stated
legal set closes every character no finding has yet named, which is what makes this the last round for this
predicate rather than the next one. The promote's cost is a false-red risk, and that is bounded by
measurement rather than by argument: every scoped grant in all 33 spawn-grant scan members must still return
its full name list, and a real refusal is raised as a finding rather than resolved by widening the set.

**One branch is deliberately NOT promoted and NOT deleted: the escape refusal beneath the split.** It
becomes unreachable through this function, because the allowlist excludes both quote characters and the
backslash. It is kept because it enforces D-32's allowlist decision at this call site and would become
reachable again the moment the check above is narrowed — and it is not an `add-alongside` second opinion,
because it cannot disagree with the check above, only follow it. That domination is required to be
**asserted by a case** against the allowlist constant rather than claimed in a comment, so the branch's
note is true rather than merely written; a comment claiming a property is not the property.
