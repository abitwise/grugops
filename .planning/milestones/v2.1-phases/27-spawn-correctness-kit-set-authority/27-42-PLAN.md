`scripts/check-foundation-guards.ts:1368-1392` computes `claimedKeys` as
`pluginForbiddenComponentKeys() ++ coveredKeys ++ exemptKeys`, and `pluginForbiddenComponentKeys()`
(`scripts/kit-model.ts:350-358`) is itself `schema \ (covered U exempt)`. So
`schemaKeys.filter(k => !claimedKeys.includes(k))` is **provably empty for every possible input to
today's code**. The `doubleClaimed` and `foreign` arms are genuinely falsifiable and do fail closed.

silently"*. That disclosure is correct and stays. What is missing is that the arm the disclosure defends
**cannot be exercised at all**, so nobody knows whether it would fire when the later hand-edit arrives.
A future-proofing arm nobody can test is a promise, not a floor.
