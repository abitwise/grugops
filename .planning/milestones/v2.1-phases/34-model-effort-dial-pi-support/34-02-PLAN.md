<objective>
Create the one registry of supported host tools (D-11) and wire installer detection to it, with Pi
as a registry row (D-10). This is the enabling change of the phase: every later consumer (the
asymmetric-table oracle, the validator, the doc tables, the prose scan, the Pi template write)
derives from this registry, so a stale "five" or a host missing from one list fails red.

Purpose: set-literal drift is this repository's second systemic failure class; the registry and its
asserted count must land before any Pi file does.

Output: install/host-tools.ts (pure data) and its test, and `detectTools()` plus the closing host
line in install/install.ts derived from it.

Spec-less probe fallback: no SPEC.md exists and no requirement IDs existed at plan start, so no
probe-derived edge predicates were generated; edge cases come from 34-CONTEXT.md D-10/D-11 and
34-RESEARCH.md § "Host-tool inventory" and § "Pattern R".
