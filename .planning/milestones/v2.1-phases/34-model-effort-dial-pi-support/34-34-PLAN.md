<objective>
Close WR-01 (D-27 point 3). The doctor called a carrier "install's own, stale" on owns alone and told the
user to re-run install.js. Install refreshes only when three more things hold: the record is not a link
record, the file is a regular file and not a link, and the kit's current text can be read. On a link the
remedy was false, and the FAIL could never clear. After this plan, one `refreshable` predicate owns those
conditions. Install refreshes only when it answers ok, and the doctor promises a refresh only when it
answers ok.

Purpose: the AUTH-1 class ("would install refresh carrier X" answered twice) and its VERDICT-1 effect (a
remedy the run did not earn). Output: refreshable, its three callers, the absent arm asking readForWrite, and
the install-agreement rows on links.
</objective>
