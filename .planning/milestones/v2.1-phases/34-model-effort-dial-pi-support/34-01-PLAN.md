repository's config is read by the one reader in `scripts/model-tiers.ts` (D-07), resolved by a new

refusal rule (D-02, D-03) with tests that cover the whole class, including the consumption probes
that catch the roles-absent early return (RESEARCH Pitfall 1, Pitfall 6).

config-key contract already decided by the human; this plan implements it exactly and does not
re-ask. D-08: no capability table. D-18: the reader's pre-existing unbounded read is disclosed, not
fixed.

unit-level tests.
