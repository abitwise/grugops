## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer to user repository | install writes under the user's target; anything already at `.pi/` is user content |
| uninstall to user repository | removal decisions cross from the ledger into user-owned paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-34-10 | Tampering / Denial of Service | a symlink, FIFO, device or directory at `.pi/prompts/grugops.md` | high | mitigate | `readForWrite` gate: `blocked` → counted verify, nothing written; exclusive `wx` create; special-file class test covers the path by derivation |
| T-34-11 | Tampering | overwriting a user's own Pi template | high | mitigate | `ok` → skipped; create-only; never-installed class test plants a user file at the path |
| T-34-12 | Tampering | uninstall deleting a user's Pi files or `.pi/` directory | high | mitigate | Removal only through the ledger walk and `owns(path)` with content match; dirs only if install created them and they are empty; user-edit class test |
| T-34-13 | Elevation of Privilege | prompt injection through the shipped template | medium | mitigate | Fixed literal pointer text; no config, argv or environment value reaches it |
| T-34-14 | Tampering | a DRY_RUN run writing | medium | mitigate | DRY_RUN return before the write; DRY_RUN case asserts no `.pi` created; fs census row names the caller |
| T-34-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed by this plan; the Pi CLI itself is never installed by grugops |
</threat_model>
