<objective>
Collapse the two governance config readers into one discriminated-result reader whose failure path is
fail-closed, delete the second authority rather than joining it with a third, and give `admit()` the
explicit degrade path that made the fail-open reader necessary in the first place.

Purpose: AUTO-06 is not a tidy-up. The fail-open reader exists because `admit()`'s zero-config
contract needed leniency; deleting it without giving `admit()` somewhere to land would turn a lean
default into a refusal. The degrade path is the substance; the deletion is the consequence.

Output: one exported reader, three moved call sites, an `admit()` that refuses and degrades instead
of throwing, and a scan-derived assertion on how many places in this tree read the config at all.
</objective>
