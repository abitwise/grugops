<objective>
Move test-integrity enforcement to its point of effect: `emitVerdict()` refuses to write a green
verdict unless it is handed a clean test-integrity result, and refuses fail-closed on anything it
does not recognize.

Purpose: the dial exists today only as a validated config enum that nothing consumes at the moment a
green verdict is written. Handing it an env var it cannot enforce would be a false equivalent. The
honest mechanism is a required argument at the one function that writes the note, with the argument's
tier stated rather than papered over.

Output: a three-state required parameter, a refuse-before-compose branch, the missing command-line
surface the gate workflow already describes, and a corrected sentence where that description was
false.
</objective>
