<objective>
Close gap 1 of `31-VERIFICATION.md` round 3 (CR-07 and WR-14 of `31-REVIEW.md`) — the THIRD recurrence
inside Phase 31 of "a predicate closed at the exact coordinates a verifier measured, reappearing one
register over".

`31-11` was right: it replaced the enumerable `BANNED_CONSTRUCTS` literal with the D-17 head/tail rule
and closed round 2's two spellings. The rule is sound over every shape it is asked about. But it is
only ever ASKED about a callee `calleeDottedPath` resolves, and that resolver returns null for any
chain containing a `CallExpression` link and does not canonicalise an `ImportSpecifier` rename before
the head segment is read. So five real evasions of the SAME D-14 arm (c) ban pass the committed `.js`
at `0 findings over 1/1 uat specs checked`, exit 0 — each independently reproduced by the round-3
verifier: `test.info().skip()`, `test.info().fail()`, `test.info().fixme(true, "later")`,
`expect.configure({ soft: true })(locator).toBeVisible()`, and
`import { test as it } from "@playwright/test"; it.skip(...)`.

The register D-17 fixed was MEMBERSHIP. The register that failed is SHAPE RESOLUTION: which call
expressions the membership rule is even asked about. This plan therefore does not add members. It
DECIDES the declining shapes, and then derives the set of shapes the resolver still declines so that a
fourth undisclosed shape cannot land silently — the same derive-the-set discipline `31-10` applied to
the writer and refusal-family axes, applied here to the resolver's own decline branches.

Purpose: UATX-06's whole content is "the recipe's claim matches exactly what the checker decides". A
runnable that silently declines a real Playwright spelling makes that claim false at a boundary nobody
wrote down — which is the defect class this requirement exists to prevent, and the defect the recipe's
"Deliberately outside the rule" list is supposed to make impossible to have unknowingly.

Output: a decided call-link path shape and a decided configured-soft rule (recorded as D-18, extending
D-14 arm (c) and D-17), an import-rename canonicalisation, three type-checked corpus fixtures, an
AST-derived decline-site set bound to residuals in both directions with a watched-fail mirror, an
`info` member on the declared surface with its partition dispositions, and a recipe whose boundary
prose and completeness paragraph state what the mechanism actually reaches.

**Ordering note:** this plan is wave 1 and `31-14` is wave 2 purely because both must append a dated
decision to `.planning/phases/31-autonomous-manual-testing/31-CONTEXT.md`; the two gaps are logically
independent and touch disjoint code (`scripts/runnable-ref/**` here, `scripts/context-io.ts` +
`scripts/compactor.ts` there).
</objective>
