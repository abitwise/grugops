<objective>
Close CR-05 / gap 1 of `31-VERIFICATION.md` round 2. The admission authority is reachable from
`appendNote` for exactly one kind. `admit()` decides four refusal families — D-01 (a `finding`
stamped `§14-gate#<id>` is admitted only against a live green verdict with that per-run id), D-03
(the artifact-ref binding), D-04 (a high-severity governance finding needs a named human
disposition) and D-14 (an unreadable governance config refuses) — and the branch 31-05 added reaches
only D-03. The verifier reproduced the consequence live against the committed `.js`: a `finding`
naming `verified_by: "§14-gate#fabricated-run-id"` was written through `appendNote` with no refusal,
and `render()` printed it into `index.md` indistinguishable from a genuinely admitted finding.

Purpose: this is the phase's central goal failing on the sibling kind gap 1 was closed for — an
agent's own claim about what it saw, wearing a gate stamp it never earned. It is also the fourth
time this phase has paid for the same failure shape: a predicate closed exactly where a verifier
measured it and nowhere else along the same family. So the fix removes the axis rather than widening
it. `appendNote` stops deciding which kinds admission applies to, because that question belongs to
`admit()` alone.

Output: a `scripts/context-io.ts` (and its committed `.js`) whose `appendNote` consults the single
authority for every note it writes; a named, bounded, module-private route for the two callers that
have already been adjudicated; one trusted answer to which root governs an admission; a measured and
dispositioned blast radius across every caller; and three workflow documents plus two appended
summary corrections that state what the mechanism now does.
</objective>
