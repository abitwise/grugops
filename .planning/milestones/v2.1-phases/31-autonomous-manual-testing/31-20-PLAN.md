<objective>
Close gap-closure round 5 by re-running the round-4 evidence against the finished tree, measuring the
whole repository green at one commit, writing the round's residual register, and dispositioning every
finding the round-3 code review raised.

This phase has now completed four verification rounds. In every one of them the green suite exercised
NONE of the defects that round found — the round-4 report says so explicitly, for the fourth consecutive
time. So the closing measurement of this round is deliberately structured the way the verifier's own is:
the ADVERSARIAL REPRODUCTIONS come first and are re-run with the exact probe spellings
`31-VERIFICATION.md` and `31-REVIEW.md` used, and the suite is recorded afterwards as a floor rather
than as proof. A closure round that re-measures only its own fixtures has measured its fix and not the
finding.

The round-4 report also recorded a false alarm of its own: a first full-suite run failed one case
because of leftover probe files under `.temp`, which `SKIPPED_DIRECTORIES` does not exclude. That
reconciliation is part of this plan's method rather than a footnote — the environment is proven clean
before the suite figures are taken.

Purpose: the next artifact this phase produces is a fifth verification round. Its verifier should be
able to start from a written register of what this round decided to leave open, a table pairing every
round-4 reproduction with its post-round result, and a ledger row for every finding — rather than
rediscovering them.

Output: a re-run of every round-4 reproduction with results paired to the originals; a one-commit
measurement of the whole suite and every repository gate; a re-measurement of the frozen floors; a
tracked residual register for the round; a disposition ledger covering every CR, WR and IN of
`31-REVIEW.md`; and the requirement rows left exactly as they are.

**Ordering note:** wave 5 and `depends_on: ["31-19"]`. This plan measures the finished tree, so it must
run after every plan that changes it. It modifies no source file — which is deliberate: a closure plan
that fixes something has found a new defect, and a new defect belongs in a new plan with its own
RED-first reproduction, not in the round's own closing measurement.
</objective>
