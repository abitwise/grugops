<assumption_delta_decision>
The `assumption-delta` detector fired on one `optional` signal: *"Claude in Chrome is available as an
optional, clearly-labelled `verified_by: <named human>` lane."* The question it asks is whether the
anchor has moved — whether an optional second lane means the identity model should name a more
general noun.

- **The noun that stays primary:** the committed `*.uat.spec.ts`, re-run by the §14 gate, as the ONE
  kind of UAT evidence. The `finding` + `artifact-ref` pair stamped by a gate run is the primary
  representation; a human-stamped note from the attended lane is a witness record, not a second
  evidence source.
- **Decision: `no-change`.** The two-stamp model (a gate stamp and a named-human stamp) is not new —
  it is the shared verified context's existing vocabulary, and the attended lane is an instance of
  the human stamp, not a new variant of the machine one. Promoting a general "evidence" noun over
  both would erase precisely the asymmetry UATX-03 exists to preserve: the human lane can never
  produce a machine stamp.
- **Companion invariant (accepted, implemented as Task 3):** the contract test that goes red the
  instant a future phase gives the attended lane a route to the machine stamp — the derived
  reserved-identity author set with its count asserted.
</assumption_delta_decision>
