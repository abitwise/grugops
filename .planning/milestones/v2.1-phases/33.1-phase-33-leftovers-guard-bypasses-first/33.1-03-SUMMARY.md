# Phase 33.1 Plan 03: Claude Code ask rules from the checkpoints config Summary

**The installer now writes 55 derived Claude Code `permissions.ask` rules (git push, gh pr merge, the deploy and publish tools) into the target's `.claude/settings.json` under a carried-forward provenance ledger that uninstall reverses exactly, and a committed zero-token harness shows the installed `git push` rule denying in all six `claude -p` configurations while the config-off control pushes.**

## Accomplishments

- `install/checkpoint-ask-rules.ts`: a pure sibling module (no imports) holding the rule table transcribed from the retired `COMMAND_CHECKPOINT_RULES`, minus `benign`, verb-prefix resolution and the git local ref-write verb (D-29). Forms A/B/C per verb plus the vercel `--prod` flag form give 55 rules; the count is derived and pinned.
- `writeAskRules()` in `install/install.ts`: reads `.grugops/factory.config.json`, else `agent-factory/config/factory.config.json`; fails closed (absent, unparseable, non-object, any value other than an exact `notify`/`off` writes the rules); appends only missing rules and keeps every other key and its order; leaves an unparseable or wrongly typed file byte-identical with a `verify` finding (exit 3); DRY_RUN writes nothing.
- The `claudeAskRules` ledger `{added, createdFile, createdPermissions, createdAsk}` is computed as (previous ∩ present) ∪ added-now and written by `writeMarker()` after `installMode`, so a second install cannot orphan the rules.
- `removeAskRules()` in `install/uninstall.ts` runs before `removeMarker()`, removes exactly ledger ∩ present, drops a container only when install created it and it is empty again, reports the user's own identical rule as left, and writes nothing when nothing changes.
- `--check` reports each ledger rule present or absent (WARN on absent) and never repairs.
- Installer safety prose now states the three tiers: git host is the hard floor, the ask rules are a speed bump and not a security boundary, the plugin form carries none, the other four CLIs get documentation only.
- D-20 part (d) evidence committed with a re-runnable harness.
