<objective>
Close the non-bypassability items of CR-01 (33.1-VERIFICATION.md gap 1: "Read enforce_admins.enabled on the
classic arm", "Consult ruleset bypass actors before calling a pull_request rule protective") on BOTH branch
arms, inside the canonical table plan 33.1-17 built (D-19). Round 1 of the 4-round cap (D-06).

The floor is meant to hold against the account the agent works under, which on most repositories is the
human's own token. A requirement that account can bypass protects nothing against it. So a ruleset rule
counts only when its ruleset reports `current_user_can_bypass: "never"` for that account, and classic
protection counts only when it applies to administrators and grants no pull-request bypass allowance. This
is added as a qualifier row of the canonical table and as the matching line of the one published checklist
in install/README.md §5, so code and docs change together.

Purpose: `protected` stops being reachable through a rule the checked account can bypass.
Output: bypass readings on both arms, union-matrix and mutation cases, the README line, the COVERAGE row.
</objective>
