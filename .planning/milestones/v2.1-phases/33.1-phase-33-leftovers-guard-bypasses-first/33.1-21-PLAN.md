<objective>
Close the ownership half of CR-02 (33.1-VERIFICATION.md gap 2: "Track which directories install created
(ownership), so an empty pre-existing user directory (e.g. .github/, .gemini/) is never removed"), so the
installer contract (D-18: never delete user content, reversible) and D-20's reversibility proof bar hold
end to end. Round 1 of the 4-round cap (D-06).

The ledger this needs is a new field in `.grugops/install.json`, next to the ask-rule ledger. WR-05 showed
that the two binaries already disagree about a malformed ask-rule ledger (install fails open, uninstall
fails closed) because each holds its own reader. A second ledger with two readers would repeat that. So the
fix is structural: one shared module reads the marker and both ledgers as tri-states for both binaries,
which closes WR-05 on the same code path at almost no extra cost. IN-02 (uninstall removes a user's later
duplicate of a grugops rule) is the same "never delete user content" truth on the same function and is
folded in.

Namespace rule: a directory whose own name begins with `grugops` is grugops-owned by name, so installs made
before this ledger existed still clean up their own skill directories and `tools/grugops/`. Shared-name
directories (`.claude/`, `.claude/skills/`, `.claude/agents/`, `.gemini/`, `.github/`) need ledger evidence.

Purpose: an uninstall, real or previewed, never removes a directory the user made.
Output: install/install-marker.ts, the `createdDirs` ledger, the ownership gate, WR-05 and IN-02 fixes, the
README and CHANGELOG updates, and the deferred-findings ledger rows.
</objective>
