## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical functionality] The census's loader refusal was narrower than its purpose**
- **Found during:** Task 3, while probing the census beyond the four required demonstrations.
- **Issue:** As first written, the check refused only a direct CALL whose callee was named `require` or `createRequire`. Storing the loader first, as in `const r = x.require; r("node:fs")`, passed at 6/6 green. `process.getBuiltinModule` (Node 22.3+) was not covered at all.
- **Fix:** The census now refuses any identifier named `require`, `createRequire` or `getBuiltinModule`, whether called, stored or reached as a property. It also refuses any fs module name as a string literal outside an import declaration's specifier. Both probes are now red, and the committed tree stays green.
- **Files modified:** install/installer-fs-census.test.ts
- **Commit:** 57bf0def

**2. [Rule 2 - Missing critical functionality] The plan's two subset cases are vacuous on an installed tree**
- **Found during:** Task 2
- **Issue:** I measured that after a real install, the preview names no `would-rmdir` path on flow 7's or flow 8's tree, because every directory uninstall visits still holds a grugops file. The subset comparison therefore always checks an empty set. The copy-based design also meant a preview that deleted directories would not have failed it.
- **Fix:** The subset helper now also asserts that the preview left both roots snapshot-identical. I added a third, non-vacuous subset case on an installed tree whose `.github/` the user has since emptied: the preview names `/.github` and the real run must remove it. That case goes red against the pre-fix binary. The vacuity is stated in a comment above the helper.
- **Files modified:** install/installer-dry-run.test.ts
- **Commit:** c4142bc2

**3. [Process] Task 1 used two commits instead of one**
- The RED test was committed first (648b65f9), then the fix, the twin and the README (f09f6c6e). This follows the TDD reference's RED-commit rule. The acceptance criterion that the source and twin land in one commit is still met by f09f6c6e.
