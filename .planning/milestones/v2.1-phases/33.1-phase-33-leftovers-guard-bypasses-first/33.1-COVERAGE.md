# Phase 33.1 — API coverage matrix

The phase's only external API use is the read-only GitHub REST check in
`scripts/runnable-ref/host-protection.ts` (D-19), reached through `gh api --method GET -i`. grugops never
configures the git host (D-19), so every write capability is an explicit opt-out. Since plan 33.1-41
(D-31 Q4) the check reads only what the branch checklist needs: the repository answer, the ruleset
rule list and rulesets, and classic branch protection with its branch answer. It does not read the
production environment or the protected-branch list. The zero-token harnesses talk to a local mock on
127.0.0.1, not to a model API.

| capability | decision | reason |
|---|---|---|
| GET repos/{owner}/{repo} (default branch) | INTEGRATE | host check reads the default branch name, read-only |
| GET repos/{owner}/{repo}/rules/branches/{branch} | INTEGRATE | ruleset evidence: pull_request (approval count, dismiss_stale_reviews_on_push, require_last_push_approval), non_fast_forward, deletion, each rule's ruleset_id; no admin needed |
| GET repos/{owner}/{repo}/rulesets/{ruleset_id} | INTEGRATE | reads current_user_can_bypass so a rule this account can bypass never counts; 200 without admin (measured 2026-09-28); id must be a safe positive integer |
| GET repos/{owner}/{repo}/branches/{branch} | INTEGRATE | classic protected flag, used only to classify a Not Found protection read |
| GET repos/{owner}/{repo}/branches/{branch}/protection | INTEGRATE | classic detail: enforce_admins, approval count, dismiss_stale_reviews, require_last_push_approval, bypass allowances (counted, not named), force push, deletion; 404s fail closed |
| GET repos/{owner}/{repo}/branches?protected=true&per_page=1 | OPT-OUT | not read: the production environment is UNKNOWN - verify by design (D-31 Q4) |
| GET repos/{owner}/{repo}/environments | OPT-OUT | not read: the production environment is UNKNOWN - verify by design (D-31 Q4) |
| gh auth status | INTEGRATE | read-only precondition; failure maps every branch to UNKNOWN - verify |
| PUT/PATCH/DELETE branch protection | OPT-OUT | D-19: grugops never configures the host; the check is read-only by construction |
| POST/PUT/DELETE repository rulesets | OPT-OUT | D-19: never writes host configuration |
| PUT/DELETE deployment environments | OPT-OUT | D-19: never writes host configuration |
| GitHub GraphQL API | OPT-OUT | not needed; the REST GETs above decide all three verdicts |
| Anthropic Messages API from the harnesses | OPT-OUT | harnesses use a local 127.0.0.1 mock (zero tokens); the one live call is the D-10 capture via the claude CLI |
