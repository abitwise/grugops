<objective>
Create the config dial: `agent-factory/config/factory.config.json` populated with the spec §15 lean default field set and values, plus its human-readable twin `agent-factory/config/factory.config.md`. Purpose: Freeze the config field names every later role and workflow cites by name, with the visible, editable lean baseline.
Output: `factory.config.json` (populated) + `factory.config.md` (field table + zero-config defaults).
</objective>
