| installer → frozen core + user data | agent-factory/, plans/, .planning/, docs/, user files must never be modified or deleted |
| installer → approval secret | The installer must never set the deploy-approval env var (only a human may) |
| docs → safety guarantee scope | README must not overstate the guard's reach (Claude-only) — honesty about the 4-tool fallback |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-05-Tamper-1 | Tampering / DoS | installer clobbers a user's CLAUDE.md / settings / secrets file | mitigate | Additive ensure-line + read-modify-write JSON; never `>`; DRY_RUN; double-install-diff test asserts zero diff |
| T-05-05-Tamper-2 | Tampering | uninstall deletes the frozen core or user files | mitigate | uninstall removes only installer-added artifacts; explicit guard on agent-factory/ / plans/ / user paths; cleanliness test asserts agent-factory/ survives |
| T-05-05-EoP-1 | Elevation of Privilege | installer sets the deploy-approval env var (auto-approving deploys) | mitigate | Installer never writes GRUGOPS_PROD_DEPLOY_APPROVED; grep asserts absence |
