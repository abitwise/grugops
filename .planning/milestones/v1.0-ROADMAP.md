# Milestone v1.0: MVP — Full Agent Factory v2

**Status:** ✅ SHIPPED 2026-06-04 (archived retroactively at v1.1 close, 2026-06-08)
**Phases:** 1–6
**Total Plans:** 34

## Overview

v1.0 built the complete Agent Factory v2 spec — core roles + enterprise pack + plugin distribution — plus brand/legal collateral, validated by an end-to-end dogfood run. Built bottom-up as a file protocol (not a runtime): freeze the shared vocabulary every later file cites by name (config fields, board columns, stable IDs) and lay the empty state plane (Phase 1) → the shared I/O contracts: handoff templates, checklists, memory-bank seed (Phase 2) → all 16 role prompts, Orchestrator first, plus the minimal AGENTS.md substrate (Phase 3) → the workflows that compose roles into the full lifecycle, dual cadence, and the bounded backpressure quality gate (Phase 4) → the thin per-tool adapters, both Claude distribution forms, idempotent installers, and the mechanical prod-deploy hook (Phase 5) → the validator, examples, brand/legal collateral, and a real idea→PR dogfood across both dispatch paths (Phase 6). Each phase's outputs are the next phase's inputs.

## Milestone Summary

**Decimal Phases:** None — v1.0 ran phases 1–6 in straight integer order.

**Key Decisions:**

- Build the **full v2 spec** (core + enterprise pack + plugin) this milestone, not lean-first.
- Ship **both** Claude distribution forms — standalone `.claude/` (literal `/grug…`) AND the versioned plugin + marketplace.
- Enforce prod-safety **mechanically** via a plugin-level PreToolUse hook, not subagent frontmatter (which plugin subagents silently ignore).
- Phase order follows the research dependency chain — config/IDs/board → contracts → roles → workflows → packaging → validation/dogfood; never place a consumer before its dependency.
- **D-28:** version string `0.1.0` (brand-new public tool), VERSION + plugin.json synced-bump.
- **D-29:** `skills/` over `commands/` for the plugin; standalone `.claude/` for the literal `/grug`.
- Markdown-only kit; no runtime, DB, or queue — intelligence lives in the host agent.
- Memory-bank is the minimal agent-maintained state/plans store (same anti-bloat rule as AGENTS.md).
- AGENTS.md embeds Karpathy's 12 coding-agent rules as default behavioral guardrails.
- **[Phase 2]** Handoff duplicate-header collision (`## Scope`/`## Risks`) resolved: universal-header sections are authoritative; the two spec-verbatim §5.A bodies are tolerated. ✓ Resolved.

**Issues Resolved:**

- §5 `plans/`-prefix drift in role handoff paths (ba-pm/system-analyst) corrected to real `agent-factory/handoffs/` paths.
- Phase-5 code review: 1 BLOCKER (uninstall deleting a user-owned `AGENTS.md` symlink) + 6 warnings — all fixed and re-proven.
- Phase-6 code review: 1 Critical (`JSON.parse(null)` crash on unreadable `plugin.json`) + 4 warnings — all fixed and re-proven.

**Issues Deferred:**

- **DOG-02 live-Claude-Code half** — plugin-cache pointer resolution (D-31), live SAFE-02 hook firing, CC sub-agent spawn + dual-path parity. Genuinely not agent-runnable; deferred to milestone-close UAT. Tracked in `06-HUMAN-UAT.md` / `05-HUMAN-UAT.md`. Carried forward at v1.1 close (see STATE.md Deferred Items).

**Technical Debt Incurred:**

- The in-repo install assumption (adapters referencing `agent-factory/…` repo-relative, but the kit never installed into the target) surfaced as the central dogfood pain — became the entire v1.1 milestone (shared-location install).
- Several phase SUMMARY one-liners left empty (hygiene gap, not a coverage gap).
