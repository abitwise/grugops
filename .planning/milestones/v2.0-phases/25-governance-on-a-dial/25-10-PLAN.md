<objective>
Build the un-forgeable GOV-01 gate on the structured channel (D-01). Retarget hooks/admission-guard
from a Bash command-string matcher to a PER-CALL structured PreToolUse matcher on the mcp__grugops__.*
family, DELETE the entire command-string parser (the 10-round liveTokens machinery), and decide
admission from the FINAL structured tool_input plus the FRESH per-call session env. The hook runs fresh
per call (confirmed CC capability) and reads the CURRENT session env — so the disposition is PER NOTE
(D-07), not a frozen-at-launch session blanket. Because tool_input is delivered final (no shell
expansion), the whole shell-obfuscation bypass family (glob, brace, param/command substitution,
word-split, extglob `(`-fragmentation, launcher rename) is gone by construction.

For a GATED note the hook DENIES unless BOTH the fresh env GRUGOPS_ADMISSION_APPROVED_BY=<name> is
present AND tool_input.verified_by === `human:${name}` — binding the agent-supplied stamp to the
env-verified approver per call, un-forgeably (the agent cannot set the hook's session env). The severity
classifier is the IMPORTED single-source isHighSeverityRole (25-09) — the hook defines none (round-8
anti-drift).

Purpose: make the SANCTIONED admission channel mechanically un-forgeable on Claude Code PER NOTE while
carrying forward every SC3 fix from rounds 1-5 (off-only-is-off canonicalization, corrupt-config
fail-closed) and keeping the gate OUTSIDE the agent process (D-01, D-05). Output: the retargeted hook +
committed .js, the hooks.json matcher swap, a both-direction RED->GREEN proof vs the committed artifact,
and the SC3 floor-invariance sweep on the structured channel.

The D-04 in-script admit() refusal + its frozen classifier stay the documented WEAKER degrade tier for
the four non-CC CLIs (D-04/D-05) — unchanged; context-io's existing surface stays byte-frozen this plan
(the new isHighSeverityRole + admitAndAppend exports were added in 25-09).
