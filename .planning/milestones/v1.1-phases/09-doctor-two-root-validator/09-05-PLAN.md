<objective>
Close the two doctor-parity blockers (CR-01, CR-02) so the sh doctor agrees byte-for-byte with the Node doctor (install.mjs — the parity ORACLE) on both the exit code and the first-failure line, for the two inputs the committed suite never exercised: a non-normalized GRUGOPS_HOME (trailing slash) under --strict, and a present-but-garbled install marker.

GAP 1 (CR-01): `resolve_grugops_home` in install.sh uses `abspath()`, which does NOT strip trailing slashes, so `KIT_ROOT="$GRUGOPS_HOME/agent-factory"` becomes `…//agent-factory` (double slash). The Node installer wrote the marker/adapter with a single slash (Node's `resolve()` normalizes), so the sh doctor's source (a) ≠ the recorded marker/adapter → a spurious cosmetic WARN → under --strict, exit 1. Node's doctor sees them agree → exit 0. Same install, same flag, two exit codes. Fix: make `resolve_grugops_home` normalize GRUGOPS_HOME the same way Node `resolve()` does — a LEXICAL slash-collapse (NOT `cd && pwd`, which fails on a not-yet-existent GRUGOPS_HOME) that drops trailing slashes and collapses repeated slashes.

GAP 2 (CR-02): the sh doctor's not-installed gate only tests `[ ! -f "$_marker" ]`, so a present-but-unparseable `.grugops/install.json` slips past, `read_marker_field` returns empty, and the D-03 cross-check fires "kit-root sources DISAGREE … marker=<unset>". The Node doctor's `readMarker()` (try/catch JSON.parse) returns null for the same garbled file → `notInstalled()` → "grugops not installed in <target> …". Both exit 1, but the first-failure LINES differ. Fix: after the `[ ! -f ]` check, add a marker-extractability gate — if `kitRoot` cannot be read from the marker, fold into the SAME not-installed FAIL (byte-identical message + flow) the Node doctor emits.

Purpose: the central phase contract is "sh and Node doctors agree byte-for-byte on exit code and first-failure line." These two fixes bring the sh side INTO agreement with Node's already-correct behavior. install.mjs is the ORACLE — do NOT change its exit codes or wording.
Output: a normalized `resolve_grugops_home`, a fail-closed marker gate in `doctor()`, and two new install.test.sh parity checks that fail before the fix and pass after.
</objective>
