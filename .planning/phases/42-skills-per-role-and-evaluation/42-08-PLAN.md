**Claude Code plugin skills (42-RESEARCH § "Claude Code plugin-skill resolution").** Plugins root = `CLAUDE_CODE_PLUGIN_CACHE_DIR` when
set, else `<home>/.claude/plugins`. Read `<root>/installed_plugins.json` through `readUserFile`. An absent file means no plugin is
installed. Any other non-`ok` state, a JSON parse error, or a shape other than an object whose `plugins` is an object of arrays of
objects each with a string `installPath` makes plugin skills `not checked` for the run, with the reason. For each `installPath`, look in
`<installPath>/skills/` and in each path of the `skills` field (a string or an array of strings) of `<installPath>/.claude-plugin/plugin.json`,
read through `readUserFile`. A manifest path that is absolute, or has a `..` segment, or resolves outside `installPath`, is refused:
plugin skills become `not checked`, naming the plugin key. Other plugin forms, `enabledPlugins`, and `synced/` plugins are not checked;
found on disk is not the same as enabled in a session.

**Found** means `<folder>/<skill>/SKILL.md` is a regular file when the path is followed (`statSync(..., { throwIfNoEntry: false })?.isFile()`).
No file content is read for a presence check.

**Line wording this plan adds (keep to one line each; 42-02 already prints the missing, found and reader-failed lines):**
- missing on a host whose plugins entry is `unknown`: the 42-02 missing line, `skill <name> (<role>, <role>) not found for <host name>; optional, see docs/skills.md`, plus ` (plugin installs on <host name> are not checked: UNKNOWN - verify)`.
- not checked: `skill <name> (<roles>) not checked for <host name>: <reason>; optional, see docs/skills.md`.
- reader refusal: `declared skills of <role> not read: <reason> (the role-frontmatter guard reports this)`.
- Every line uses the `advisory` label, except a found skill, which uses `ok`. Print only through `docReport` (D-25). Printed strings
  carry no planning ID (install/message-references.test.ts refuses them), and the host is printed by its registry `name`.

**Line choice, per declared skill (in the reader's order) and per host in `hosts`, first match wins:** found in a project folder, a user
folder or the host's plugin lookup → `ok`; a `userOverrides` variable of that host is set → `not checked`, naming the variable; the
host's plugins entry is `claude-installed-plugins` and the lookup is `not checked` → `not checked` with its reason; otherwise the missing
line, with the plugin clause when the entry is `unknown`.

| T-42-04 | Denial of service | `installed_plugins.json`, `plugin.json` reads | medium | mitigate | Every content read goes through `readUserFile` (bounded size; symbolic links, FIFOs and special files refused); an unknown shape is `not checked`, never "not found" |
