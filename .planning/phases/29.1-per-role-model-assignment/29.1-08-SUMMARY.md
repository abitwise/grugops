  saying which mutation moves it and which does not.

- **Commit:** `cd07484`

**2. [Rule 2 — missing critical correctness in a safety surface] The refusal clause did not agree in
number with its list**

- **Found during:** Task 1, reading the multi-key post-fix transcript.
- **Issue:** the first implementation produced ``sets `models.presets`, `models.rolez`, which is not

  the single-key case requires `which is not a key of` and the multi-key case requires

- **Files:** `scripts/model-tiers.ts`, `scripts/model-tiers.test.ts`

**3. [Rule 2 — coverage the plan named but did not enumerate as a case] `MODELS_KEYS`'s own shape**

  nothing about membership. A tuple with a typo'd or duplicated member would satisfy that grep.
- **Fix:** added a case asserting the tuple's exact sorted membership and that its member count
  equals its `Set` size — the "derive the set, assert the count" discipline this repository records,

- **Files:** `scripts/model-tiers.test.ts`
- **Commit:** `cd07484`
