<objective>
Make "refused fail-closed" true of the whole `models` config surface rather than of part of
it, and make the resolver's own preset floor hold in the direction its docstring promises.

Two findings, one module, one concern: a validator that publishes a guarantee wider than its
mechanism.

WR-01. `readModelsBlock` reads `models.preset` and `models.roles` and never enumerates the
block's own keys. The verifier reproduced four shapes against the committed `.js`, all
silently accepted. The worst is not the typo — it is
`{"models":{"preset":"tiered","role":{"orchestrator":"opus"}}}`, where the preset APPLIES and
the overrides silently do not. The user gets a partially wrong tier map, a green run, and no
message of any kind. That is verbatim what this module's own `unassigned` refusal calls "a
tier the user believes they set and did not" — the principle D-06 states and enforces one
level down inside `models.roles`, and does not enforce for the block that contains it.

WR-02. `const preset: PresetName = options?.preset ?? "none";` runs the coalesce before
`isPresetName`, so `null` and `undefined` are both coerced past Floor 0. The docstring
directly above claims the resolver "validates it by exact equality anyway — a JS caller can
hand over anything". It does not. This is latent today because `readModelsConfig` cannot emit
a null preset, but the tooling layer ships as committed `.js` with no type checking on hosts,
which is the docstring's own stated reason for existing. The code is fixed rather than the
docstring deleted, for that reason.

**What this plan will NOT claim.** The configuration file's own top-level key set is
legitimately open — the same file carries the governance, quality and compaction dials — so
`{"model":{"preset":"tiered"}}`, singular, cannot be refused by a closed-set mechanism without
refusing valid dials. It stays the zero-config answer. That boundary is disclosed in source,
pinned by a case, and written into `factory.config.md`, because a documentation line that says
"unknown keys are refused" while one level of the surface is open is the exact defect this
round exists to close.

Output: a `models` block whose key set is closed by name, a preset floor that validates before
it defaults, and a shipped sentence that states precisely which surface is closed.
</objective>
