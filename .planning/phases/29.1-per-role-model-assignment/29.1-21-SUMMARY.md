### The authority, and it is total

```ts
function quoteValue(value: unknown): string {
  let rendered: string | undefined;
  try {
    rendered = JSON.stringify(value);
  } catch {
    return `<${describeShape(value)} that cannot be serialised>`;
  }
  return String(rendered);
}
```

**The docstring above it already claimed this behaviour** — "A value quoted back to the user exactly
as they typed it, **including a non-JSON-serialisable one**". That claim was FALSE before this change
and is TRUE after. It is the same class as the four docstring findings this round raised, and it is
recorded here rather than quietly repaired, because the module's own posture is that a published
claim wider than its mechanism IS the defect.

**Why the render is assigned to a local rather than returned from inside the `try`.** The acceptance
criterion is that the composed spelling `String(JSON.stringify(` appears nowhere in the
comment-stripped source. Written the review's way, the authority would have satisfied that scan
itself, and a predicate its own subject satisfies is not a predicate. The `try` also stays around the
single expression that can actually throw.

**Why the catch is unconditional rather than `instanceof TypeError`.** A getter that throws
mid-serialisation surfaces its OWN error, which need not be a `TypeError` — the shape corpus below
carries exactly that case.
