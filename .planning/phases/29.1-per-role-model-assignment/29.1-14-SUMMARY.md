1. **R2-WR-02 closed on the right bound.** `ubuntuBlock()` finds the step name, takes the remainder,
   finds the NEXT `"\n      - name: "` in that remainder, and ends the block there — falling back to
   end of file only when no next marker exists. `(r-bound)` then asserts the sliced block contains no
   occurrence of the marker, so "this block happens to be last today" became an asserted property

## Part 3 — the shared-helper disposition, and why

**`ubuntuBlock` is NOT shared between the two files.** The two available ways to share it were both
worse than writing the slice twice:

- **Copy the helper into the sibling.** Two authorities over one predicate — the shape this round is
  deleting elsewhere in the same phase.
- **Promote it into a production module that only tests consume.** A shipped surface added for a
  test, which is the same trade in the other direction.

So each file bounds its own slice, and the CLASS is closed by `(r-class)` instead: one assertion is
the authority over whether every reader is bounded, even though the slicing is written twice. The
bound is required in a single canonical source spelling, so the two implementations cannot drift into
"equivalent but differently written" without going red. The disposition and its reasoning are
recorded in BOTH case bodies, as the plan required.
