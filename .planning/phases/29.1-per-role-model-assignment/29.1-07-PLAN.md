<objective>
Close the D-04 zero-config pin so that it describes the resolution the run performed rather
than one of the resolution's two inputs.

This is CR-01, the round's only critical finding, plus the two warnings that are load-bearing
parts of the same mechanism (WR-03, WR-04) and the discrimination case the original plan
never wrote.

The defect is structural, not a typo. `resolveModels` takes a preset AND a sparse overrides
map. `generate-role-adapters.ts:543` announces `resolvedPresetLine(modelsConfig.preset)` —
half the input. The verifier performed the exact edit plan 29.1-03's must-have promised to
survive: added `agent-factory/config` to the freshness twin list, planted
`{"models":{"roles":{"orchestrator":"opus","security-nfr":"opus"}}}`, regenerated, and
watched `adapters-freshness.js` print the zero-config answer and exit 0 while two committed
adapters carried `model: opus` and `guard_model_assignment` passed green alongside it. Per
D-04 the committed adapters are the ZERO-CONFIG output, and every gate was green while that
was false.

Two further defects sit inside the same grammar. `resolvedPresetsIn` matches the marker
anywhere in a line, so `'WARN could not read resolved model preset: none'` satisfies the pin
(WR-03). And `adapters-freshness.ts:354` hand-spells a marker whose own declaration at
`model-tiers.ts:213-222` states that neither site spells it — this repository's named second
systemic failure class, committed inside the fix for its first, and load-bearing because the
freshness oracle's success cases parse that hand-written literal rather than the generator's
announcement (WR-04).

**A deliberate, recorded coupling.** Anchoring the reader requires the emitter to own the
full prefix, which moves both call sites in the same edit. The three tasks below therefore
land one grammar across three files, and the full regression suite is green only at the END
of task 3. Tasks 1 and 2 verify against their own scoped oracles plus typecheck and build.
Splitting this across plans would leave a half-wired grammar on the tree, which is precisely
the state this repository's one-authority rule exists to prevent.

Output: an announcement that describes the resolution, a reader that cannot be satisfied by
an incidental mention, one authority for both line grammars, and a mirror-planted `roles`
block that turns the gate red.
</objective>
