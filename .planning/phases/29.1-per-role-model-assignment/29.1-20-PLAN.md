<objective>
Close the round's pointer gap and its last unfalsifiable assertion.

Plan 29.1-16 rewrote the packaging authority's `model` bullet to defer the whole-file precedence rule
to a named section of the configuration field reference — "the single authority for the rule and the
only place this kit states it". The round-3 verifier measured what happens when that section is
renamed: `npx vitest run scripts/model-dial-consistency.test.ts` stays at **33 passed (33)**. The
oracle pins the pointer's PATH and a different section name; nothing asserts that the section this
sentence sends every reader to exists. A pointer to a fact that is not there is the defect class this
module's own prose names, and the only pointer to the precedence rule in the shipped kit is the one
that is unpinned.

**One measurement decides the shape of the fix, and it is not in either round-3 report.** The
authority spells the citation without the inline code delimiters the heading itself carries — the
cited document's heading wraps the field name in backticks and the citing sentence does not. A
byte-equality predicate would therefore be RED on a correct tree. So the fix is a **declared canonical
form** — the citable form of a heading — applied by one function to both sides, with a collision
floor asserting that the form cannot merge two distinct sections. That is the shape this repository
ratified for exactly this problem: define what a value may BE, once, and compare against it.

The same plan closes the third and last instance of the round's "a proof that cannot fail" class.
Two containment assertions over the model-bullet region are guaranteed by the reader's own
`slice(0, Math.min(...ends))` and can never fire. The region reader's THROW paths are genuinely
proven and are not in question; only those two lines are dead weight. They are deleted, and the
bound gets a case that can see it.

Output: a cross-document citation that cannot be orphaned by a rename, a canonical form declared
once with a collision floor under it, and a region bound proven on text that can defeat it.
</objective>
