<objective>
Close the two round-3 blockers. Both live in one function of one file, and both are the same
sentence said twice: **count the unit you claim, and say what a name may BE.**

Plan 29.1-17 admitted `agent-factory/config` into `check-kit-refs`'s twenty-two-phase-old
zero-tolerance scan and wrote an exemption for the two self-references the shipped configuration
reference owes its reader. The exemption is bypassable on two independent axes, both reproduced by
the round-3 verifier and by the round-3 reviewer against the committed `.js` on hermetic mirrors:

**R3-CR-01 — the exemption is asked once per LINE.** `grepSubstring` emits one hit per line, the
exemption pushes one `exempt` entry per hit, and the cardinality assertion compares that entry count
against a constant whose own comment calls it a count of *mentions*. So an already-exempt line
absorbs unbounded further mentions without the predicate ever being asked about them. The declared
number has never described this tree: `grep -o 'agent-factory/config/' agent-factory/config/factory.config.md | wc -l`
measures **3**, on **2** lines. The gate prints `exactly 2 hit(s) in 1 file(s), as declared` at exit
0 while the document carries the literal instruction D-08.1 exists to forbid.

**R3-CR-02 — `.` and `..` pass the self-reference predicate.** The capture class `[A-Za-z0-9._-]+`
admits both, and the resolution test is a bare `existsSync`, which is true for a directory. So
`agent-factory/config/..` captures `..`, resolves to `agent-factory/`, and is certified as a
reference to a file inside the configuration directory. The documented predicate is false on both
halves, and the same hole makes a future `agent-factory/config/<subdir>/` wholesale exemptable.

This plan applies the project's terminal lesson in its stated form: **the structural fix, not another
heuristic.** The mention count is derived from the same extraction the predicate already runs. The
self-reference test becomes membership in a set derived from what the directory actually carries —
an allow-list of what a basename may BE — replacing a character class plus an existence probe.

Output: an exemption that counts mentions, admits only real sibling files, publishes all three of its
numbers in its own verdict, and carries a case for every bypass this round reproduced.
</objective>

this checkpoint exists to catch.

**The companion invariant test the checkpoint suggests, accepted:** the mention cardinality is
asserted two-sided, so a future change that reintroduces the line-granularity answer is red in both
directions rather than only when a mention is added.
