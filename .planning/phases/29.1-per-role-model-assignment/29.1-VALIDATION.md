## Sampling Rate

- **After every task commit:** `npx vitest run scripts/<changed>.test.ts` + `npm run build` + `npm run typecheck`
- **After every plan wave:** `npx vitest run --exclude '**/scripts/e2e/**'` + `npm run freshness` + `npm run freshness:adapters` + `node scripts/check-foundation-guards.js`

## House Standard (restated — this project's record depends on it)

**A green suite is not proof of a safety invariant.** Every requirement below names
three things: the **mechanical decider**, **what makes its verdict FALSE**, and the
**planted mutation that must turn it RED by name**. Where the decider and the thing
decided share a derivation, that is the CR-01 shape and a second, independent
opinion is named.

## Open Questions Affecting This Strategy

Three findings where a **locked CONTEXT.md decision meets a tree fact it did not
have**. None is re-opened unilaterally — each is the user's call, and each changes
what gets validated:

1. **D-12 names `scripts/frontmatter.ts` as "the one authority" — for adapters, the tree's authority is `scripts/canonical-frontmatter.ts`.** Plan 27-65 cut `guardReferentialIntegrity` over to `admit()`, whose header states of `frontmatter.ts`: *"this module is the new safety authority and must not inherit the eleven-round parser's reach."* Following D-12's letter puts the weaker reader on a **new** safety surface. `admit()` already carries `model` in its 10-key `CANONICAL_SCHEMA` and admits all four aliases unchanged.
2. **MODEL-07 has no mechanical decider** — see the MODEL-07 row. Position (a) or (b) must be chosen before the honesty-floor task is planned.
3. **D-01 reverses `install/`'s explicit D-18/D-28 decoupling from `scripts/`** (`install/kit-source.ts:29`: *"This module deliberately does NOT import scripts/kit-model.ts"*), and hits an ordering problem — the adapter loop is at line 1468, `seedState()` (which creates the target config) at 1555. The researcher recommends **splitting the phase**: MODEL-01..05 are provable with no install change; the install delivery path carries all three premise conflicts.
