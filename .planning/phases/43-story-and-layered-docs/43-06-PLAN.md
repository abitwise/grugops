## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| grugops checkout → user's kit home | Files copied onto the user's machine |
| user's existing kit-home content → installer | Content install did not write may already be at the new entry paths |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-43-18 | Tampering | a user's own `$GRUGOPS_HOME/docs` overwritten | high | mitigate | The record decides the arm: anything install did not record is renamed to a recorded backup, never overwritten; never-clobber on an existing backup name |
| T-43-19 | Information disclosure | checkout-only records shipped to users | medium | mitigate | Staging copies only shippedDocs() paths file by file; a test asserts the excluded paths are absent from the kit home |
| T-43-20 | Tampering | a forged record entry pointing prune at another path | medium | mitigate | KIT_ENTRY_PATHS is closed; a backup must be `of` a member and named `<of>.bak.<ISO>`; prune acts only on recorded entries through owns |
| T-43-21 | Elevation of privilege | an install path touching state roots | high | mitigate | Writes stay under `$GRUGOPS_HOME`; tests assert the target's state roots are byte-unchanged; the overlap refusal is unchanged |
| T-43-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package |
</threat_model>
