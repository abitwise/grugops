§1.1  THE NAME, AND WHY THIS ONE

    CHOSEN:            admitted-under-this-id
    REVIEW SUGGESTED:  admitted  |  declared-by-a-document

    `admitted` alone does not tell the pair apart: `admitted-under-another-id` is also an
    admitted record, so a reader meeting `admitted` beside it has to open the module to learn
    which admission is which. `declared-by-a-document` states the right fact but drops the
    symmetry — the two arms stop reading as a pair, and the pair is how a reader uses them.

    The lookup is `populations.byId.get(id)`, whose subject is THIS identifier: some admitted
    document declares it. `admitted-under-this-id` states exactly that subject, and reads as the
    converse of `admitted-under-another-id` — the same sentence with the other object. The
    contract already described the arm this way ("A document declares it."), so the code now
    agrees with the document rather than the document having to be bent to the code.
