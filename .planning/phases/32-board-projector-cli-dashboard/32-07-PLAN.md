Wire the modes. `main` selects one of three writers from the parsed options and the injected
`io.isTty`: the frame writer, the single-document JSON writer, and the NDJSON writer.

TTY live mode clears the screen before each frame and re-renders on every completed refresh. The
clear is a plain escape sequence emitted only when `io.isTty` is true; there is no cursor-addressing
library (D-17). Non-TTY mode passes empty strings for the styling constants and never clears, so a
redirected run produces plain text through the same renderer rather than through a second one.

`--once`, and a non-TTY run without `--json`, print one frame and exit 0 **even when the result is
stale or conflicted**. The state is in the frame; the exit code is not the channel (D-18). Exit 2 is
reserved for exactly two conditions: a usage error and an unreadable `repoRoot`.

`--json` writes exactly one document to stdout and implies `--once` unless `--watch` is also given,
in which case it writes one complete document per line per completed re-read. Every diagnostic, every
read-error summary and every refusal message goes to stderr. Buffer each NDJSON document and write it
in one call, so an interrupted run cannot leave a half-written line a consumer would fail to parse.

Complete the `--interval` validation: a base-10 integer at or above the 1000 ms hard floor, otherwise
a usage refusal naming the floor and exit 2. Never coerce, never clamp silently (ASVS V5).

Harden the entry tail: catch anything escaping `main`, print one named line to stderr identifying the
dashboard and the message, and exit 2. A raw Node stack as the last bytes a piped consumer reads is a
recorded defect class, and this repository's own guard scripts already avoid it (ASVS V7).

Install the SIGINT handler to close every watcher, clear the debounce timer and the poll interval,
flush nothing partial, and exit 0.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| board content → terminal stdout | Ticket titles and opaque metadata reach an emulator that interprets escape sequences |
| argv → `--interval` | An externally supplied number controlling a timer |
| an exception inside `main` → a piped consumer | The last bytes a script or CI job reads |
