Purpose: D-14 makes the directory watch the low-latency path and the poll the safety net; a watch
that is down without saying so converts a live view into a ten-second-granular one under a confident
header. D-12 makes the badge the one place staleness is stated. CLAUDE.md's no-fabrication rule makes
a permanent promise of a re-arm a false statement on the trace surface, not noise.

The canonical-form move here is granularity: narrow the signal consumed to the specific directory a
handle would be opened on — the path the containment authority SPELLED — instead of widening the
response to a label several directories share. And make the early return do both things its
neighbours do, for the reason its neighbours state.

the converse cases the round-2 test stopped one level short of; and the context reader's two silent
skips given names.
