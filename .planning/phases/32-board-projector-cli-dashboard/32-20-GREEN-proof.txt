7. WHAT REMAINS OPEN AFTER THIS PLAN — measured, not remembered
------------------------------------------------------------------------------
  • `import.meta` is a meta-property rather than an identifier, so a member reached on it is outside
    the identifier-rooted capability census by construction. MEASURED: the live closure reaches two
    such members today (`import.meta.url` in scripts/is-entry.js and scripts/board-dashboard.js,
    `import.meta.dirname` in scripts/kit-model.js), both read-only path plumbing.
    `import.meta.resolve` would not be. This is the nearest open edge to the rules added here.
  • Any route whose identity exists only at RUN time — a writer VALUE handed in from outside the
    closure. Undecidable for a syntactic pass; bounded by the zero-runtime-dependency assertion and
    the relative-only closure walk rather than decided.
  • The MECHANICAL proof that this gate is reached in CI. The gate IS reached (the unconditional
    vitest suite step contains this file). What is missing is the derivation that says so:
    `scripts/check-foundation-guards.test.ts` skips any `check:*` script whose command does not
    match `/node (scripts\/[\w.-]+\.js)/`, which silently skips this one. Finding F-01; plan 32-21
    closes it. Cross-referenced in this file's docblock rather than duplicated.
