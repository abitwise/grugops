that a directory entry is attacker-influenced whenever an agent can write into the tree, which is
this kit's normal operating condition.

the repository root is an exfiltration channel with a terminal and a JSON document on the far end.

Output: one containment authority deciding on `realpathSync`, one refusal-to-`readErrors` authority
so a refusal is loud and local rather than fatal, a derived census proving both are the only
spellings, and the contract sentence that makes the behaviour normative rather than incidental.

section to satisfy.

## Trust Boundaries

| Boundary | Description |
