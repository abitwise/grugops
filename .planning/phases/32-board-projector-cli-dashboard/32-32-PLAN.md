## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository tree → the dashboard's module closure | any agent this kit runs can modify a module already inside the closure; that is the bound every finding in this family shares |
| a capability-bearing global → a local binding | a local name is the seam where the census lost the path; the binding is inside one module and inside one AST pass |
| the committed `.js` closure → `npm run check:dashboard-readonly` | the guard is the only mechanism deciding DASH-06 |
| a failing assertion's message → the maintainer who reads it | a message naming the cheapest edit back to green is itself an attack surface, because the cheapest edit was the bypass |
