platform-variable part of the API and which D-14's explicit directory list exists to avoid. The
listener ignores its `filename` argument entirely: Node documents it as null on some Linux systems,

`schedule()` coalesces with a 250 ms debounce — measured this session, one plain write produced four
directory events on macOS, so the debounce defends against multiplicity rather than volume. Both the
debounced callback and the `setInterval` poll tick call the same `refresh()`; one code path, two

path and for a filesystem that emits no events at all.

rather than starting a second read, and the flag is consumed when the first completes. Two
overlapping triggers therefore produce two sequential complete snapshots and never an interleaved
