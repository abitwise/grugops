§1.1  THE DEFECT, RESTATED AS THE OBSERVABLE IT RESTS ON

`presenceOf` (scripts/board-model.ts:1327-1328) answers:

    const admitted = populations.byId.get(id);
    if (admitted !== undefined) return { kind: "admitted-under-its-stem", record: admitted };

`byId` is keyed by the identifier a document DECLARES. The lookup therefore decides that some
admitted record declares THIS identifier, and decides nothing at all about the name the
directory gave that record. For `ABC-901.md` declaring `id: ABC-902` with a board row naming
`ABC-902`, the arm returns a kind spelled "under its stem" carrying a record whose stem is
`ABC-901`. The name asserts a fact the arm never measured.

Observable, run on the pre-change tree:

    $ npx vitest run --exclude '**/scripts/e2e/**' scripts/board-model.test.ts -t "converse"
    scripts/board-model.test.ts:3118
      expect(presenceOf("ABC-902", populations).kind).toBe("admitted-under-its-stem")  PASSES
      with populations.byId.get("ABC-902").stem === "ABC-901"   (asserted at :3111 as a PREMISE)

    That is the whole finding in one line: the arm whose name says "its stem" is reached, and
    the record it carries has a different stem.
