<objective>
Turn the parsed board into a joined `FactorySnapshot` that **surfaces** disagreement instead of
resolving it: seven named conflict kinds derived from board headings, ticket frontmatter, queue
state, context notes, traceability and config — and freeze the resulting shape with a committed
fixture tree that renders to a committed golden byte for byte.

Purpose: DASH-03's whole value is that the projector says "claimed 2 / counted 3 / limit 3" rather
than pretending the board is clean. Research measured that no real board in the wild produces a WIP
mismatch today, so the comparison would ship unexercised unless the fixture manufactures one — which
is exactly how a green suite comes to mean nothing.

Output: `joinSnapshot` and `CONFLICT_KINDS` in `scripts/board-model.ts`, the join wired through
`scripts/board-read.ts`, the `scripts/fixtures/board-snapshot/` tree with all seven kinds, and
`expected-snapshot.json`.
</objective>
