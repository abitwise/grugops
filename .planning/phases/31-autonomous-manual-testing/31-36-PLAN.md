<objective>
Make two verification harnesses able to observe the properties they claim.

- **WR-31 + IN-18** — every CONTROL row in `scripts/check-platform-shapes.ts` is itself a refusal and
  is scored `not refused (correct)`, because the check asks only whether one clause string is absent
  and never asserts the ordinary verdict it already computed. The module's own header says `a run that
  refuses everything proves nothing`, and that is what the run currently is. Alongside it, the
  `FORCE_ABSENT_ENV` seam constructs the shape it has already decided to skip, so the seam does not
  exercise the path it stands in for.
- **WR-32** — `scripts/nonblocking-reader-parity.test.ts` recognises the refusal predicate by ONE
  operator, and both of its mutation mirrors are written in that same operator, so the mirrors prove
  only that the predicate recognises itself. A semantically identical third implementation spelled
  differently is invisible, and an UNTRACKED one is invisible to the input boundary as well.

Both are the same class: a derived axis whose own denominator or whose own control cannot see what it
claims to see. This repository has logged fourteen instances of a harness producing a false result, and
the standing rule from that log is to ASSERT THE HARNESS'S OWN PREMISE before reading its answer.

Purpose: these two harnesses guard the write chokepoint and the non-blocking reader rule — the two
mechanisms UATX-01 rests on. A guard that cannot fail is not a guard.
Output: positive control assertions with reachable ordinary outcomes; a seam that skips without
constructing; a semantic refusal predicate with one mirror per accepted spelling; a two-source input
boundary; decision `D-37` recorded.
</objective>
