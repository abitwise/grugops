<objective>
Close CR-06 / gap 2 of `31-VERIFICATION.md` round 2. `calleeDottedPath` resolves every spelling of a
callee to one dotted path correctly — that half is sound and the verifier re-confirmed it — but the
membership decision is `BANNED_CONSTRUCTS.includes(dottedPath)` against a nine-member frozen literal.
`test.describe.serial.only(...)` and `test.describe.parallel.only(...)` are real Playwright spellings
that narrow an entire gate run exactly as `test.describe.only(...)` does. The verifier reproduced
both live against the committed `.js`: `0 findings over 1/1 uat specs checked`, exit 0, on the same
harness that correctly reports one finding and exit 1 for `test.describe.only` alone.

Purpose: 31-06 centralised the SHAPE question and left the MEMBERSHIP question as a hand-maintained
literal, which is this repository's recorded second systemic failure class — a set literal that rots
while every gate over it stays green. The file's own header says a red-team finding is "a NEW
DECISION and a gap-closure round, never a quiet edit here", and cites the prior phase that closed a
class by defining a canonical form instead of adding one more spelling. This plan does that: the
membership question becomes a rule over the resolved path, so a new intermediate segment cannot
create a new hole.

Output: one membership authority decided by head and tail over the normalised path; a refusal corpus
generated from the rule rather than maintained beside it; a false-positive control over legitimate
routing segments; two new type-checked fixtures; a recipe that states the rule and quotes the three
constants by value; and D-17 recorded as a dated gap-closure decision.
</objective>
