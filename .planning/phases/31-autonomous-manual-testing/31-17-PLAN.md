<objective>
Close WR-19 and WR-20 of `31-REVIEW.md` — the two resolver-internals defects the round-4 verification
independently reproduced beside the Criticals — and re-derive the residual register and the recipe from
the mechanism they now describe.

**WR-19 is a floor bypass wearing a warning's clothes.** D-18 (1) made `calleeDottedPath` recursive
and did not re-derive its 512-step bound, so the bound now restarts on every recursion frame. The
verification drove a spec containing a 4000-link call chain through the committed `.js` and got an
uncaught stack-overflow exception: a stack trace on stderr, EMPTY stdout, and NO `visited/expected`
line printed at all. The exit code landed inside the D-12 contract's `{ 0, 1, 2 }` only because an
uncaught throw exits 1 — which that contract reads as "a finding, the quality gate blocks". The
substantive harm is that `reportMeasured` is never reached, so the vacuity floor and the denominator
floor — the two branches that exist precisely so a check that did not run cannot be read as a clean one
— are bypassed by construction. That is UATX-05's own contract failing on a path nobody had asked
about. It also makes the residual sentence the recipe quotes verbatim — that a chain reaching the bound
yields no path rather than a truncated one — false as written.

**WR-20 is a false refusal, and after `31-16` its blast radius doubled.** `canonicaliseHeadSegment`
rewrites the head segment whenever it is a key of the file-level rename map, with no scope analysis at
all. The verification reproduced a legitimate spec — a local parameter named the same as a renamed
import, calling a method on a plain object — refused at exit 1 with a finding naming a construct that
does not appear in the file. A checker that misnames what it found trains a reader to work around it.
And `31-16` adds a SECOND map feeding that same canonicaliser, so a scope rule written for only the
import map would be this exact defect one map over — which is the shape this phase has now paid for
four rounds.

Purpose: UATX-05 requires that an unusable lane produces a loud skip and never a silent pass, and
UATX-06 requires that the recipe's claim match what the checker decides. WR-19 breaks the first on a
reachable path and WR-20 breaks the second in the misleading direction. Both were reproduced; neither
is speculative.

Output: one shared step budget threaded through the recursion with an end-to-end assertion that a
pathological chain prints the measurement line and exits inside the contract; one scope rule in the one
canonicaliser covering both maps, with a false-positive control fixture; a re-derived decline-site set
and residual register bound in both directions with an asserted cardinality; a re-quoted recipe; and a
dated decision recorded beside D-18 and D-20.

**Ordering note:** wave 2 and `depends_on: ["31-16"]`. This plan and `31-16` both modify
`scripts/runnable-ref/uat-spec-integrity.ts`, `scripts/runnable-ref/uat-spec-integrity.test.ts`,
`agent-factory/checklists/browser-uat-recipe.md` and
`.planning/phases/31-autonomous-manual-testing/31-CONTEXT.md`. Sequencing removes the conflict and lets

retrofitted.
</objective>
