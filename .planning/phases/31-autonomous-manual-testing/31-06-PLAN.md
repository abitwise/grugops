<objective>
Close gap 2 of 31-VERIFICATION.md: arm (c) of the D-14 ban set matches a callee shape Playwright
never produces. `@playwright/test` exports no top-level `describe`, so the only real spellings —
`test.describe.only` and its siblings — are invisible to the matcher, as is every bracket-notation
call. The verifier reproduced this live: a spec carrying all three constructs reported 0 findings and
exited 0. The union fixture that was meant to prove this arm imports a binding the package does not
export and is excluded from both tsconfigs, so the corpus could never have caught it.

Purpose: `test.describe.only` narrows an entire gate run to one describe block. That is precisely the
"a green lane would certify a scenario nobody exercised" failure the checker exists to prevent, and
it is the mechanical half of UATX-06.

Output: a dotted-path callee normaliser feeding one comparison; `BANNED_CONSTRUCTS` expressed in
Playwright's real spellings without dropping anything D-14 named; a corrected and a new fixture; a
declared `@playwright/test` surface with a dedicated typecheck target wired into `npm run typecheck`;
a harness proving every banned spelling is a construct that surface actually has; and a recipe whose
ban set and residual list are re-quoted from the one constant.
</objective>
