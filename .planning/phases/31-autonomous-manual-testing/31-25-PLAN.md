Round 4's `31-17` closed WR-19 — a per-recursion-frame step bound and a self-recursive AST walk that
together let a deep call chain kill the process with an empty stdout and both measurement floors
bypassed. That closure is real: a 4,000-link chain now reports `0 findings over 1/1`, exit 0, stderr
empty. What it did not do is wrap the PARSER. `ts.createSourceFile` is a recursive-descent parser
running on author-controlled source, and it sits one line ABOVE the `try` the fix added. The verifier
measured WR-19's exact harm reproducing at a quarter of the round-4 probe's depth: 1,000 nested
parentheses, uncaught `RangeError`, empty stdout, exit 1, no measurement line.

**The bypass threshold moved from 4,000 to 1,000, in the opposite direction from the fix** — and the
recipe paragraph this same round added asserts it cannot happen.

The substantive harm has never been the exception. It is that `reportMeasured` is never reached, so the
vacuity floor and the denominator floor are bypassed by construction while stdout stays silent, and
Node's uncaught-exception code 1 is read by the D-12 contract as "a finding — the gate blocks". A check
that never ran is reported as a check that found something.

`deriveSpecPaths`'s directory `walk` is the second unguarded self-recursion in the same file. The review
names it explicitly so the fix covers the class rather than the one call.

Purpose: put every exit of this runnable through a decided boundary, and assert the partition over a
pathological corpus rather than over the one depth a reviewer happened to try.

Output: the parse, the diagnostics read and the walk inside one per-file boundary; `main`'s body inside
one process boundary returning 2; a de-recursed directory walk; a run-time-generated pathological corpus
asserting both the exit code AND the measurement line; a corrected, honestly-bounded recipe paragraph;
and decision **D-28** appended to `31-CONTEXT.md`.

|----------|-------------|
| an author-controlled spec's bytes -> the TypeScript parser | a recursive-descent parser on untrusted input crosses here, and it sat outside every guard |
