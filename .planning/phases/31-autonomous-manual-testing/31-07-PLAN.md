<objective>
Close gap 3 of 31-VERIFICATION.md: `guardPlaywrightMcpPin` reads its authority as the first
`@playwright/mcp@` mention in the recipe with no check that what it read is a well-formed concrete
version. If that first mention is itself a floating specifier, the pin becomes the dist-tag string,
every other re-pinned mention compares equal to it, and the guard prints a clean pass over a fully
floating kit — the exact failure it exists to prevent. The guard's own source comment and
31-03-SUMMARY.md both assert the opposite, and no test in the shipped suite makes the authority
float.

Purpose: this is the only supply-chain control over a pre-1.0 MCP server the user's own coding agent
fetches with `npx`. It is a documented must_have of Plan 31-03 that fails as written, and it is
UATX-02's mechanical half.

Output: a concrete-version shape assertion on the authority with a named refusal; two new test cases
covering the floating-authority configurations; a watched-fail proving the assertion is the control;
a corrected rationale comment; and an appended dated correction note on 31-03-SUMMARY.md.
</objective>
