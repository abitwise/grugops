<objective>
Tell an upgrading Claude Code user about the engineer adapter Phase 39 retired, and write the install docs for the level
adapters (TIER-03, TIER-06; D-5, D-13, D-22).

A host repository installed before Phase 39 keeps `.claude/agents/grugops-software-engineer.md`: the generator only writes,
and the installer's adapter set comes from the kit source, so nothing names it. Claude Code still loads it, and on the Reduced
tier it can be spawned. This plan adds a derived, report-only check to install, `--check` and `--dry-run`, keeps the file's
ledger record so uninstall can still remove it, and documents the level adapters, the v2.1.293 floor and the run-time paths
that can flatten the levels.

Purpose: no upgrade leaves an unreported, spawnable adapter behind, and the install docs say what the levels do and do not do.
Output: the installer report, its tests and the README sections.
</objective>
