**2. [Rule 1 - Bug] The mutation mirror's seed check tested presence, not uniqueness**

- **Found during:** Task 2
- **Issue:** `mirrorCensus` threw only when the seed string was absent. `String.replace` with a string pattern rewrites the FIRST occurrence, so a seed matching twice would silently un-own a site chosen by source order and every count assertion downstream would be about a different sentence than the one named.
- **Fix:** The mirror counts occurrences and refuses on anything other than exactly one, naming the count and the module.
- **Files modified:** `scripts/board-model.test.ts`
- **Verification:** Both mirror arms green; `scripts/board-model.test.ts` 177 passed.
- **Committed in:** `c83fb4b3`

**3. [Rule 3 - Blocking] `SpawnSyncReturns<string>` has no `err` property**

- **Found during:** Task 1
- **Issue:** The premise message read `r.err ?? r.stderr`, borrowing a shape from `board-tracer.test.ts`'s wrapper type rather than from `spawnSync`'s own. `npm run typecheck` refused it (TS2339).
- **Fix:** The message reads `r.stderr`.
