## Accomplishments

- **The class question is deleted, not redrawn.** The `path` carve-out and the `internal` carve-out are both gone from the builder's docblock and both declaration tables are gone from the census. In their place stands one universal rule — every value interpolated into a published sentence is built through the builder — enforced as a two-sided set equality that derives both of its sides.
- **The second class was disproved by MEASUREMENT in this plan, not by the first one's precedent.** A probe at HEAD spawned the committed dashboard against a non-existent root named `repo<U+0085>x` and read back a refusal that names `repox` twice: the platform's own `ENOENT` text, quoted into `board-dashboard.ts`'s `(e as Error).message`, sanitized on the way to stderr. The `internal` carve-out had named that exact route in its own second half and then excused it, and one table excused the site by pointing at the other while the other excused it by class.
- **The work list was the whole denominator, and it was derived.** 42 unowned published substitutions — 3 in `board-model.ts`, 29 in `board-read.ts`, 10 in `board-dashboard.ts` — all closed. The post-cutover census reports published 86, owned 86, unowned 0, with the substitution total unmoved at 171 and the denominator unmoved at 86, because a tag is not a sentence.
- **The tracer's one path became four.** Plan 32.1-12 proved the defect at the claimed-queue claim record; this plan reproduced it at the context reader's shape refusal, the context reader's event-index parse refusal and the ticket reader's decode refusal — three further arms in two further readers, each measured at the model, the stderr frame and the published JSON document in one run, each RED before the cutover with every premise passing.
- **The equality has been watched fail in every module it covers.** A single-substitution tag removal seeded in each of the three moves the owned count by exactly one, reds both directions, names module/expression/declaration, and leaves the denominator at 86. A premise case asserts the seed set is derived-equal to the census's module set, so a control exercised in a subset can no longer pass unnoticed — which matters because ten of this plan's cutovers landed in the module that had never been seeded.
- **Every arm the cutover could have broken was probed with a result.** The two-authority render pin, idempotence at the nested stderr-frame site (now proved by byte equality rather than argued), the one-shot JSON document's shape and content, the conflict identifier join key that WINDOWS.md row 218 deliberately leaves scrubbed, the read-only posture and the platform shapes. All recorded in `32.1-13-GREEN-proof.txt` section 3.

### Auto-fixed Issues

**1. [Rule 1 - Bug in the plan's verify command] The JSON verify pins the wrong schema version**

- **Found during:** Task 3
- **Issue:** The plan's `<verify>` for the JSON document asserts `j.snapshot.schemaVersion !== 1` and fails otherwise. `scripts/board-model.ts:58` declares `SCHEMA_VERSION = 2` and has since phase 32-33 (commit `92f27444`), so the command as written fails on correct code, for a reason unrelated to this plan. Run verbatim it exits 1 with `Error: schemaVersion=2`.
- **Fix:** The check is run with the declared version DERIVED from the module (`import { SCHEMA_VERSION }`) and compared against the document's, which is what the acceptance criterion actually asks — "exactly one JSON document with its DECLARED schema version". Typing the number is the failure mode this phase's own prohibitions name.
- **Files modified:** none in the tree; the probe is a transcript, recorded in `32.1-13-GREEN-proof.txt` section 3.3.

## A Plan Premise Corrected by Measurement

Recorded here rather than left in the transcripts:

**"The `path` class is the expansion's work list (18 substitutions, 16 remaining)."** Once the class question is deleted, the work list is the whole denominator: 42 unowned published substitutions, of which 16 are `path`, 24 `internal` and 2 `assembled`. Plan 32.1-12's scoping was correct for a plan that kept the classes; it is not the scope of a plan that deletes them. The RED baseline records the whole 42 as the authority, and all 42 moved.

Additionally, the denominator's movement from 45 (plan 32.1-12's RED) to 42 (this plan's RED) is **3, not the 2 arithmetic predicts**. Re-running the census rather than subtracting exposed the third: tagging the `tampered` claim-record sentence also owned `atLineCount`, because ownership is a property of the TEMPLATE and that sentence carries two substitutions. This is the second consecutive plan in which reading the number out of the instrument caught a count that arithmetic would have got wrong.
