## Sampling Rate

- **After every task commit:** the per-file quick run for the file the task touched, plus
  `npm run typecheck`, plus `npm run build && npm run check:build-parity` whenever a `.ts` under
  `scripts/` moved.
- **After every plan (each plan is its own wave — the phase is strictly sequential):** the full
  excluded lane, plus the prose gates for any plan that edited `agent-factory/` or `docs/`.
- **Before `/gsd-verify-work`:** full lane green, `npm run check:diff-disposition` green, the D-13
  live transcript filed, and `node .planning/phases/32.1-board-dashboard-deferred-residuals/32.1-ledger-check.mjs`
  exiting 0.
- **Max feedback latency:** ~60s at task level; ~460s at plan level.
