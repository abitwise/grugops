<objective>
Close the two warnings this phase's own code review raised against the modules it rewrote, and give
every information item a disposition.

The first warning is a header that outruns its code. The rewritten specifier walk states that it
refuses rather than returns short, and that a slot it cannot read is never silently treated as no
edge. The parser it now uses does not throw on a syntax error — it recovers and hands back a partial
tree — and the walk reads that tree without asking whether the parse was clean. A source with an
unterminated block comment therefore yields a closure that is short by however many imports followed
the unterminated token, at exit 0, with an empty unreadable list. That is precisely the outcome the
header calls the failure it exists to prevent.

The second is a guard whose failure mode is silence. The loader oracle's child load has no bound, so
if the entry detection it rests on ever mis-detects, the child runs a watch loop that never exits,
the worker hangs, and the run reports a timeout naming nothing. This repository's ledger records that
shape repeatedly: a hung gate is not a red gate.

Neither is closed by argument. Both are RED-first, with a fixture that reproduces the short answer
and a bounded reproduction of the unbounded wait, each proved to red alone.

Purpose: the phase's verification recorded both as Info on the ground that their blast radius is
narrow. Narrow is a reason to fix cheaply, not a reason to leave a module's own header stating
something its code does not do.
Output: two named refusals with reproductions, one recorded seam form, four one-line information
fixes, three information items dispositioned as register rows with owners, and the committed build
output rebuilt faithfully.
</objective>
