<objective>
Finish what plan 32.1-12 started on one path, and finish it as a canonical form rather than as a
wider enumeration.

Plan 32.1-12 proved that the carve-out excusing path-derived values was unsound at the claim-record
sentences and closed those two. The remaining question is which OTHER class is unsound, and the
honest answer is that the class question is the defect. The excluded table names a second class —
internal values, including "the text of an error the platform handed up" — and a platform error text
names a path, which is composed from the same directory listing. Narrowing one class and keeping the
other is the move this repository's ledger records failing round after round: the fix lands in one
arm and the next round finds the same defect one register over.

So this plan deletes the class question. Every substitution reaching a published sentence in the
three board modules is built through the builder. The two declaration tables go, the two carve-out
paragraphs go, and the census keeps one two-sided equality and one pinned count in their place.

Per D-07 the builder puts the escaping in the constructor and there is no arm in which a caller opts
out. This plan makes that sentence true of the whole published surface instead of true of a
classified subset.

Purpose: a classification table is a hand-maintained set, and this repository has already paid twice
for a hand-maintained set that rotted while its tests stayed green. Deleting the set is the only move
recorded here as terminal.
Output: every published substitution owned, both declaration tables and both carve-out paragraphs
deleted, one derived equality with one pin, a mutation proof per module, and the committed build
output rebuilt faithfully.
</objective>
