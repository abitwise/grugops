<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Code agent → host shell (deploy command) | The PreToolUse hook intercepts every Bash command before it runs; this is the deploy access-control boundary. The agent is untrusted with respect to production deploys. |
| Untrusted hook stdin (JSON) → guard parse | The PreToolUse payload is parsed; a malformed payload must never crash-allow a deploy. |
| human-set process env → approval | Only a human-set `GRUGOPS_PROD_DEPLOY_APPROVED` in the process environment authorizes a deploy; the agent may never set it inline. |

| T-15-02-guard-DoS | Denial of Service → bypass | malformed hook stdin crash-allowing a deploy | mitigate | Fail-closed stdin parse (`readFileSync(0)` → `JSON.parse` in try/catch → empty command); unparseable/empty → only non-deploys pass.
