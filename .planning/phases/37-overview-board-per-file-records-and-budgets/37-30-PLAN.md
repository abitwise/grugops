<objective>
Extend the READ-1 table per D-18 and 37-GAP-PLANNING-BRIEF.md §1.1 so it can see the shapes that raise no error. Round 1's
table injected error codes at each read site; CR-03 and CR-04 were a link-borne ENOENT and a filtered entry, which no
error-code row can reach. This plan plants the non-error shapes at every read position of the three runnables, derived from
the one owner's callers and counted, and runs every existing EIO row a second time with ENOENT, the code a dangling link and a
vanished file both produce.

a later change that reads a dangling link, a wrong type, a refused entry or a vanished path as "no data" turns a row red,
whichever position it touches. It also authors the round's three concurrency edges (SPLIT-03, SPLIT-05, SPLIT-06) as explicit,
tested truths.

Output: the shape table and its derived position set, the ENOENT variant with its exemption list, a fix for any row that finds
a defect, and the mutation proofs.
</objective>
