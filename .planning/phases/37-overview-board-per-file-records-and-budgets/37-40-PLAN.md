<objective>
Close G-37-2 per D-21: the installer writes `tools/grugops/package.json` holding `{"type":"module"}` beside the programs it
copies, under the installer contract, so every program loads as an ES module whatever the host's package.json says, and
`--check` reports the file.

Purpose: Node takes a bare `.js` file's module type from the nearest package.json. A host whose package.json says
`"type": "commonjs"` (npm 11's `npm init -y` default) makes Node parse each program as CommonJS, and it throws at its first
import before any of its own code runs. Node's uncaught-error code is 1, the finding code, so WF05 and WF09 read a program that
never ran as a finding or a refusal (37-UAT.md test 2, reproduced at planning: 7 of 7 programs exit 1). A package file beside
the programs is the scope boundary Node honors: with it, all seven run their own body (verified at planning).

Output: the kit file, one RUNNABLES row and its mirror, the commonjs-host regression with its premise control, the
installer-contract cases, the doctor line, the moved count pins, and the install guide and changelog text.
</objective>
