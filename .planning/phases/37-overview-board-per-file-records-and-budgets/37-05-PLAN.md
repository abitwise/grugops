## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-37-11 | Tampering | overwriting a hand-written traceability.md or trace file on an unmigrated host | high | mitigate | the render replaces or removes only files whose first line is the generated header; anything else stops the run with exit 1 before any write |
| T-37-12 | Tampering | two identifiers folding to one file name overwriting each other on a case-insensitive disk | medium | mitigate | caseFoldCollisions runs before any write; a collision is exit 1 naming both |
