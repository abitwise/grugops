<objective>
Close IN-03 per D-17 and the READ-1 class it belongs to in scripts/validate-agent-factory.ts, which the brief names in
READ-1's rule: a read that fails is a named finding, never "no data" and never a pass.

Purpose: the validator's helpers answer existence with existsSync, which is false for EACCES on a parent as well as for
ENOENT, and catch every read error to null or an empty list. So an unreachable NFR, ticket or trace directory gets no
finding (IN-03), an unlistable tickets directory makes checkTickets vacuously green, an unreadable role file skips its
section check, and an unreachable marker reads as absent and downgrades a migrated tree's budget errors to warnings. The
fix puts the rule in one place: five read primitives that only call ENOENT absent, and helpers that record every other
failure by name.

Output: the primitives, the recording helpers, checkBudgets on the primitives, the IN-03 case, the validator's READ-1 table
and census, and the rewritten tests.
</objective>
