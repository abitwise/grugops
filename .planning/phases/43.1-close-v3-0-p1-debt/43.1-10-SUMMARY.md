## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical] install/README.md §5 states GitHub's immutable OIDC subject format**
- **Found during:** Task 1 (reading the OIDC page)
- **Issue:** The page read today documents a second default subject format. Repositories created, renamed or transferred after July 15, 2026, and older repositories that opt in, use `repo:OWNER@OWNER-ID/REPO@REPO-ID:...`. The plan's checklist row C and citation paragraph show only `repo:<owner>/<repo>:environment:<name>`. Left alone, the guide would present that older format as the only one. A trust policy written from it would never match a newer repository's token: deploys would fail rather than open up, but the guide would be inaccurate.
- **Fix:** I kept checklist row C exactly as the plan fixed it, in all three files. In the citation paragraph I added one sentence: newer repositories, and older ones that opt in, use an immutable format whose repository part adds the owner and repository IDs (`repo:<owner>@<owner-id>/<repo>@<repo-id>`), so the trust policy should be written in the format the repository uses. The C-28-090 mechanism records that the sentence goes beyond the plan's scripted wording, and why.
