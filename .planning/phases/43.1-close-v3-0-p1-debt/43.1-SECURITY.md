|----------|-------------|---------------|
| installer → target repository | `install/install.js` writes, replaces and removes files in a user's repository (plans 02, 06) | user-owned files; the install ledger decides what install may remove |
| CI workflow → gate modules | `.github/workflows/ci.yml` decides which gates run on main (plan 01) | gate selection; a removed gate must carry a recorded reason |
