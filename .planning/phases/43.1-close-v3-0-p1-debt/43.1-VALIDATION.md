- **After every plan wave:** `npm run typecheck`, `node scripts/check-build-parity.js`, and every gate in the ci.yml ubuntu block
- **Before `/gsd-verify-work`:** full suite compared **by test name** against the baseline in RESEARCH Item 9 (EDQUOT on /tmp can give false failures), then a green ubuntu CI run on main
- **Max feedback latency:** 120 seconds per task
