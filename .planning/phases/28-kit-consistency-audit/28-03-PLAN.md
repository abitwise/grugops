## Register schema — the format the gate parses

`docs/audit/28-disposition-register.md` carries exactly two tables and three prose sections.

**Table A, the file rows.** One row per audited file. Columns, in this order:

| Column | Values | Meaning |
|---|---|---|
| `file` | repo-relative path | The row key. Duplicates are a named refusal. |
| `kind` | `role` \| `workflow` \| `protocol` | Derived, not asserted by the author. |
| `counted` | `yes` \| `no` | `no` only for the D-02 protocol row, which carries its reason in `observation`. |
| `safety_surface` | `yes` \| `no` | D-18's input. Recorded by the reader, who is already in the file. |
| `findings` | integer ≥ 0 | The count of Table B rows whose `file` is this row. D-03 equality two's left side. |
| `observation` | prose | Substantive. The bare word describing an absence of findings is refused by the gate. |

**Table B, the finding rows.** One row per finding. Columns, in this order:

| Column | Values | Meaning |
|---|---|---|
| `finding_id` | `F-28-NNN` | Zero-padded, unique. Duplicates are a named refusal. |
| `file` | repo-relative path | Must be a `file` present in Table A. |
| `category` | `1`…`6` | The D-07 rubric category. |
| `disposition` | `fixed` \| `accepted` \| `deferred` | D-04's closed set. A fourth value fails. |
| `target_phase` | phase number or `—` | Required when `disposition` is `deferred`. |
| `reason` | prose or `—` | Required when `disposition` is `accepted` or `deferred`. |

**Prose sections.** Four, all created by this plan.

- `## What this register does not prove` carries D-06's unverifiable-read limit.
- `## Rubric` names D-07's six categories and states that category 6 is record-only.
- `## Out-of-set by derivation` explains the D-02 protocol row.
- `## Recorded couplings and out-of-set notes` holds records about files and directories that have no
  Table A row and therefore cannot hold a Table B finding — the Phase 33 coupling on
  `examples/03-ticket-to-pr.md` and the two deleted hygiene directories, both written by 28-05. It
  exists because the alternative is a Table B row whose `file` is absent from Table A, which the parse
  authority refuses and which would break the D-03 equalities if it were allowed. The section's own
  header states that rule, so a later editor does not solve the problem by widening Table A.
