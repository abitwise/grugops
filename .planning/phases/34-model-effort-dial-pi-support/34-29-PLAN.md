<objective>
Close the `--check` half of G-34-2: the doctor that printed ALL CHECKS PASSED while Pi could not reach
the Orchestrator now follows the route as an agent would. It checks every carrier the registry derives
and says, for every supported host, whether that host reaches the Orchestrator. A two-sided class test
holds the doctor's verdicts equal to verdicts the test computes from the files alone.

Purpose: AGENTS.md's STOP rule sends the agent to `install.js --check`. A doctor that is green while a
host is stranded leaves the agent and the human nowhere to go. That is the "why not caught" half of the
diagnosis. A test over the whole host set, derived from HOST_TOOLS, makes a seventh host or a missed
carrier fail red.

Output: the doctor's kit-route section, extended from 34-27's tracer, and the scenario matrix in
install/kit-route.test.ts.
</objective>
