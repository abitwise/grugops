## Shared Patterns

- **Closed tuple + exact equality + derived type + COUNT constant** (`scripts/model-tiers.ts` 165, 225, 275, 802): every new set (effort levels, host tools).
- **Refusal names every offender, sorted, with remedy** (`readModelsBlock`); value quoting via `quoteValue`/`describeShape`.
- **One authority per predicate:** frontmatter parsing via `admit()`; user-path reads via `readForWrite`/`readUserFile`; file creation via `writeTargetFile(...,"create")`; ownership via ledger `recordCreatedFile` + `owns()`.
- **Derive-the-set, assert-the-count** for host-tool lists in docs/tests/validator (set-literal drift class). Never write "six" in prose.
- **Tests drive the committed `.js`** — run `npm run build` before tests (Pitfall 12). Regression: `npx vitest run --exclude '**/scripts/e2e/**'`.
