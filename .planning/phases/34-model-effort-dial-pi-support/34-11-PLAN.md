## Root cause (established at planning from source and the printed CI log)

Log: `gh run view --job 112468804112 --log` (read-only), run 37521787426, head dc2c7581. 91 reds
print `it was written for another directory (C:\Users\runneradmin\AppData\Local\Temp\grugops-useredit-tesGCj\edit-default-1), not this one (C:/Users/runneradmin/AppData/Local/Temp/grugops-useredit-tesGCj/edit-default-1)`
or `expected 'C:/Users/runneradmin/…' to be 'C:\Users\runneradmin\…'`, or follow a `rebindMarker`
call (the four installer-dry-run subset cases, installer-user-edit KNOWN EXCEPTION 12 and 13). The
same log prints `target: C:\Users\RUNNER~1\…` for the run's own target, the 8.3 short form.

- WRITE side (product): install/install.ts:4198 `const here = realTargetPath(TARGET)` → :4286
  marker `target: here`; install/install.ts:2837 `realTargetPath(GRUGOPS_HOME)` → :2852 kit-home
  record `grugopsHome: here`. The spelling is install/user-file.ts:281-287 `realTargetPath`
  (`realpathSync.native`, then a backslash-to-slash fold at :283) and :304-320
  `realPathThroughExisting` (the same fold at :316).
- COMPARE side (product): install/install-marker.ts:302-305 computes `here` the same way, then
  :332 `boundTo !== here` compares the RECORDED value raw; install/install-marker.ts:1098-1099
  `parsed.grugopsHome !== here` likewise.
- The second spelling comes from the tests: install/installer-paths.test-support.ts:181
  `rebindMarker` writes `m.target = realpathSync.native(t)`, the host's backslash spelling. It is
  called by record-truth.test.ts:109, installer-user-edit.test.ts:162, installer-dry-run.test.ts:295
  and :351, installer-never-installed.test.ts:178, :305, :320, ledger-provenance.test.ts:377. Direct
  fixtures do the same: marker-binding.test.ts:73, :114, :139, :150; installer-kit-home.test.ts:178,
  :318; ledger.test.ts:500, :658 (those are plan 34-12).
- So the product is self-consistent and fails closed (exit 3, nothing removed). The product defect
  inside the class: the compare side never passes the recorded value through the spelling
  function, so a target written in the native spelling (the documented "same repository moved"
  remedy, uninstall.ts:2041-2043 and install.ts:1101) is refused on Windows. And on POSIX the fold
  turns `/tmp/a\b` and `/tmp/a/b`, two directories, into one spelling; install.ts:280 `toPosix`
  folds a POSIX `--target` containing a backslash into a different directory name.
- 8.3 short names: `realpathSync.native` (product) expands `RUNNER~1` to `runneradmin`; the tests'
  SCRATCH roots use the JS `realpathSync`, which does not. A test must therefore take a recorded
  path's expected value from the product's `realTargetPath`, never from its own SCRATCH string.
