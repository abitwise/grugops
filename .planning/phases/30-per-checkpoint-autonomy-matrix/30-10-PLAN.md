Attack the three predicates on this surface with the four standing questions, and write each attack as
a failing test BEFORE any fix.

What set does each predicate ENUMERATE? The derivation's corpus, the validator's legal key set, the
reader's key set, the render's row set. For each, find the input that makes the enumerated set differ
from the set the predicate believes it has.

What is each predicate's INPUT ASSEMBLED FROM? The tag scan receives a line range from the section
locator; the validator receives a parsed object; the render receives two files. Attack the assembly,
not only the predicate: a correct parser handed a wrongly assembled string is the shape that took six
rounds to find in an earlier phase here.

At WHICH POSITIONS is each predicate even ASKED? A pattern that accepts the right characters but is
never consulted at the position that matters is a bypass that no character-level test finds.

Does the HARNESS assert its own PREMISE? For every fixture-based assertion on this surface, prove the
fixture actually exhibits the condition the test believes. This produced a false result six times
across four consecutive rounds in an earlier phase of this project.

precisely what it now reads that neither predecessor did and attack that delta. Second: every
must-change-together rule introduced in this phase — the config twins, the disposition companions, the
guard freeze — is it scoped to the commit that actually changed the thing, or merely to a range? A
range-scoped rule self-disarms the first time its companion legitimately changes, and a two-commit
fixture can never see the difference.

For every finding: reproduce it pre-fix on a mirror of the committed compiled artifact — the mirror
exits zero, the current tree exits non-zero — fix it structurally, and prove the fix discriminates by
mutation. Log each in the round log with its reproduction commands.
