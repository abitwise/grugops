The CLI contract for these two commands (D-01, D-08):

| Command | Exit 0 stdout | Exit 2 (stdout empty, one `Error: ` line on stderr) |
|---|---|---|
| `free` | `free N`; defaulted: `free N (queue.wip_limit not set, default 3)`; over: `free 0 (N claimed, wip_limit M)` | the config path is not a regular file, `claimed/` unreadable |
| `sweep` | `swept N`, then one `reclaimed TASK` or `released TASK (already done)` line each | queue unreadable |

**Open Question 4, decided: yes.** The stamp landed in plan 41-03. READ-1 is decided here. A row-per-site table in the style of
scripts/runnable-ref/read-sites.test.ts is the wrong cost: that file is 2,457 lines of per-runnable fixtures, and adding a fourth name to its
`RUNNABLES` would also pull its shape and owner tables along. A separate derived test keeps the rule and its derivation, and needs no hand
table: every site comes from `deriveReadSites` and `callingSites`, and every site must fire in at least one mode. Sites with a reason to
differ are listed by name.

**Why no generator change.** The claim.ts roots landed in plan 41-03, so this plan touches only the hand-written part and the three regions
stay as they are.
