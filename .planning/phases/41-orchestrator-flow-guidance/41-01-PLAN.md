<objective>
Give `scripts/claim.ts` the whole queue lifecycle, in a shape a host program can embed.

Purpose: today `done` is a bare file move that leaves `claimed/TASK/claim.md` behind, so the in-flight log never empties and
any count of running work is wrong (RUN-01, research Pitfall 1). The library also cannot be embedded: two of its names collide
with `scripts/context-io.ts`, and its default queue root pulls `import.meta.dirname` into the closure (Pitfall 2). This plan fixes
both and adds every rule the CLI needs, so plans 41-03 and 41-05 write no queue logic of their own.

Output: an extended authority with its committed build, unit cases for every edge, and the dual-path oracle on the new shape.
</objective>
