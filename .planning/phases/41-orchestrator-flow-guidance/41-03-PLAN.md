TASK, ADAPTER, LEVEL, FOLDER, AT, N and DIR in this plan are placeholders.

**The CLI contract (D-01, D-08; exit numbers and wording are Claude's discretion, following state-roll).** Exit 0 is done, exit 1 is an outcome
to act on, exit 2 is could not run or refused. An escaped throw is always exit 2.

| Command | Exit 0 stdout | Exit 1 stdout | Exit 2 (stdout empty, one `Error: ` line on stderr) |
|---|---|---|---|
| `claim TASK --by ADAPTER [--level LEVEL]` | `claimed TASK by ADAPTER` | `lost TASK` | bad task name, missing `--by`, refused owner, bad level, no pending subtask, already in `done/` |
| `done TASK` | `done TASK` | `not-done TASK: no sealed note in .grugops/context/FOLDER/ since AT` plus unsealed names | not in `claimed/`, tampered record, bad `ref:`, unreadable notes |
| `now-running` | `rendered .grugops/queue/now-running.md` | none | queue unreadable |

**Root.** The current directory, or `--root DIR`, resolved once with realpath. This is the one deliberate difference from state-roll's
positional root, because a positional task would make that awkward. Exit 2 when `DIR/.grugops` is absent, so a wrong working directory never
makes a stray queue.

**Generator bootstrap.** tsconfig sets `noEmitOnError: true`, and the committed generator is what writes the region. So code that uses
embedded names cannot compile before the region exists, and the row cannot run before it compiles. Add the row with a stub target first,
build, generate, and only then write the hand-written part. Task 1 spells this out.

**A pending case the test file must hold.** The order inside `claimPending` makes a lost race read as `lost`, never as a missing subtask.
Plan 41-01 owns that rule, and this plan proves it at the process level.

Project rules: never `npm test`; run `npx vitest run <files>`. No branch create or switch. Do not stage
`docs/audit/28-prepass-evidence.md` or the untracked `~/` directory; do not delete or move `~`. Commit subjects start `feat(41-03):` or
`test(41-03):`. Large gate output goes to a file, never a pipe.
