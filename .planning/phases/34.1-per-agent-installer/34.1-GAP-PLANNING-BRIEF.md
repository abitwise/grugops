A later finding that matches one of these is **the same class again**, not a new gap. Fix the
class, not the site.

## 2. Required in every gap-round plan set

### 2.1 Tests that catch any member of the class
- **REC-1:** one table-driven test over every arm that writes the marker (install; uninstall
  per-agent and flag-less, each with and without a held entry; a shared `.agents/skills` entry
  held while one of its two owners is removed). Each row asserts the invariant "every agent owning
  a ledger entry is in `agents`" and, where the field means installed, the converse. The arm list
  is derived by search over marker writes, with the count asserted.
- **REC-1 / MSG-1 remedy test:** partial per-agent uninstall with one edited owned file, restore the
  file, run the exact command the kept line printed, assert the file and the agent are gone.
- **MSG-1:** a test per message site that the referenced line is printed in the same run, or the
  message names a README section that exists.
- **DOC-1:** a docs scan that "kit-read rule" no longer appears in user-facing text (README, install
  notes, closing lines), with the replacement sentence present.

Each class test needs a mutation proof: break the rule, watch the test go red, record it.

### 2.2 One authority per rule
- REC-1: one function computes `agents` for every marker write (no second set expression in an arm).
- MSG-1: the remedy command is built by the same function that names the per-agent flag (`agentFlag`).

### 2.3 Sibling search before execution
The planner and the checker each list, for every class touched, **all** sites in that class,
found by search, not taken from the review or the verifier. For each site, name the plan and test
that covers it.

## 3. Required in every gap-round execution

- Regression gate per plan: `npx vitest run --exclude '**/scripts/e2e/**'` plus `npm run build`,
  `npm run check:build-parity`, `npm run typecheck`. Never a red commit. Do not run `npm test`
  (it triggers the live e2e lane). The five DI-03 Node 26 reds are a baseline, not new failures.
- Every scratch install sets `GRUGOPS_HOME=<scratch dir>` (and HOME where the run touches `~`);
  without it the installer overwrites the user's real `~/.grugops` kit.
- No per-plan red-team (retired 2026-10-04). New adversarial findings go to deferred-items.md for
  human triage, not into the next plan's scope.
- Do not flip ROADMAP/REQUIREMENTS rows; restore STATE.md frontmatter if a gsd tool strips it.
  Stage files by name (no `git add -A`). No agent runs `git push`.
- Windows stays out of scope (phase goal).
