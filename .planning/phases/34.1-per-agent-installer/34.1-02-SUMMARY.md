# Phase 34.1 Plan 02: Host-entry freshness gate Summary

**`npm run freshness:host-entries` regenerates the Codex CLI skill, OpenCode command and Pi template in a temp mirror from the committed generator. It fails on a one-byte drift, an extra or missing entry, or a committed `.gemini/skills/grugops` entry. It runs in the ubuntu CI freshness block, and a test reads that wiring.**

## Accomplishments

- `scripts/host-entries-freshness.ts` follows the skill-twins gate. It keeps SCRIPT_ROOT and KIT_ROOT separate (KIT_ROOT honours CHECK_ROOT). It creates the temp mirror with `mkdtempSync(... "grugops-host-entries-fresh-")` and registers `process.on("exit", cleanup)` straight away. The comment above the hand-written closure list (`generate-host-entries.js`, `is-entry.js`, `host-tools.js`) records the trade-off of keeping that list by hand. The mirrored generator runs with OVERWRITE_FLAG, and CHECK_ROOT is deleted from the child's environment.
- The rendered set is whatever the mirrored run wrote. The gate types no entry path.
- The set check runs before the byte check. EXTRA and MISSING files are named by relative path. The `.gemini/skills/grugops` refusal (D-20) is a separate check. Every committed path is read with `lstatSync` before any read, so a link, directory or FIFO at an entry path is reported, never read through.
- When the gate passes, it prints one line: `Host entries fresh: 3 entries compared, 0 byte difference(s), entry set equal.`
- The ci.yml ubuntu block runs `npm run freshness:host-entries` after `freshness:skill-twins`, with a comment naming D-11 and the wiring at both ends.

## Decisions Made

- The gate imports TEMPLATE_REL and OVERWRITE_FLAG from the generator, so the pointer path is spelled in one place (DI-02).
- The gate derives the rendered set from what the mirrored generator wrote, not from ROUTE_POINTERS. If the generator writes somewhere new, the gate compares that path too, with no change to the gate.
- The D-20 refusal covers the whole `.gemini/skills/grugops` path, not only `SKILL.md`.
- The temp mirror gets its own `package.json`, which the sibling gates do not write. This avoids the Node 26 typeless-package warning behind DI-03.
