**The pre-write refusal is now decided before the agents are chosen. ## Decisions Made

- No agent named, so print the flag-less command, not no command. This is the CONTEXT discretion the plan names. The closing prints `agentCommand(..., [], COMMAND_CONTEXT[, ["--migrate"]])` followed by "installs again; " or "runs --migrate again; ", then DOCTOR_NO_FLAG_CLAUSE. Once the marker is fixed, that command chooses the recorded agents, which is what the verify's "re-run the installer" already says.
- `AGENT_LIST_AT_TERMINAL` compares `process.stdin.isTTY === true`. The original truthiness test is equivalent, since isTTY is `true` or undefined, and the const is typed boolean.
