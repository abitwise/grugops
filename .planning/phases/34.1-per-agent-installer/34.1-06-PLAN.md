<objective>
Decide which agents an unattended install is for (D-03), with one derivation of "which agents are installed here"
(installedAgents) that reads a new recorded `agents` marker field and falls back to the D-23 legacy rule, Copilot's
narrower detect signal (D-24), and the record that install only adds (D-04).

Purpose: the human's direction (G-34-R3-2): do not install for every agent. An existing CI re-run keeps working
because a recorded or legacy install selects what it already has; an empty repository with no flag refuses and says
which flags to pass, instead of silently installing everything.

Output: installedAgents and the `agents` field, the selection and its refusal, the banner line, marker.agents, the
Copilot detect change, tests, and the install guide's unattended rule. The checkbox list at a terminal is plan
34.1-12; until then a terminal run without flags follows the same chain.
</objective>
