## The kit home and install mode uninstall's context carries (D-33, the planner's reading)

uninstall.ts resolves no kit home of its own; uninstall never reads or removes the kit. Its context decides only the
install commands it prints (plan 34.1-25's reinstallCommand): the kit home is the GRUGOPS_HOME the run was given
(non-empty, resolved and spelled as install does), else the `grugopsHome` the target's marker records (an `ok` marker,
or the object of an `unbound` one, whose kit fields the doctor already reads) when it is a non-empty absolute string,
else the default. The install mode is the marker's `installMode` when it is `symlink`, else copy. Without the marker's
values, an uninstall run given no GRUGOPS_HOME would print an install command that writes a second kit into
`~/.grugops`, which is WR-19's harm. An uninstall.js command carries neither (scriptCommand, plan 34.1-22).
