<objective>
Close CR-03, the blocking gap of the re-verification, as decision D-32 sets it. On a partial uninstall the marker
is the only record of the agents that stay, so no printed alternative may tell the user to delete it. The kept `left`
line and the KEPT_FOR banner offer deleting the marker only on a FULL run. On a partial run they name the per-entry
by-hand remedy and say the marker is still the record of the staying agents. install/README.md and the CHANGELOG say
the same. A test follows the printed partial-run alternative and then removes the staying agent.

The same owner (uninstall.ts removeMarker and finishCommand) also closes DI-07 under D-31. DI-07 reads "a verify on a
recorded directory leaves no per-agent finishing command". The planner's search found that no recorded verify ever
lands on a directory entry. A failed rmdir of a recorded directory instead returns `left` with no line at all. So the
remedy is a `left` line for that directory, plus a finishCommand that never names an agent the marker no longer
records.

Purpose: CLAUDE.md requires installers to be reversible, and D-05's job is to remove one agent. The round-1 rewrite
made the installer's own advice destroy the record of the agents that stay (34.1-VERIFICATION.md truth 4, FAILED).
