# Phase 34.1 Plan 22: The printed command carries the run's kit home and script path (WR-19 tracer) Summary

**agentCommand now takes the run's invocation context. The doctor's nothing-installed note prints `GRUGOPS_HOME=<kit home> node <absolute>/install/install.js --target <t> --pi` when the run used a kit home other than `~/.grugops`. The test harness runs a printed command the way a user would: from a scratch directory outside the checkout, with no GRUGOPS_HOME unless the printed text sets one. Run that way, the verifier's reproduction now writes the Pi template, records the run's kit home, and writes no second kit under `<HOME>/.grugops`.**

## Accomplishments

- host-tools.ts (still import-free and pure) has CommandContext, commandContext, scriptCommand and CommandMode. agentCommand takes an optional context and modes. With a context, an install.js command is `[GRUGOPS_HOME=<k>] node <dir>/install.js [--symlink] --target <t> <flags> <modes>`. An uninstall.js command is `node <dir>/uninstall.js --target <t> <flags>`, whatever the context holds. With no context, agentCommand prints exactly what it printed before. That form is transitional: plan 34.1-24 removes it. One shellWord rule quotes the target, the script path and the kit home.
- install.ts builds COMMAND_CONTEXT once, right after GRUGOPS_HOME and KIT_ROOT. It holds the script directory, the kit home this run used (null when it is the default) and `INSTALL_MODE === "symlink"`. The doctor's nothing-installed note passes it. install.ts has 9 other agentCommand calls; plan 34.1-23 moves them.
- The test support's runPrintedCommand runs a printed command in the user's environment and returns its premise (cwd, and the GRUGOPS_HOME the child saw). The earlier runner is now runPrintedCommandInCheckout, used by the 8 call sites not yet moved. printedCommand reads both the absolute and the relative form. The support also adds commandContextFor and RunOptions.omitKitHome.
- The WR-19 row in kit-route.test.ts is the verifier's reproduction, run as printed. agents-record.test.ts has the builder's unit rows and two premise rows.
