## Accomplishments
- The printed-command rule changed in one place. `CommandContext.kitHome` is a path. `commandContextFromRecord` no longer maps the default kit home to null. `RunInvocation` loses `defaultKitHome`, and `contextKitHome` is deleted, so its four callers name `COMMAND_CONTEXT.kitHome`. `scriptCommand` states the kit home on both binaries.
