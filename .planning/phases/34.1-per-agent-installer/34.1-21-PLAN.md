<objective>
Close DI-07 under decision D-31, and make the finishing command of a partial run safe in every arm (MSG-1, D-05).

DI-07 reads "a verify on a recorded directory leaves no per-agent finishing command". The planner's search found that
no recorded verify ever lands on a directory entry. A failed rmdir of a recorded directory instead returns `left` with
no line at all. So the remedy is a `left` line for that directory.

finishCommand on a partial run names the agents it set out to remove that the marker still records. The plan check
found that the empty case is reachable: when the marker rewrite fails on a partial run whose own entries were all
removed, UNFINISHED is empty and the INCOMPLETE banner still prints finishCommand. Today's fallback names NAMED, which
the un-rewritten marker still records. This plan keeps that fallback, adds a last case that is never flag-less, and
forces the state in a row that runs the printed command (R32), so the guard is held by a run, not by an argument
that the arm cannot be reached.

Purpose: the flag-less uninstall command removes every agent. Printing it on a run that named one agent would make
following the installer's own advice remove the agents the user kept.

Output: the failed-rmdir line, finishCommand's explicit partial cases, rows R22, R23 and R32, the parser row, and the
mutation proofs.
</objective>
