# Phase 34.1 Plan 29: Messages about what is installed read one derivation (IN-23, IN-24) Summary

**`installedSplit(rows, entries | null)` is now the one answer to "is anything installed for this agent here". The doctor and install's closing notes both ask it. An agent that was refused and is recorded as chosen is no longer called "Left installed". It gets its own "Recorded as chosen ... nothing is installed for it here" line, with an install command and a command that drops it from the record, and R29 runs the drop command as printed. The doctor's note now says where the agent came from (recorded or legacy). With a malformed ledger the doctor no longer says that nothing is installed for any agent.**

## Accomplishments

What the closing notes print now, after a refused Pi and then `install --claude`:


- **Why:** an equality whose expected side is built by agentCommand alone cannot catch a defect in agentCommand.
