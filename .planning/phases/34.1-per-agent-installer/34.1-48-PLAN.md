<objective>
Finish D-38's printed-command half: the install mode and the kit checkout are stated on every printed command. WR-25
reproduced the mode half (a shell exporting INSTALL_MODE=symlink turned a printed copy-mode remedy into a symlink
install), and the sibling search finds the same encoding for GRUGOPS_SRC. The spelling is decided from the code:
install.js accepts `--symlink` (symlink only) and INSTALL_MODE=copy|symlink (both, anything else exit 2), and has no
copy flag, so the one spelling it accepts for both modes is the INSTALL_MODE assignment; adding a `--copy` flag would
extend the published CLI contract (D-01's note), which D-38 does not ask for. Printed commands therefore carry
`INSTALL_MODE=<mode>` and no `--symlink`. The harness keeps conflicting INSTALL_MODE, GRUGOPS_SRC and TARGET values in
the child's environment.

Purpose: a printed command does what it says in any shell.

a missing GRUGOPS_SRC, or the GRUGOPS_SRC opt-in.

Why fifteen files: as in plan 34.1-47, one builder and one harness change every printed command and every
follow-as-printed row at once; the test edits are expected-value re-pins that must land in the same commit.
</objective>
