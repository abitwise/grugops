# Phase 34.1 Plan 17: The OpenCode external_directory rule described by its scope (WR-18, IN-19) Summary

**The OpenCode rule install writes is no longer called a read rule anywhere outside the planning record. One
sentence, host-tools.ts OPENCODE_RULE_SCOPE, says it allows every tool call OpenCode gates by `external_directory`
on the kit path, edits included, and marks the `edit`-permission interaction `UNKNOWN - verify`. Install prints that
sentence wherever it writes, finds or proposes the rule, and the README carries it word for word. IN-19's stale
header now names the selection.**
