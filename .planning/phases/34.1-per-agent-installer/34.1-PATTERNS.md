## Shared Patterns

- **One authority per rule:** docblocks say "THE ONE AUTHORITY/ONE DERIVATION"; consumers import constants (`KIT_ROUTE`, `PI_PROMPT_REL`) and never re-spell them. Apply to agent flags, entry paths, start-here sentence.
- **Closed tuple + `Record<Kind,…>`** so new kinds are compile errors (`host-tools.ts:29-38,195`).
- **Fail closed:** unusable marker/ledger → `verify(...)` finding, never silent overwrite (`install.ts:5201-5240`).
- **Bad usage = exit 2, one exit site** (`install.ts:262-271`); gate/generator findings = exit 1.
- **Set derived, count asserted** (`HOST_TOOL_COUNT`, host-tools.test.ts).
