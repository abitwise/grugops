## IN-26: which owners install may record again

agentsToRecord adds only ids in `known`, and adds every owner of a holding entry that no kept agent owns. Install
passes `known` = this run's agents (AGENTS_AFTER's registry ids) plus the registry ids that own a holding entry of the
next ledger (nextEntries, entryHolds, entryOwners), and `keep` = AGENTS_AFTER's registry ids. Only a marker whose
`agents` contradicts its ledger can change: a hand edit, or a marker written by the unreleased round-0 uninstall.
- An agent that alone owns a held entry (a Claude Code skill) is recorded again (R30).
- A held shared entry (`.agents/skills/grugops/SKILL.md`) with no recorded owner records both owners, Codex CLI and
  Antigravity CLI (R31). The ledger cannot tell which one install wrote it for (install-marker.ts "WHY A RECORDED
  FIELD"). Recording both keeps the record consistent with the ledger and keeps the file removable per agent
  (`uninstall --codex --antigravity`). This is the review's proposed fix. Uninstall still never adds an owner (its
  `known` is the installed set, T-34.1-27).
