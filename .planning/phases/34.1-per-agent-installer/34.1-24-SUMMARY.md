# Phase 34.1 Plan 24: Every printed command in both binaries carries its module's context Summary

**uninstall.ts builds COMMAND_CONTEXT once and passes it at all four of its agentCommand calls, so every command it prints names uninstall.js by its absolute path and carries no kit home and no `--symlink`. Row R24 runs such a command as printed, with no kit home and from a scratch directory, after an install from another kit home: it finishes the reversal and writes no kit under `<HOME>/.grugops`. The transition is closed: agentCommand's context is required, the checkout runner is deleted, printedCommand reads only the absolute form, and a parser census holds COMMAND_CONTEXT at every builder call in both binaries.**
