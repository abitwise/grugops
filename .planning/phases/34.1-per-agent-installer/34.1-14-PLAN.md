## The D-26 reading this plan implements (flagged for the human)

D-26 says "the flag-less arm never writes `agents: []` beside held entries". REC-1 (the brief) defines the rule by
ownership: an agent stays recorded while the ledger holds an entry it owns, counting shared entries through
entryOwners. This plan implements that. A flag-less kept run records the owners of its held entries (installed ones
only). A held entry with no owner is the D-06 shared footprint, for example an edited AGENTS.md. It keeps no agent
recorded, so `agents` is `[]` beside it, and the printed flag-less command finishes it. The alternative, keeping every
earlier agent recorded, would make `--check` report reach lines and `install.js --yes` re-install agents the user just
removed. Row R6 of agents-record.test.ts pins this reading, so the human can change one row and one rule if they read
D-26 the other way.
