# Phase 34.1 Plan 43: D-37 for a malformed install ledger Summary

**Install's own marker with a malformed install ledger (one ledger entry's kind set to `banana`) is now treated as a record to fix by hand on every run kind. The uninstaller, the installer and `--check` each name readLedger's problem, say "never delete the marker" and print the command to run next. Following that command after the hand fix finishes the uninstall, or brings back a passing check.**
