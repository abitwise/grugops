## Why the doctor's commands are flag-less

`--check` takes no agent flag (D-25) and speaks for the agents the marker records. install.js with no agent flag
chooses that same recorded set when it runs unattended (D-03), and at a terminal it shows the agent list with them
checked (D-02). So the doctor's install command is `agentCommand("install.js", TARGET, [], COMMAND_CONTEXT)`. With no
marker, or one the doctor cannot use, install detects the agents or refuses and names the flags; the remedy text says
so where that applies. The nothing-installed note keeps its one agent's flag (plan 34.1-15).
