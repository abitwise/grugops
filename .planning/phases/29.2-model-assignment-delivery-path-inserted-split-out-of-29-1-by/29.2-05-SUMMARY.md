## Decisions Made

Recorded in the `key-decisions` frontmatter above. The two load-bearing ones:

**`report("cleanup", …)` and not `verify()` — decided, not defaulted.** The review explicitly asked for the choice to be made rather than left implicit. `verify()` increments `VERIFY_FINDINGS`, which drives `process.exitCode = 3`, and exit 3 in this installer means an install *class* was refused and a human must resolve it (D-03). A temp directory the operating system will not release is housekeeping on a run that already completed its work. Reporting it as exit 3 would tell every downstream consumer an install class failed when none did, and would give one exit code two meanings. The argument is written into the source above the block, not only into this summary.

**The hazard guard stays above the relocated preview branch.** A preview over a hazardous destination is still a refusal. Reading through a link is a read this installer was never entitled to take, and `skipped (identical copy present)` must never be printed about bytes outside the target — the property plan 04 bought, preserved through this relocation and pinned by the offset check below.
