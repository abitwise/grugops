<objective>
Make a `models` block written into a target repository reach that repository's adapters.

`install/install.ts` gains one render authority - `renderAdaptersInMirror()` - which mirrors
`scripts/adapters-freshness.ts`'s proven harness into a temp tree, drops the target's own
`.grugops/factory.config.json` in as the one new input, spawns the committed generator, and hands
the rendered bytes to the existing `materializeAdapter()` writer. The install loop keeps
`srcAdapterFiles(GRUGOPS_SRC)` as the SET and uses the mirror only as the per-member BYTE source.
An illegal block refuses the adapter class by name while every other class completes.

**No requirement is new or re-opened.** This plan delivers the installed-target half of
MODEL-01 through MODEL-05; every MODEL row stays as 29.1 left it.

Purpose: closes the limitation 29.1 shipped with - that a per-repo `models` block does not change
the adapters an installed repository loads.
Output: a render helper, a resolution reader probe, a rewired adapter loop, a refusal relay, and
the end-to-end cases that prove each.

<planner_ruling id="R-1" reversibility="reversible">
**D-04 versus the install/ to scripts/ import boundary (RESEARCH Open Question 1).**
`install.ts` holds **no** copy of the announcement grammar and spells **no** prefix literal.
Two halves:
(a) **The banner relays.** Every stdout line the mirrored generator emitted is echoed verbatim
through the existing report channel. The installer authors one line of its own naming the
configuration file it placed into the mirror, or stating that no configuration file was found and
that the run therefore resolved nothing.
(b) **The count comes from the module that owns the grammar.** `install.ts` writes a small fixed
reader script into the mirror beside the twins, spawns it with the generator's stdout on stdin, and
that script imports the **mirrored** `./model-tiers.js` and calls its exported
`resolvedAssignmentsIn` - the one authority for that grammar - printing one JSON line back.
`install/`'s module graph is untouched, so D-18/D-28 is preserved, not reversed; and no sixth
hand-synced literal is created.
Rejected: importing `scripts/model-tiers.ts` into `install.ts` (reverses a recorded decision);
re-spelling `RESOLVED_ASSIGNMENT_PREFIX` in `install.ts` (a second copy of a cross-boundary literal
whose drift direction is silent); skipping the count cross-check (the pattern this milestone exists
to enforce).
</planner_ruling>

<planner_ruling id="R-5" reversibility="reversible">
**No fallback byte source.** If the twins are missing, the spawn cannot start, the generator exits
nonzero, the mirror's output directory cannot be read, or a set or count cross-check disagrees,
then **no adapter is installed**: a finding names the condition and its remedy, every other install
class completes, and the run exits 3. Falling back to the kit-shipped adapter bytes would be a
second byte source and a silent downgrade of a configured target to `inherit` - the shape D-03 and
D-11 both reject. The precedent is already in the file: the unreadable-source arm of the adapter
loop installs nothing rather than guessing. This changes what a partial checkout produces, and the
CHANGELOG entry in plan 03 states it.
</planner_ruling>
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| target repository to installer | `TARGET/.grugops/factory.config.json` is user-authored content the installer copies and a spawned process parses |
| installer to spawned generator | a child process is started and its stdout and stderr are read back and relayed into the run report |
| installer to filesystem | a temp mirror is created, written into, executed from, and removed |

| T-29.2-02 | Tampering | generator OUT_DIR | high | mitigate | `OUT_DIR` stays a fixed literal in the generator with no output flag (T-27-28, ASVS V12); the installer reads the mirror's output directory rather than telling the generator where to write |
| T-29.2-03 | Tampering | config value reaching a path | high | mitigate | Nothing read out of the target's configuration is ever joined onto a path; the file is copied wholesale and only the generator reads values from it |
