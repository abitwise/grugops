### `install/install.ts` — `materializeAdapter()` skip-if-identical + banner slot (utility, file-I/O)

**Analog:** itself, `install/install.ts:1091-1138`; report shape from `linkOrCopy()` `:948-960`.

**Current strip-then-inject core (the three properties any second slot must preserve)** — sentinels
at `:183-185`:

```ts
const MAT_OPEN = "# <!-- grugops:materialized-kit -->";
const MAT_CLOSE = "# <!-- /grugops:materialized-kit -->";
const MAT_SLOT = "# 1. (installed) the absolute kit path the installer wrote above this line.";
```

```ts
// install/install.ts:1100-1138
  const lines = readFileSync(src, "utf8").split("\n");
  const out: string[] = [];
  let inblk = false;
  let buf: string[] = [];
  for (const line of lines) {
    if (line === MAT_OPEN) { inblk = true; buf = []; continue; }
    if (inblk) {
      if (line === MAT_CLOSE) { inblk = false; } else { buf.push(line); }
      continue;
    }
    if (line === MAT_SLOT) {
      out.push(MAT_OPEN); out.push(`KIT="${KIT_ROOT}"`); out.push(MAT_CLOSE); out.push(line);
      continue;
    }
    out.push(line);
  }
  // Unterminated open at EOF: the block never closed → restore what we buffered (lose nothing).
  if (inblk && buf.length > 0) { for (const line of buf) out.push(line); }
  writeFileSync(dest, out.join("\n"));
  report("materialized", `${label} (KIT=${KIT_ROOT})`);
```

Properties: **whole-line equality never a pattern** (`line === MAT_SLOT`, matching
`srcCarriesSlot()`'s `.split("\n").includes(MAT_SLOT)` at `:215-221` so "routing and injection can
never disagree"); **bounded removal (CR-01)**; **content-idempotence**.

**Skip-if-identical report shape to adopt (D-11)** — `install/install.ts:957-960`:

```ts
  if (existsSync(dest) && sameContent(src, dest)) {
    report("skipped", `${label} (identical copy present)`);
```

`sameContent` is `install.ts:250-256` (a `try/catch` string compare, fail-closed to `false`).
**Pitfall 3 (RESEARCH):** build the FINAL bytes in a buffer (slots materialized), compare that
buffer to the target's bytes, then write only on difference — one function serving both D-11 and
D-09's like-for-like compare. Never `sameContent(mirrorFile, targetFile)`.
