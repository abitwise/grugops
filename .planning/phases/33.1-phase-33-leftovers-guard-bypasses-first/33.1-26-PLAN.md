`context.fileName`, and what shape it found. Uninstall reverses only that. A file with no record is left
alone and reported, with the manual remedy. That is the safe answer for a never-installed target and for an
install made before this release. The three interim rules VERIFICATION lists become permanent rules inside
the reversal, not temporary ones.

in because they are on the same file pair. It reports an unparseable file with an uncounted `report("verify")`,
so the banner still says complete and the exit code is 0. It also crashes or silently drops the merge when the
parsed JSON is `null`, an array, or has a non-object `context`.
