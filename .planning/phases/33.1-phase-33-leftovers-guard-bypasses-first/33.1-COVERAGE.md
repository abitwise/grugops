# Phase 33.1 — API coverage matrix

The phase's only external API use is the read-only GitHub REST check in
`scripts/runnable-ref/host-protection.ts` (D-19), reached through `gh api --method GET -i`. grugops never
configures the git host (D-19), so every write capability is an explicit opt-out. The zero-token
harnesses talk to a local mock on 127.0.0.1, not to a model API.

| capability | decision | reason |
|---|---|---|
| GET repos/{owner}/{repo} (default branch) | INTEGRATE | host check reads the default branch name, read-only |
| GET repos/{owner}/{repo}/rules/branches/{branch} | INTEGRATE | ruleset evidence (pull_request, non_fast_forward), readable without admin |
| GET repos/{owner}/{repo}/branches/{branch} | INTEGRATE | classic protected flag, used only to classify a Not Found protection read |
| GET repos/{owner}/{repo}/branches/{branch}/protection | INTEGRATE | classic protection detail; both 404 bodies mapped fail-closed |
| GET repos/{owner}/{repo}/environments | INTEGRATE | production environment required reviewers, readable with read access |
| gh auth status | INTEGRATE | read-only precondition; failure maps every target to UNKNOWN - verify |
| PUT/PATCH/DELETE branch protection | OPT-OUT | D-19: grugops never configures the host; the check is read-only by construction |
| POST/PUT/DELETE repository rulesets | OPT-OUT | D-19: never writes host configuration |
| PUT/DELETE deployment environments | OPT-OUT | D-19: never writes host configuration |
| GitHub GraphQL API | OPT-OUT | not needed; the REST GETs above decide all three verdicts |
| Anthropic Messages API from the harnesses | OPT-OUT | harnesses use a local 127.0.0.1 mock (zero tokens); the one live call is the D-10 capture via the claude CLI |
