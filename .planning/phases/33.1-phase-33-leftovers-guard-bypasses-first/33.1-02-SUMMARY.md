## Accomplishments

- **C1 is one authority.** `canonicalWordValue` (exported) is the only canonical-vs-opaque decision. A word is canonical when it is one of these:
  - an unquoted `CANONICAL_CHARS` run;
  - a single-quoted run of anything;
  - a double-quoted run with no `$`, backtick or backslash;
  - the flag/assignment prefix followed by one such quoted run.

  Everything else is opaque.
- **`classifyWords` uses it.** Each run now records its quote kind (`Run` → `WordRun`), and every canonical decision goes through `canonicalWordValue`. The redundant `sawBackslash` flag is gone.
