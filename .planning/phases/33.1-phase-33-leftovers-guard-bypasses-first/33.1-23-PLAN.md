Design choice (Claude's Discretion under D-19, which leaves the `gh api` endpoints to the planner): the
evidence for "only protected branches can deploy" must be CLASSIC branch protection. GitHub defines
"Protected branches only" in terms of branch protection rules and does not mention rulesets, while
`branches?protected=true` returns branches protected by branch protections OR rulesets. Reading that list
alone would recreate the defect for a ruleset-only repository, so the list is used only to show that NO
branch is protected (then every branch can deploy: `failed`) or to name one branch whose classic protection
is then read. A ruleset-only answer is `UNKNOWN - verify`, which is honest because the documentation does not
say. The README consequence is written by plan 33.1-25.

not show.
