## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Correctness] The subagent request is keyed on the absent spawn id, not on "does not offer Agent"**
- **Found during:** Task 2 (mock extension).
- **Issue:** The plan's sketch issued the `Write` on the first later request that does not offer the Agent tool. CC 2.1.283 lets subagents nest (row 309's primary source), so a subagent's request may offer `Agent`. The case could then never fire and would read `UNKNOWN - verify` by construction.
- **Fix:** Issue the `Write` on the first later request that offers `Write`, carries no `tool_result`, and does not contain `toolu_mock_first`. The main thread's continuation always contains that id.
- **Verification:** the subagent case shows the `Write` with `parent_tool_use_id=toolu_mock_first` in both the measurement and the control.
- **Commit:** `a82b25b9`.

**2. [Rule 2 - Missing critical] A control and an in-target case in the harness**
- **Found during:** Task 2.
- **Issue:** A `denied` verdict alone cannot tell a denying mode from a harness that cannot observe writes. A pin that also blocked in-target writes would red the paid run.
- **Fix:**
  - `--mode bypassPermissions` must read `ran`, and it did in both cases.
  - `--case inside` (not in the default set) writes inside the scoped grant, and it read `ran`.
  - The pin decision still reads only the two default-mode rows.
- **Commit:** `a82b25b9`.

**3. [Rule 2 - Missing critical] `--permission-mode` added to `REQUIRED_FLAGS`**
- **Found during:** Task 2.
- **Issue:** Every flag the live invocation depends on is probed in `--help` before spend (D-10). The pinned flag was not.
- **Fix:** one entry. Every consumer of `REQUIRED_FLAGS` derives from the list, and the dry run now shows `flag --permission-mode in --help | MET` (12 precondition rows).
- **Commit:** `8072c5b8`.

**4. [Rule 1 - Consistency] WR-03 touched four comment sites, not three, and a test-file comment**
- **Found during:** Task 3.
- **Issue:** The review cites three sites. `isWriteShapedCommand`'s "the over-count is the fail-safe direction" is the same claim. The WR-02 block comment in the test file ("never adds a false `pass`") repeats it.
- **Fix:** all were rewritten. The source-reading test forbids "fail-safe direction" as well.
- **Commit:** `b08175ec`.

**5. [Rule 2 - Precision] The version suffix is granted to interpreter words only**
- **Found during:** Task 3.
- **Issue:** A suffix on every word would read `rm2` or `tee3` as writers. The plan says "an interpreter word".
- **Fix:** add `VERSIONED_INTERPRETER_WORDS`, asserted to be a subset of the counted words. Mutation M8 (suffix on every word) is caught by the `rm2` case.
- **Commit:** `b08175ec`.
