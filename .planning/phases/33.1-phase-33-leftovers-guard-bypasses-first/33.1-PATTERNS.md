### `hooks/guard.test.ts` (test, spawn request-response) — WR-04 FIRST (D-05(a))

**Analog:** itself, plus the wrapper's own allow rule in `hooks/hook-entry.ts`.

**The weakness to remove** (`hooks/guard.test.ts:2382-2407`): `runAll` resolves with stdout alone, and
the timeout path kills with `SIGKILL`, so a crash or a hang resolves `""`.
```typescript

  ...

        const child = spawn("node", [...argv], { env, cwd: REPO });
        let stdout = "";
        const timer = setTimeout(() => child.kill("SIGKILL"), SPAWN_TIMEOUT_MS);
        child.stdout.on("data", (d: Buffer) => (stdout += d.toString("utf8")));
        child.stderr.on("data", () => undefined);
        child.on("close", () => {
          clearTimeout(timer);
          resolve(stdout);
        });
        child.stdin.end(reviewPayload(commands[i] as string));
      });
```
Change the resolve to `{ stdout, code, signal, fd3 }`. The `close` event already carries `(code, signal)`.
Keep the 8-worker pool (`:2405`) and the scrubbed env `bare()` (`:2371-2378`) unchanged.

**The allow rule to copy into the new `expectAllowed` helper** (`hooks/hook-entry.ts:527-557`): the
wrapper itself treats a signal, a non-zero exit, and "empty stdout without the fd-3 token" as
not-an-allow. The test helper must hold the same bar:
```typescript

if (child.status !== 0) { denyFailClosed(...) }
const allowChannel = String(child.output?.[3] ?? "");
if (stdout === "" && allowChannel.trim() !== ALLOW_TOKEN) { denyFailClosed(...) }
```
The fd-3 channel is opened by `stdio: [0, "pipe", "inherit", "pipe"]` (`hooks/hook-entry.ts:522`).
For a direct `guard.js` run, spawn with `stdio: ["pipe", "pipe", "pipe", "pipe"]` and read
`child.stdio[3]`. `guard.ts` writes the token before exit and tolerates fd 3 being absent
(`hooks/guard.ts:138-146`), so a direct run with fd 3 open will carry `grugops-hook-allow`.

**The helpers to retire** (`hooks/guard.test.ts:84-92`):
```typescript

}
```
`runGuard` (`:71-82`) already returns `status`; the new helper asserts `status === 0`, the spawnSync
`signal === null`, `stdout === ""`, and the fd-3 token where fd 3 was opened.

and 15 call sites; inline sites at `:417-419`, `:820-821`, `:517`, `:531`, `:666`, `:698`, `:925`,
