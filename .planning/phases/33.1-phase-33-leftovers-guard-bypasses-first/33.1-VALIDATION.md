## Sampling Rate

- **After every task commit:** quick run of every touched test file; for guard tasks also `scripts/autonomy-zero-config.test.ts` + `scripts/floor-invariance.test.ts`, then `npm run generate:hook-manifest` and `npm run freshness:hook-manifest`
- **After every plan wave:** full offline suite + build/parity/typecheck + manifest freshness; after doc edits also `npm run check:banned-claims && npm run check:public-docs`
- **Guard wave gate (D-07):** all of the above + corpus replay report (both entry points) + two independent red-team reports with self-reproductions → blocking human checkpoint
- **Before `/gsd-verify-work`:** full offline suite green; the live capture is never part of an automated gate
- **Max feedback latency:** ~60 seconds per task
