## Sampling Rate

- **After every task commit:** quick run of each touched test file, plus `npm run build && npm run check:build-parity`. For any `scripts/checkpoints.ts` / `scripts/context-io.ts` edit, also `npm run generate:hook-manifest` and `npx vitest run --exclude '**/scripts/e2e/**' hooks/admission-guard.test.ts scripts/floor-invariance.test.ts`.
- **After every plan wave:** full offline suite, then build, generated-artifact and doc gates.
- **Before `/gsd-verify-work`:** full offline suite green. The live capture is never part of an automated gate.
- **Max feedback latency:** per-task quick runs < 120 s; per-wave ~12 min.
