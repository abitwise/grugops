### Residual

- **Install records no backups.** A file with a backup name is never claimed or removed, whoever made it; a backup install did make is reported by its name pattern only.
- **A mode change is a user edit.** A chmod-only change to a kit file now also counts as an edit at re-install (the kit-file record does not hold), so D-32's consent is asked for it. This is the same rule on both sides.
- **Old records.** A record written before the mode was recorded (only builds of this unreleased round wrote one) is still honoured by its bytes; a re-install carries it unchanged while the bytes hold, so it gains a mode only when install next writes that file.
- **An install-created settings file kept after a whitespace edit** is left as the text the removal leaves (for example `{\r\n}\r\n`), with the grugops rules removed and the line saying why.
- **Items 12 and 13** (ask rules removed by name; an unreadable settings file resets the ask ledger) are unchanged, pending plan 33.1-35.
