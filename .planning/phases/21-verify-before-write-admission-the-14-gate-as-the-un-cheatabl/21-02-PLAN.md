gate emits a verdict — a context note authored `by: §14-gate` carrying a unique per-run id from
`node:crypto` — that downstream `finding`s reference as `verified_by: §14-gate#<id>` (D-03, VFY-01).

stamp `by: §14-gate`, which is why the verdict-is-a-finding model does not create an infinite
"every finding needs a stamp" regress.

forked. It also makes the bounded verify→regenerate loop honest by pointing at the EXISTING Step-4
`self_fix_attempts` loop (D-12) and stating the green-only / `UNKNOWN - verify` escape-hatch posture
(D-11, VFY-04).

Purpose: close the loop — Plan 01 admits findings against a real green verdict; this plan is where a
real green verdict is born. Output: an edited single-source gate workflow, clear voice, no fork.
</objective>
