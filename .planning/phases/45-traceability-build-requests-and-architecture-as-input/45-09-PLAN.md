| build-request text → upstream owner's agents | the request travels into another agentic system by a human's hand |

## STRIDE Threat Register

|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-28 | Elevation of privilege | request text read by upstream's agents | medium | mitigate | the contract makes request text structured (question, IDs, options, blocks) with no commands and no text aimed at agents (Pitfall 27) |
| T-45-29 | Spoofing | `human:<name>` in History | medium | mitigate | the contract states it is a prose-tier record, not authentication; the git host and review remain the hard checks |
