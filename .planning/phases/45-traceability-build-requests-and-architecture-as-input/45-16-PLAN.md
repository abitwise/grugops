<objective>
Keep a deviation or floor-conflict request reserved for a named human's withdrawal, whatever path filed or edited it (gap G-45-9b, review finding WR-07; the human ruled "fix WR-06 WR-07").

Today Workflow 20 step 13 recognizes such a request in one way only: its `## Question` says so (step 4). That mark fails on two paths:
- Merge path. Step 3 merges an observation into an existing request that asks the same thing. It adds the ticket to `## Blocks` and writes an `edited` line, but nothing marks the Question. A floor conflict merged into an ordinary `open` request therefore leaves a request that BA/PM may withdraw alone as unneeded.
- Edit path. An `edited` line may follow `open`, and nothing forbids an edit that removes the statement from `## Question`.

The side-door probe (case d) confirmed that the programs accept `withdrawn, by BA/PM` on such an `open` request, and state-check prints `No findings.`. The ticket stays guarded by its human-stop bullet. But the Done condition clause "Every withdrawal of a carried, deviation or floor-conflict request names a human" cannot be checked against the files.

The fix is the review's own proposal:
- Step 13 keys the reservation on something BA/PM does not control through the request text: a ticket in its `## Blocks` that holds a human-stop bullet. Only a named human's word removes that bullet (Workflow 20 bullet (vi), the human's-word stop bullet). The `## Question` statement stays a second mark.
- Step 3 marks the Question in the same `edited` entry when it merges a deviation or a floor conflict.
- The contract forbids an edit that removes the statement from `## Question`.

One planner addition, recorded so a reviewer can reverse it. The contract also forbids an edit that removes from `## Blocks` a ticket that holds a human-stop bullet. Without it, keying step 13 on `## Blocks` opens a new edit-path door: BA/PM edits the held ticket out of `## Blocks`, then withdraws alone. The rule fails closed. A request whose `## Blocks` shares a held ticket with another request is reserved too, even when its own question is ordinary, and only a named human then withdraws it. Once that human lifts the stop, the ticket no longer holds the bullet and the edit is allowed again. The request otherwise stays editable until answered, as D-07 chose.

The optional program check that the gap names is not planned. A request file has no field for its kind (D-05 closed key set). A check keyed on `## Question` wording would be a heuristic detector over free text, the kind this project refuses. A check keyed on ticket bullets would miss the probe case d2, where the bullets are also removed. Human decision 3 (plan 45-13) chose a text-only fix for this family. The residual is accepted as T-45-54. The human can still rule a check later.

Out of scope (not ruled by the human): WR-08, WR-09, IN-10, IN-11, IN-12 and the carried-forward findings. WR-06 is plan 45-15.

Purpose: BA/PM alone cannot withdraw a deviation or floor-conflict request on any path, and the Done condition can be checked against the files.
Output: Workflow 20 steps 3 and 13, the contract's edit rule, the text tests, the disposition rows, and WR-07 recorded as fixed.
</objective>
