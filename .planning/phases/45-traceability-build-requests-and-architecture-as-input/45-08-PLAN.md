<objective>
The structure validator checks ticket citations (TRC-01) and confirms each cited upstream ID exists at its pinned commit (TRC-03), using the decisions of plan 45-06 and the one hardened git read; it adds no rule and no git logic of its own (D-02). It stays exactly v3.0.0 when no `upstream` key is declared, and an unread source is `UNKNOWN - verify`, never a pass and never a failure (D-03).

Recorded choices (reversible, research assumptions A2 and A4): a citation counts from any current note whose refs name the ticket, not only notes `by: ba-pm` (`by` is self-asserted); a missing statement is a WARNING for a ticket not `Done` and nothing for a `Done` one, so declaring `upstream` on an existing repository does not flood it with errors; an undeclared source is an ERROR for a ticket not `Done` and `UNKNOWN - verify` for a `Done` one. Limit stated in the contract by plan 45-09: the validator is dev and CI tooling and is not installed on a scripted-install host (research Pitfall 10).

Purpose: the trail from an upstream decision to a ticket is checked, not trusted.
Output: one context-io reader, two validator arms, the third report list, and their cases.
</objective>

| T-45-26 | Repudiation | the render block | high | mitigate | UNKNOWN lines go to a third list never counted, not promoted by `--strict`, and replace the ALL CHECKS PASSED line, so an unread source is never a pass or a failure (D-03) |
