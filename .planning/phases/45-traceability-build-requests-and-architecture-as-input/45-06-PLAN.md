## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| note refs and BR fields → git arguments | commits and IDs come from agent-written notes and files |
| upstream checkout → git answers | the checkout, its config, grafts, replace refs and shallow state are untrusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-17 | Tampering | upstreamGitManifestAt / upstreamGitDescends arguments | high | mitigate | every commit passes UPSTREAM_OBJECT_ID_RE (hex only, never a leading `-`) and every source resolves only through the declaration; `shell: false` |
| T-45-18 | Tampering | ancestry answer | medium | mitigate | GIT_NO_REPLACE_OBJECTS and GIT_GRAFT_FILE set to the null device on the ancestry call; shallow clone answers UNKNOWN; `not-descendant` is only ever a warning (D-11) |
| T-45-19 | Information disclosure | new read paths in a partial clone | high | mitigate | upstreamGitOpen runs the partial-clone guard before any object read for every new function (tested with versionedGitDir and a recording log) |
| T-45-20 | Tampering | `upstream.escalation_days` | low | mitigate | closed parse: a safe integer of at least 1, refused by name otherwise |
| T-45-SC | Tampering | npm/pip/cargo installs | low | accept | this plan installs no package |
</threat_model>
