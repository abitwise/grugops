<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BR files and config → git arguments | `pin` and `source` come from agent-written files |
| requests stdout → Orchestrator | the report decides what the agent asks the human |
| upstream checkout → git answers | shallow, grafted or partial clones can mislead |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-45-21 | Elevation of privilege | requests output | high | mitigate | only grammar-checked fields and git reasons already printed by `check` reach stdout, through `printable`; a planted marker in a question never appears (tested) |
| T-45-22 | Repudiation | requests verb | high | mitigate | no write path; product, config and upstream digests unchanged by a run printing every kind (tested); a pin moves only by a named human's commit |
| T-45-23 | Tampering | `pin` / `source` from a BR file | high | mitigate | parsed by the closed grammar (UPSTREAM_OBJECT_ID_RE, UPSTREAM_SOURCE_ID_RE) before any use; the source resolves only through the declaration; length checked against the declared pin |
| T-45-24 | Tampering | ancestry and changed-ID answers | medium | mitigate | shallow clone gives UNKNOWN; grafts and replace refs neutralized by the launcher (plan 45-06); `not-descendant` is a warning only, and the human decides the answer |
| T-45-SC | Tampering | npm/pip/cargo installs | low | accept | this plan installs no package |
</threat_model>
