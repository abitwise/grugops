<objective>
Apply the profile to the thirteen shipped seed templates and the two contracts — the last part of the
governed corpus — and correct the board template's stale column entry criterion.

This part of the corpus is where D-16's surface split becomes concrete. LANG-02 names six surfaces, and
three of them — the shared-context notes, the board and the traceability trail — are runtime artifacts
that do not exist at build time in this repository. What does exist is the templates the kit ships for
them, and those are what the guard governs. The runtime instances an agent writes carry the profile as
instruction through the context read-write workflow. Saying the guard governs a note an agent writes at
runtime would be the overstated-claim class the registry exists to hold, which is why the profile states
the split in its own words rather than leaving it implied by a scan set.

Two of these files are more than prose. The context-note contract defines the note kinds, and the board
template defines the board columns; both are derivation inputs for the project Technical Names set the
guard itself reads. A column or kind renamed for style would change the guard's vocabulary as a side
effect of a style edit, so those names are out of scope for rewording and only the prose around them
conforms.

D-46's last correction lands here. The board template carries a column entry criterion requiring an
artifact this project deleted two milestones ago, and it survived because the kit-reference scan
deliberately excludes the seed directory as state templates rather than live kit references. It is a
shipped template, so a project bootstrapped from it inherits the stale criterion.

Purpose: finish the governed corpus so both new predicates go green having been watched failing first.
Output: fifteen conforming files, one corrected board criterion, and a disposition file.
</objective>
