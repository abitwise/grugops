<objective>
Close **WR-02** of `29-REVIEW.md` (round 4).

`readRegistry` declares two tallies and refuses when the shared locator's block count differs from
"heading-shaped lines minus heading-shaped fenced lines". Both expressions consume the SAME
`CLAIM_HEADING_RE` and the SAME `fencedLineFlags(text)` over the same text, so the identity
`|re and not flags| = |re| − |re and flags|` holds unconditionally. **No input can make this refusal
fire.**

The comment above it asserts the opposite in so many words: that the block is two separate expressions
"never by one expression and a subtraction of its own output, which is 29-REVIEW § WR-03's shape one layer
down." It is exactly that shape, on the wrong side of the sentence. The version this round got right sits
one file over — the duplicate-assertion census counts OCCURRENCES with a `g`-flagged match against a
classifier that counts LINES, two answers of different kinds which can genuinely disagree.

This is not cosmetic. `readRegistry`'s claims feed `safetySurfaceUnion`, which feeds the D-18 exclusion
list that decides which files a controlled-language pass may never touch. A projection whose published
denominator cannot contradict it is a number that can be short against nothing, in the one parse whose
shortness silently shrinks a safety exclusion.

Purpose: per D-08 the published figure must be a measurement, and a measurement needs a witness that can
disagree with it. Per LANG-07 the correction must not buy that witness by adding a second fence traversal —
one fence verdict, consulted once.

Output: a witness that differs in kind, proven able to fire by a recogniser-drift mutation, and a comment
that describes the block that ships.
</objective>
