absent literal reads to the next editor as an oversight worth fixing, which is exactly why this module

enumeration did not have: a co-occurrence WINDOW. The window is a line, this scanner's line is whatever
falls between two line feeds, and the governed corpus is soft-wrapped prose. This phase's terminal lesson
is to ask at WHICH POSITIONS the predicate is even asked — not only which characters it accepts — and the
round that unified two parsers still shipped a scope defect because nobody asked what BOUNDS the new
authority's input.

proven able to fail, a refusal with a number beside it, and an attack whose attempts are written down
including the ones that succeeded.
