<objective>
Close LANG-06's round-3 gap: the fail-open REGRESSION that round 2's own structural fix created
(29-REVIEW.md CR-01, plus WR-01).

Round 2 made `readCavemanFence`'s section bound fence-aware by delegating to `frontmatter.ts`'s
`sectionEndIndex`. The authority is correct. The consumer's use of it is not: the caveman fence's OWN
INTERIOR is flagged by the fence toggle, so a `#`/`##` heading written between the opening and closing

in `inside`, and `outside` can be driven to the empty string — at which point `guard_voice` scans zero
bytes and prints a bare PASS with no denominator. The identical bytes were refused `unterminated` at
`3ed76c1`. This is the phase's founding defect, reopened.

Purpose: this plan is sequenced FIRST and everything else in round 3 depends on it, because every
later plan's "all seven gates exit 0" evidence is worth nothing while the guard the phase exists to
build can measure zero bytes and pass.

Output: a fail-closed caveman reader, a `guard_voice` that publishes what it measured, a module header
that states the shipped fail direction, and permanent two-sided cases for both.
</objective>
