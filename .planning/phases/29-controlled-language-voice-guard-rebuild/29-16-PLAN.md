<objective>
Close the three findings in `guard_diff_disposition` that 29-15 deliberately left alone, each of
which is the same failure at a different altitude: a predicate deciding membership by excluding one
bad value, a locator deciding an extent with a second grammar, and a vacuity floor comparing an
object with itself.

WR-05 is the arm that carries the whole positional freeze. A companion cell containing a hyphen, an
en dash, `n/a`, `TBD`, `?` or `none` is neither empty nor the one em dash the code excludes, so it
satisfies the companion requirement for a change inside a frozen `## Hard limits`, `## Stop
conditions` or `## Commit` section. The fix is not a longer list of rejected glyphs. It is a canonical
FILLED form — prose of at least a declared minimum length — with everything outside it refused. That
is D-64's move, the one that closed Phase 27 at round twelve after eleven rounds of widening a parser
one more time, and it is D-43's polarity: declare the legal spelling, refuse the complement, consult
no character class.

WR-06 is a second grammar over the same bytes, which is this phase's own stated defect class. Three
locators in this repository decide "where does this section end" with a bare heading-prefix scan while
`fencedLineFlags` — the single fence toggle — already exists and is already consumed by a sibling
gate for exactly this question. In this gate the direction fails OPEN: a `## ` inside a fenced example
truncates a frozen region, shrinking what is protected with no failure at all.

WR-02 is the shared vacuity rule receiving a denominator derived from the very array the loop counts,
so its second branch can never fire. This gate's own module argues elsewhere that once both sides read
the same object, the comparison is documentation of intent and never a check.

Purpose: make the last live arm of the frozen set enforceable, its extent fence-aware, and its
published denominator independent.
Output: a canonical companion predicate, a fence-aware section locator, an independent denominator
with a named set refusal, and three planted fixtures that prove each — because all three are
behaviour-preserving on the live corpus and a corpus-derived proof would prove nothing.
</objective>
