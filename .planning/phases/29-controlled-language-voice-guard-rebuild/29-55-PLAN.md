everything the round claims.

round-6 record is 1173 lines because the value is in the reconciliation, not in the summary. This one has a

remedy is the one plan 29-46 established: delete the number or name the thing that holds it.

<standing_rules>
The house rules of this phase, encoded rather than advised. The six that bite hardest here:

- **A green suite is not proof for a safety invariant.** Every closure claim is reproduced on a hermetic
  `git archive HEAD` mirror with a sha256-verified gate binary, one plant per reset mirror, the premise
  asserted green before the plant, the plant confirmed on disk before the run.
- **Assert the verification harness's own premise.** This phase has produced a false harness result in six
  instances across four straight rounds, one of them by a round's own adversarial pass. A transcript whose
  premise was not asserted is not evidence, and this register is where that rule is applied hardest.
- **No silent drops.** Every finding, every residual, every narrowed remainder gets a visible disposition
  with a live count and a direction. A closure stated wider than its measurement is a silent drop wearing a
  tick.
- **A trail is not a tidy state.** Prior registers' bodies are history and are not rewritten; this round's
  record states what changed and cites the earlier text rather than editing it.
- **A stale number is deleted, never replaced by a fresher one in the same place.**
- **Build facts (D-13).** The sweep runs `npm run build`, `npm run freshness`, `npx tsc --noEmit`, every
  freshness gate, all seven repository gates and `npx vitest run --exclude '**/scripts/e2e/**'` — never a
  bare `npm test`, which spawns the live claude CLI, spends tokens and can hang.
</standing_rules>
