<objective>
Close the two findings that make every other fix in this round provable: IN-01, the harness that
derives its own membership from the wrong tree, and CR-01, the founding defect of the whole phase
reintroduced through the new single reader.

CR-01 is the phase's own thesis failing on itself. `scripts/voice-model.ts` exists because two fence
machines disagreed over the same bytes; its module header states the predicate as "WHERE IS THE
SECTION-ANCHORED CAVEMAN FENCE" and the implementation is not section-anchored. It finds the
`## Caveman prompt` heading and then scans to end of file for a delimiter, so a role whose caveman
section is reworded into plain senior prose adopts an unrelated later code block as "the caveman
block" — and both voice guards then publish a measured number about the wrong bytes and pass. The
project's standing question is what BOUNDS a predicate's input, not what characters it accepts, and
this is a pure scope bug (D-22, D-23).

IN-01 comes first inside this plan because it is the instrument. `roleTextsIn(root)` calls
`listRoles()` with no argument, so it lists the REAL repository's roles and then reads each name from
the mirror. A case that plants an eighteenth role into a mirror measures a set the guard did not, and
the evidence for every other fix in this round is only as sound as the harness producing it. Phase 27
recorded the verification harness producing a FALSE result in six instances across four straight
rounds; this is a live instance of exactly that.

Purpose: make the harness measure what it claims to measure, then close the founding defect
end-to-end — structural fix, permanent tests, adversarial self-reproduction, gate green — proving the
shape the four following plans repeat.
Output: a section-bounded fence reader, a root-honest harness, four new permanent cases, and two
recorded transcripts.
</objective>

This phase's surface is build-time guards over local markdown. There is no network call, no user
input, no credential and no persisted state. The boundaries that genuinely exist are named below;
canon web-application threats (injection, path traversal from a request, session handling) have no
counterpart here and are not minted.

| Boundary | Description |
|----------|-------------|
| repository bytes → guard verdict | Arbitrary committed markdown is parsed by a reader whose verdict decides whether the build is green. A reader that reaches outside its stated scope measures the wrong bytes and publishes a number about them. |
| test harness → evidence | The harness is the only instrument that proves a guard fixed; a harness deriving its input set from a tree other than the one it measures fabricates evidence without anyone lying. |
| temporary plant → committed tree | An adversarial reproduction writes a deliberately broken file into a working tree that is otherwise clean. |
