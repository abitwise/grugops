<objective>
Close **CR-02 / G-29-2** — by deleting the enumeration rather than relocating it for a third time.

Round 5 was ordered, by an explicit user decision, to replace a six-phrase comprehension enumeration with
a structural rule. What shipped was a seven-stem hand-authored verb list gating the bare term through the
same-line arm — the identical defect one slot to the left. Five plants reproduce it at exit 0 with the
planted file never named: `increases comprehension`, `raises comprehension`, `gives models sharper
comprehension`, `aids comprehension`, and `makes models understand prose faster`.

The reviewer's proposed remedy was to pin the SUBJECT side instead. D-48 refuses it, and the reason is the
one this repository has now paid for three times: `controlled language`, `this profile`, `the kit`, `the
voice` is a third hand-authored list over an equally open class — `grugops`, `the factory`, `these roles`,
a pronoun — so it buys exactly one round. **Every axis a bare term can be paired against is an open class.
The only bounded thing in this design is the one named exemption region, and a region is positional.**

So the carve-out becomes positional and the lexical half is deleted. The bare terms become unconditional
literals, the same-line arm goes, and the marker constant is deleted rather than replaced. This is D-64's
canonical-form move — define the admitted form, refuse everything outside it — applied to a prohibition
instead of to a parser, and it deletes a set literal instead of authoring one.

**And D-53 extends it to the group that gives the gate its name.** Authoring this plan set surfaced that
the identical defect survives one member over: `Simplified Technical English` is gated by a six-stem
conformance list, so `follows` / `meets` / `adheres to` / `is written in` each yield ZERO findings while
`conforms to` yields one. Under D-48's own arithmetic the fix is free — the term occurs on exactly two
lines and both are inside the exemption region — so the same move applies rather than being deferred to a
seventh round. `CONFORMANCE_VERB_MARKERS` is deleted alongside the benefit list, all three bare-term
members become unconditional, and conditional members go **3 → 0**.

**The field goes with them, out of the TYPE.** `requiresOnSameLine` is removed from `BannedClaimLiteral`
rather than left empty, because an emptied list leaves the mechanism standing for the next member to reach
for while a removed field makes reintroducing a marker list a visible type change in a diff. The gate's
whole predicate becomes *a pinned literal list plus one named exemption region*.

Purpose: the fix shape that held in Phase 27 and in plan 29-40 was deletion of a duplicate grammar, not
another arm. This is the same move against the second systemic failure mode this repository names — and
this time it is applied to both groups at once rather than to the one the review happened to name.

Output: both marker constants gone; the field gone from the type; three unconditional terms; the one
ordinary-English occurrence rephrased rather than exempted; every pin the change moves re-derived through
the gate's own counter and every pin whose subject it removes retired with its reason; and the source
prose that claimed the spelling problem was closed corrected to say what actually happened.
</objective>
