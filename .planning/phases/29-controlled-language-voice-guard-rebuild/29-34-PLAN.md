<objective>
Close **WR-04** and **WR-05** of `29-REVIEW.md` (round 4). Both are the same mistake seen from two
sides, and the repository has already written the lesson down: *a vacuity floor catches an EMPTY
denominator but never a SILENTLY SHORT one.*

**WR-04.** `guard_voice`'s element floor reads `if (bodyLines.length === 0 || body.trim() === "")`.
`"".split("\n")` is `[""]`, never `[]`, so `bodyLines.length` is at least 1 for every string and the
first disjunct is unreachable-false. Only the second ever fires, and the finding it produces then reports
`collapsed to 1 line(s) with no content`. The module header at `:2100-2101` states the floor as "a
scanned line count of ZERO on any voice file is a finding" — a condition that cannot occur. Its paired
assertion in `voice-model.test.ts:486-493` is the same mistake: `outside.split("\n").length` is asserted
`toBeGreaterThan(0)`, which is true of every possible value, and its own comment picks that half
deliberately "because that is the number guard_voice now publishes per file, so the two cannot drift
apart" — the half chosen for the drift argument is the vacuous half.

**WR-05.** Round-3 CR-01's second remedy was to publish AND two-side-pin what `guard_voice` actually
scanned. What shipped publishes the number and pins only its zero-content case. The denominator that
exists (`visited`/`expected`) is at the FILE level, not the LINE level, so a remainder driven from 45
lines to one non-blank line prints `scanned 1 clear-voice line(s)` and passes.

Purpose: per D-08 the PASS line must carry a measurement, and a measurement with no independent witness
is a description. Per D-22 the number that says how many lines the caveman region took must come from the
ONE reader that owns those indices — the guard recomputing it would be the two-grammar defect this phase
exists to delete.

Output: an accounting identity published per file and refused by name when it fails, a floor stated as a
reachable condition, a non-vacuous test assertion, and WR-05's remaining half recorded as a measured,
named residual rather than as 19 new hand-maintained baselines.
</objective>
