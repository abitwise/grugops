<objective>
Build the capture instrument as ONE production-quality end-to-end slice, proven at zero tokens.

This is the phase's tracer. `scripts/capture-live.ts` is wired through every layer the capture will
use — preconditions, install into a scratch target, frame ingest, the four derivations (D-02 CAP-03,
D-04 deny attribution, D-05 plugin provenance, D-07 dual-path equivalence), redaction (D-06) and
summary emission with the frozen outcome line — and the whole path is exercised by `--dry-run`
against a committed fixture JSONL, making no model call (D-10). D-01 fixes the instrument as the
headless `stream-json` transcript and nothing else; D-08 fixes it as one runner compiled to a
committed `.js`.

Nothing here is a prototype. Every predicate that the live run of plan 33-10 will rely on is written
for keeps and is red-and-green tested offline first, because this project's recorded failure mode is
a green suite that proved nothing about a safety-bearing predicate.

Purpose: prove the capture architecture end-to-end before a single token is spent, so a schema or
protocol dead-end costs one commit instead of a 4.33 USD live round.
Output: `scripts/capture-live.ts` + committed `.js`, its offline test suite, the fixture JSONL, and
the runnable fixture project.
</objective>

<assumption_delta_decision>
Now-primary noun: **two capture paths where there was one instrument**. The phase's live evidence is
no longer a single `claude -p` invocation inside a test; it is a *pair* of runs (D-07: the AGENTS.md
sequential path and the `--agent` spawn path) driven by one runner, plus a *pair* of D-02(a)
observables (nested `parent_tool_use_id` frames OR a `system/task_notification` joined by
`tool_use_id`, because `run_in_background` defaults to true).

Decision: **add-alongside**. The transcript stays the single instrument (D-01); the runner takes a
run *identifier* parameter and the predicate accepts either observable and records which one fired.
Rationale: promoting either observable to "the" observable would red a correct run — the background
default is not under this project's control.
</assumption_delta_decision>

| Boundary | Description |
