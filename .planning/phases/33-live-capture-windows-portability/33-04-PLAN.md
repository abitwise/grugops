<objective>
Close the separator class on its OTHER side: the comparisons that are never published.

RESEARCH Pitfall 3 is explicit that over-applying D-15 is its own defect — the tracked-TypeScript
census in `scripts/validate.test.ts` builds its set from a directory walk and compares it against
`git ls-files`, which always emits forward slashes. Twenty-six tracked sources in subdirectories of
`scripts/` therefore read as unscanned on Windows, and there is no publishing boundary to fix,
because the set is never published. The same is true of the watcher test's armed-directory list —
which RESEARCH measured as the actual carrier of the six `.grugops` separator assertion failures
CONTEXT attributed to four production modules.

This plan also closes the genuine exit-status class: six assertions expect a numeric exit code and
receive a null status, because the child was terminated by a signal rather than exiting.

Purpose: make the comparisons separator-honest without moving a single published byte.
Output: one spelling on both sides of every test-internal path comparison, and signal-aware child
assertions that name what happened instead of expecting what the platform never produces.
</objective>
