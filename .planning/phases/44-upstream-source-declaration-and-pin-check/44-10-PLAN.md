## Fixed reasons this plan introduces (exact text; tests and the contract pin these)

Manifest reasons from parseManifest (pinState prints each as `manifest: <reason>, line <n>`):

| Cell | Reason |
|------|--------|
| ID, fails the ID grammar (empty included) | `the ID cell (column 1) does not match the upstream ID grammar` |
| ID, repeated | `ID <ID> is listed more than once` (unchanged: the ID passed the grammar) |
| Status, not `locked` or `superseded` (empty included) | `the Status cell (column 2) of <ID> is not one of: locked, superseded` |
| Path, fails the path grammar (empty included) | `the Path cell (column 3) of <ID> is not a manifest path` (plan 44-09) |
| Superseded by, on a locked row | `<ID> is locked and must not name a successor` (unchanged) |
| Superseded by, empty on a superseded row | `<ID> is superseded and must name its successor` (unchanged) |
| Superseded by, fails the ID grammar | `the Superseded by cell (column 4) of <ID> does not match the upstream ID grammar` (new check) |
| Superseded by, names an unlisted ID | `the Superseded by cell (column 4) of <ID> names an ID the manifest does not list` |
| Supersession cycle | unchanged (names only grammar-checked IDs) |

Runnable reasons (scripts/runnable-ref/upstream.ts hand-written part):

- `check` listed-file sweep: `the file listed for <ID> (manifest line <n>, column 3) is not a regular file at the pin`
- `read` label `<L>`: `the file listed for <ID>` for an ID target, `the entry manifest` for `--manifest`
- `read` exit-1 reasons: `<L> is not a regular file at the pin`; `<L> is over the per-read ceiling (<n> bytes; the ceiling is 65536); ask upstream to split it`; `<L> is not a text file (it contains a NUL byte)`; `<L> is not UTF-8 text`; unchanged: `<ID> is not listed in the manifest at the pin` and `blob-mismatch (declared <x>, at the pin <y>)`
- `read` exit-2 messages use `<L>` too: `git cat-file gave no size for <L>` and `the bytes git returned for <L> do not hash to <blob>. Nothing was printed.`
