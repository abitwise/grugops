## Read output grammar (extends plan 44-01's grammar)

- Usage: `node upstream.js read <source> <ID>` or `node upstream.js read <source> --manifest`, each with optional `--root <dir>`.
- Exit 0: an optional `superseded <ID> by <successor>` line, then the D-17 BEGIN line, the content lines, then the D-17 END line. Content that does not end in LF gets one LF before the END line.
- Exit 1: exactly one stdout line `refused <source> <ID or --manifest>: <reason>`, no content.
- Exit 2: nothing on stdout, one `Error: ` line on stderr (an `UNKNOWN - verify` state names its reason in that line).
- `head-moved` alone never stops a read; the read is at the pin.
