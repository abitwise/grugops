## Output grammar this phase fixes (every later plan uses it verbatim)

`check` prints, per declared source in config order, one line per cause:
- `match <id> <commit>`
- `drift <id>: blob-mismatch (declared <entry_blob>, at the pin <blob>)`
- `drift <id>: head-moved (HEAD <head>, pin <commit>)`
- `UNKNOWN - verify <id>: <reason>`

When a source has both drift causes, `blob-mismatch` is printed before `head-moved`. An `UNKNOWN - verify` cause is terminal for that source: no other line is printed for it. With no declaration it prints exactly `no upstream sources declared`. Exit code (research Option A, rated `costly`, see Task 1): 2 when any source is `UNKNOWN - verify`, else 1 when any source drifts, else 0. A run that cannot start (bad argument, no `.grugops/` directory, unreadable or invalid JSON config, malformed `upstream` declaration) exits 2 with nothing on stdout and one `Error: ` line on stderr. All stdout lines are written in one write at the end.
