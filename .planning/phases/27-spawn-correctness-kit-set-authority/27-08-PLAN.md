<objective>
Add the two adapter-body guards this phase owes, and give the retired vocabulary exactly one home.

SPAWN-05's own wording conflated two different things, and the resolution matters because getting it
wrong makes a guard fail red on text that was deliberately kept. The surviving line in the live adapter
carries both a retired memory-relay phrase and a still-correct execution-topology phrase. The relay
phrasing is dead: the static handoff templates were deleted and the shared verified context replaced
them. The topology phrasing — a single window with prior context dropped between roles — is still
correct, describes how roles activate on the four non-spawning host CLIs, is verbatim in the packaging
template, and is the degraded tier's own wording under the revised D-02. A guard banning single-window
prose would fail red on text this phase deliberately preserves.

So per D-23 the guard checks **both directions**: it bans the retired relay vocabulary, and it asserts
every adapter body names the shared verified context as its memory. The positive half is the one that
matters most, because it catches an adapter gone stale by omission and does not depend on having guessed
every retired phrase.

Per D-24 the retired vocabulary lives in one exported module consumed by both checks. The two checks are
genuinely different predicates — the kit-reference assertion greps the deleted templates' **directory
path**, while the surviving adapter line contains no path at all — so a second check is justified. A
second list is not.

Per D-26 this guard is defense in depth and never the structural fix. Once the coordinator adapter is
generated from the template in plan `27-07`, the retired line dies structurally, because the template
already carries the correct memory wording. The guard exists to catch a hand-edit and a template
regression.

The other half of the plan is `guard_wr05`. Under the revised D-05 it asserts **tier-announcement
presence** — the coordinator body carries all three tiers of the revised D-02 and the capability-sensing
check that selects between them — plus the SPAWN-04 property that no non-coordinator adapter carries a
spawn-tool token. Both mechanisms hold on the subagent and main-thread paths, so no wiring artifact needs
to exist in a user's repository for the guard to be meaningful. It asserts no settings-file entry, because
under D-01 there is none.

Purpose: the structural fix landed in plan `27-07`; this plan makes a regression fail red rather than ship.
Output: one retired-vocabulary module, one new both-direction guard, an extended spawn-grant guard, and
planted regression cases for every branch.
</objective>
