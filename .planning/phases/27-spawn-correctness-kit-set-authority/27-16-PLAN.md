<objective>
Build the procedure and the recording surface for the one check no command can perform.

The runtime half of the coordinator requirement is honestly open, not defective. The previous plan
performed and recorded the two observable steps — a scratch install, and a coordinator adapter
carrying a materialized absolute kit line that resolves — and explicitly left the two interactive
steps unperformed rather than fabricating them. The platform runtime is the system under test, the
session startup header is an interactive terminal element, and whether a distinct role agent resolves
and runs cannot be observed from any command in this repository. A print-mode invocation would spend
tokens without emitting the header.

What is missing is not a claim. It is the apparatus: a single command that discharges every
precondition mechanically so the human step is two minutes rather than twenty, and one place for the
observation to land so the result is a committed artifact rather than a sentence in a chat log.

This plan builds both, and builds them so they cannot lie. The precheck asserts only what it can
observe and says so in its own success wording. The recording surface ships with empty slots and an
unverified status, so an unfilled file reads as unfilled rather than as a pass.

Purpose: make the human step cheap, scripted and recorded, without letting any part of it be faked.
Output: one precheck command, its test, one evidence file, and the validation row that points at both.
</objective>

    coordinator grant names an agent with no adapter file exits non-zero naming that agent. Assert
