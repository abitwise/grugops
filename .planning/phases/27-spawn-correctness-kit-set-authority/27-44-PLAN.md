```
SWEEP_SCALAR_STYLE      6 members, every one opening its scalar as the FIRST TOKEN after the key
                        on the key line, or as the FIRST TOKEN of a block-sequence item
                        -> no style where the value node begins on a continuation line
                        -> no flow-collection style at all

                        -> a claim about the product of two hand-listed axes, not about YAML

loader cross-check      6 NAMED cells, one per style, with a printed skip
                        -> the MECHANISM is right and already established; the SCOPE is six cells
```

## The harness, stated once

```
CORPUS      a cross-product of three axes, enumerated as DATA:
              key-line shape        value on the key line | no value | comment-only value |
                                    trailing whitespace only | flow-sequence opener |
                                    flow-mapping opener | literal indicator | folded indicator |
                                    block-sequence dash with no value
              continuation 1        opens a double-quoted scalar | opens a single-quoted scalar |
                                    plain text | a hash at position 0 | a dash at position 0 |
                                    a sigil at position 0
              continuation 2        carries the token after a hash | carries the token plainly |
                                    closes the quote after the token | closes the collection

EXPECTED    the loader's answer. One `/usr/bin/ruby -ryaml` process receives the whole corpus as a
            JSON array of frontmatter regions and returns a JSON array of {accepted, tools-value}.
            A cell the loader REJECTS is SKIPPED and the skip is PRINTED with its cell labels.

ASSERTED    for every accepted cell, the module's token-presence answer equals the loader's.
            Disagreements are collected and reported as data; the assertion is that the set is
            empty, minus the named exemptions.

EXEMPTIONS  each named with its reason and its bound, in the shape the delimiter region's one
            legitimate exemption already uses. Only the SAFE direction may be exempted: the module
            refusing where the loader grants. A module GRANT where the loader does not, or a
            module NO-GRANT where the loader grants, is never exemptible.

NON-CIRCULAR  the corpus generator's source is read back and asserted to name no module symbol;
              the expected value is the loader's, so no function of the module contributes to it.
```
