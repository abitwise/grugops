<objective>
Give the adapter set the authority treatment the role set already has, and prove it end-to-end
against the exact bypass that was reproduced.

`scripts/kit-model.ts` is a real single authority for roles and workflows. The adapter set never got
the same treatment: five files each answer "what is an adapter" with their own directory read, four
of them non-recursively, while the platform discovers the agents directory recursively and takes
identity only from frontmatter. A file planted one directory deeper is therefore loaded by the
runtime and invisible to the spawn-grant guard, the adapter-body guard, the byte-ceiling guard and
the referential-integrity oracle simultaneously. That was reproduced: a second live coordinator with
its own enumerated grant, planted at a nested path, left every gate reporting all checks passed and
the oracle still printing seventeen roles equal to seventeen adapters.

This is a set-literal defect that moved from a hand-listed name into a hand-written derivation rule.
The fix is structural in the way this project has already proven twice: one format-aware authority
per predicate, and the duplicate grammar deleted rather than corrected in place.

This plan is the tracer. Task 1 wires the thinnest complete path — authority, one real consumer,
guard output, planted-bypass RED test — before any other consumer is repointed. Tasks 2 and 3 expand
along the same seam to the skill half and to the oracle's own second directory read.

Purpose: make the adapter set a derived fact with exactly one answer, so a file the platform will
load cannot land outside the guards.
Output: two new exported authorities, one deleted duplicate derivation inside the foundation guards,
a named refusal for the nested case, and RED tests that plant the real bypass.
</objective>
