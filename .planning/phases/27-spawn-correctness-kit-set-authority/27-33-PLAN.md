## MEASURED AMENDMENT TO D-39 POINT 3 — READ BEFORE IMPLEMENTING (D-42)

D-39 point 3 defines the refusal set as the disagreement between the module's own two grammars, with
*near-delimiter* spelled `line.trim() === "---"`. **That spelling is measurably too narrow, and
implementing it literally would ship round 6.**

`String.prototype.trim()` strips ECMAScript WhiteSpace and LineTerminator — the `Zs` category plus tab,
vertical tab, form feed, space, no-break space and U+FEFF. It does **not** strip the **format**
character class (`Cf`), and U+200B ZERO WIDTH SPACE left `Zs` in Unicode 4.0.1. Measured on this
repository's committed `scripts/frontmatter.js` and on `trim()` directly:

| Spelling at the opening delimiter | live `hasSpawnGrant` today | caught by `trim()`-based `near`? |
|---|---|---|
| `---` (control) | `{ok:true,value:true}` | n/a — legal, must stay legal |
| `---` + trailing space / tab (controls) | `{ok:true,value:true}` | n/a — legal, must stay legal |
| U+FEFF byte-order mark, leading | `{ok:true,value:false}` | yes |
| U+00A0 no-break space, trailing | `{ok:true,value:false}` | yes |
| U+000C form feed, trailing | `{ok:true,value:false}` | yes |
| U+0020 space, **leading** | `{ok:true,value:false}` | yes |
| **U+200B zero-width space, trailing** | `{ok:true,value:false}` | **NO — stays a silent success** |
| **U+200D zero-width joiner, trailing** | `{ok:true,value:false}` | **NO** |
| **U+00AD soft hyphen, trailing** | `{ok:true,value:false}` | **NO** |
| **U+2060 word joiner, trailing** | `{ok:true,value:false}` | **NO** |

Swept across every code point matching `[\s\p{Cf}\p{Cc}]` minus the line feed — **253 code points, 506
positions (leading and trailing)** — the `trim()`-based predicate **misses 458 of 506**. D-39's own
rationale names zero-width space among the six spellings it exists to close, so the literal reading
does not deliver the decision's own stated evidence.

**The amendment keeps D-39's polarity exactly and widens only the alphabet.** Define the payload
(`---`, and `...` at the closing position) and refuse any line whose *only* other content is invisible:

```
declared class      = /[ \t]+$/            the ONE class, trailing-only — today's accepted set, unchanged
invisible alphabet  = /[\s\p{Cf}\p{Cc}]/u  a Unicode general-category rule, NOT a list of bad code points
is-delimiter(line)  = line with the declared class removed is byte-equal to the payload
near-delimiter(line)= the line CONTAINS the payload, and every remaining code point is invisible
refuse iff            near-delimiter AND NOT is-delimiter
```

Measured for this amendment across the same 506 positions: **0 missed**, **2 accepted** (the trailing
space and trailing tab controls, unchanged), **504 refused**. And the mandatory false-red control —
the predicate run over all **33** files in the real repository's spawn-grant scan surfaces (17 agent
adapters + 7 standalone skills + 7 plugin skills + 2 packaging templates), both delimiter positions,
both payload tokens — returns **0 refusals**.

This is the same shape as D-30's escape allowlist that held: name what is legal, refuse the complement.
It is the opposite of D-34's enumerate-one-bad-prologue that did not.
