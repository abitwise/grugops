## The rules, each stated once

### WR-03 — a total accounting, not a test for the reported shape

```
for each value under a tools key:
  occurrences = every position where the spawn token appears on a word boundary
  each occurrence is exactly one of:
    SCOPED    the token is immediately followed by `(` and a matching `)` closes it in the same value
    UNSCOPED  the token is not followed by `(`                         (a real bare grant; unchanged)
    NEITHER   the token is followed by `(` that never closes           -> REFUSE, naming the fragment
  assert  |occurrences| == |scoped| + |unscoped| + |neither|
```

The identity is what makes this an accounting rather than three tests: a bucket that silently stops
matching produces an arithmetic failure, not a quiet reclassification. The buckets are stated
POSITIVELY and `NEITHER` is their complement — D-30's polarity, one predicate over.

### IN-01 — one invisible authority, consulted where the question is asked

```
prologue skip : a line is skippable when it renders NO VISIBLE GLYPH AT ALL

in-block blank: UNCHANGED — still `trim()`, because there the narrow alphabet routes an
                invisible-only line to the REFUSAL arm, which is the safe direction
```
