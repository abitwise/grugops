<objective>
Make the adapter-body guard assert what it claims to assert.

Two of its three parts are weaker than the phase believes. Its vacuity floor tests whether the whole
scan set came back empty, but the scan set always carries the packaging template, so the floor's
condition is unreachable and a tree with both adapter directories emptied yields a pass. Its positive
half is a bare substring test for a fragment of the memory sentence, order-independent and
context-free, so any occurrence anywhere satisfies it. That is not hypothetical here: on the live
tree the packaging template's two adapter body shapes are both inside fenced blocks and are stripped
before the check, so the only thing satisfying the template's positive half today is a documentation
bullet in the guard's own explanation section that merely describes the sentence. The guard is
currently green because a comment about the rule stands in for the rule.

The third part — the scan set's blind spot to a nested adapter — is closed by the adapter authority
landed in plan 27-10, and the truth restated here is the one re-verification must flip.

The template needs a different input, not a different predicate. Its body shapes are fenced on
purpose, because they are templates the generator copies; running the live-prose rule over it is what
let documentation satisfy it. So the template half reads the raw text and requires each emitted body
shape's full sentence exactly once, while the adapters keep the fence-stripped live-prose rule with
the same anchored sentence and the same exactly-once assertion.

The plan also closes the completeness claim on the committed literal inventory, which is a record in
this same file and is the last unrecorded finding from the review.

Purpose: replace three assertions that pass for the wrong reason with three that pass for the right one.
Output: an anchored, counted positive half; a floor that can fire; a template half checked against
what the generator copies; and an honest inventory.
</objective>
