## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| a source checkout's filesystem permissions → the installer's completion claim | A partial extract, a restrictive umask or a permissions-preserving archive is untrusted input that today makes the installer more confident, not less |
| the installer's exit status and banner → every downstream consumer | Chained commands, CI and the coordinator precheck all key on the status and the banner; a truncated report or a fabricated completion propagates from there |
| a report queued on an asynchronous stdout pipe → the reader | The machine-readable half survives an immediate exit while the human-readable half vanishes, silently and only when stdout is a pipe |
