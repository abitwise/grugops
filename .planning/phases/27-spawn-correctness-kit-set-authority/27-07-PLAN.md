<objective>
Generate the 17 role adapters and gate them, turning the referential-integrity oracle green and making
role agents actually resolvable on Claude Code for the first time.

This is the step the ROADMAP orders last, and the reason is now measurable: the sets became derived in
plans `27-01`, `27-03` and `27-04`, and the oracle has been failing red against the real tree since
plan `27-01`. The 17 adapters therefore land **inside** the guards rather than outside them, which is
the entire point of the ordering.

Per D-06 all 17 adapters are self-sufficient resolvers. This deliberately overrides the earlier
architecture note recommending plain copies: in an installed repository the kit directory does not
exist locally, a spawned subagent is a fresh context holding only its own adapter body, and the
substrate's rule for an unresolved kit is to stop rather than hunt. Making a spawned session's ability
to find the kit depend on text the spawner remembered to include is the relay pattern this milestone
deleted, and it would silently break direct invocation of a single role agent.

Per D-09 the arithmetic is fixed and has no exception list: 17 adapters, and a grant of 16 — the
adapters minus the coordinator itself. Per D-10 the enterprise-tier roles are in that grant, because
grant is capability and the configuration dial is policy; filtering at the capability layer would mean
a configuration change could never reach a role the runtime had already refused. Per D-12 descriptions
derive from sections that already exist in every role and are already written as routing triggers, so
there is zero new authoring.

Per SPAWN-04 no non-coordinator adapter carries a spawn-tool token at all. This is not a workaround —
it is the mechanism the platform documents for exactly this purpose, and unlike the parenthesised
allowlist it holds identically on the main-thread and subagent paths.

The freshness gate is the fifth instance of a pattern already working four times in the tree, with one
addition the existing instances do not need: they compare a single file, while this one must also
compare the two directory listings for set equality, or an orphaned adapter left by a deleted role
passes because nothing regenerates over it.

Purpose: sixteen of seventeen adapter files do not exist and all seven currently granted names resolve
to nothing, which is why no role agent has ever run.
Output: a generator, 17 committed adapters, a byte-and-set freshness gate, and a green oracle.
</objective>
