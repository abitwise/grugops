<objective>
Complete KIT-02 and D-16 by re-pointing the validator's two frozen name lists and the three
enumerating literals in the kit-reference checker, including the one the CONTEXT.md inventory
originally missed.

`scripts/validate-agent-factory.ts` froze a 14-name workflow list and a 16-name role list during an
earlier phase. Both are stale today — five workflows and one role are simply not validated, and
nothing reports that. This is the plainest instance in the tree of the failure class the milestone
exists to kill: a hand-maintained list of names that consumers read as truth, rotting while the suite
stays green.

`scripts/check-kit-refs.ts` carries three literals. `SCAN` names one adapter file where the directory
would do — and the walker already recurses directories, so the minimal correct change makes it
self-deriving with no import at all. `MARKER_SITES` is the literal the original inventory missed:
D-06 and D-08 put the compressed kit-vs-state invariant blockquote in every one of the 17 adapters, so
a four-entry hand-maintained list goes stale by fifteen the moment they land. D-27 puts it in scope
for this phase, in this wave, derived like the others and carrying the same per-consumer assertion
D-19 requires — because leaving it hand-maintained would ship a fresh instance of the exact defect
this phase exists to delete.

Assertion 3 gets the treatment D-07 specifies: restated as a derived predicate rather than a literal
widened from three named sites to nineteen. The restatement is strictly stronger than what is there
now, because the current exclusion-by-omission would silently permit a hand-written adapter to carry
the kit-root environment variable, while the derived predicate ties the legal set to the resolver-slot
marker the generator emits.

Purpose: the validator's frozen lists and the missed marker literal are the two places where this
phase would otherwise ship the very drift it is deleting.
Output: five derived iteration sites in the validator, three re-pointed literals in the kit-reference
checker, a corrected comment, and per-consumer assertions for each.

**Expected during this plan:** `node scripts/check-foundation-guards.js` exits non-zero with exactly
one FAIL — `guard_referential_integrity`, left deliberately red by plan `27-01`. `node
scripts/check-kit-refs.js` must exit 0 throughout.
</objective>
