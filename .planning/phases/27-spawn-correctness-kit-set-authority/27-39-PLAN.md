## The rule, stated once — the state belongs to the scalar, not to the line

```
entering state  = the quote state the PREVIOUS line of this key left open: '"' | "'" | null
scanner         = seeded with the entering state, returns the exiting state
while open      -> the line is CONTENT: no comment is stripped from it, its position 0 is not a
                   node start (the reference test does not run on it), and a leading `-` is not an
                   item boundary (the sequence-item rule does not run on it)
while closed    -> exactly today's behaviour, byte for byte
```

The carried state decides **three** things and nothing else: whether a `#` on this line can start a
comment, whether position 0 of this line is a YAML node start, and whether a leading `-` on this line
ends the previous item and begins a new one. It never decides what a value MEANS, and it adds no second
grammar — it removes a per-line guess that had no right to exist.

module previously had exactly one unit, the physical line; this plan makes the SCALAR a unit that spans
lines.

**The noun that is now primary:** the **scalar** — a value with a state that persists across the lines it
occupies — replacing the **physical line** as the unit the comment scanner and the node-start test reason
about.

**Decision: `promote`.** The scalar is promoted to primary and the line is demoted to a detail of how a

opinion" or "in case the carry misses something": two answers to "am I inside a scalar" is precisely the
shape that produced CR-01, one function away, in this same module.

**Rationale:** adding the carry alongside a per-line re-derivation would leave the two able to disagree,
and the disagreement is invisible to a reader checking either in isolation — the standing lesson of this
phase's fifth spelling.

plan closes. It is named here so a later round finds it recorded rather than "discovered", and so the
next reader does not add `\<LF>` to the allowlist without re-deriving D-30. It is **not** counted against
the repository-wide false-red budget, because no tracked markdown file uses the construct — asserted by
the same repository-wide control this plan already requires.
