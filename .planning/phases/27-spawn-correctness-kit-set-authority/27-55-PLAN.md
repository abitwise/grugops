<objective>
Close **CR-01-new**, the silent-no-grant path that round 10 shipped *inside its own fix*. D-57 moved
the flush's quoting exemption off the per-value `block` fact and onto a sticky per-key fact, so one
nested block scalar anywhere in a key now switches off the D-30 escape refusal for **every other
part of that key** — including ordinary double-quoted siblings that have nothing to do with the block
scalar. The module's founding failure — *"I could not read this"* printed as *"this carries no
grant"* — is reachable by adding two lines to a document.

Measured on the committed build this session, and the pair is the whole finding:

- control, no sibling — the module REFUSES, naming the `\x` sequence.
- add one unrelated `b: >-` sibling — the module returns `{"ok":true,"value":false}` while
  `/usr/bin/ruby -ryaml` loads `{"a"=>"Agent(grugops-orchestrator)","b"=>"x"}`.

Purpose: this is a **scope** bug, not a condition bug. A *key* property is standing in for a
*region* property, and the module's own asymmetry names the correct shape — the block-sequence item
path resolves each item at the point it is pushed and therefore still refuses, while only the nested
mapping continuation path defers its resolution to the flush. This plan deletes the key-wide fact and
makes resolution a property of the region that owns it, at the point of effect.

Output: a region-scoped resolution, the pair closed with its loader column, the three spellings of
one document agreeing, a gate-level plant flipping exit 0 to exit 1, a mutation control proving the
new pin can fail, and D-59 recorded.

Implements the round's structural mandate (delete the scope-widening flag rather than tune it),
D-30 (name what is legal and refuse the complement — an escape outside the allowlist is a refusal,
never a no-grant), D-09 / KIT-03 (a name is never silently dropped or altered when computing the
grant closure), D-40 (a plant lands on both distribution twins), and D-19 (recorded measurement over
grep-shaped heuristics).
