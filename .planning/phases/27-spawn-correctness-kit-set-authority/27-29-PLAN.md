## Decisions this plan implements

- **D-30** — CR-01 is fixed STRUCTURALLY by inverting `unquote()` to an escape ALLOWLIST, not by
  adding another refusal regex. Reversibility: **costly** — the checked-unquote contract propagates
  to three call sites and one guard call site; reverting means re-threading all four.
- **D-31** — round 4 closes all eight round-3 findings; this plan owns CR-01.
- **D-32 (NEW)** — the allowlist is enforced at EVERY point the unquote helper is called (the flush
  join, the block-sequence item, and the scoped-grant name split), and a refusal at any of them is a
  document-level parse artifact. `keysGrantedAgentNames` therefore returns the module's `Parsed`
  result type so the refusal has an honest destination, and the KIT-03 oracle call site in
  `check-foundation-guards.ts` branches on it explicitly, exactly as it already branches on
  `parseFrontmatter`'s failure arm. Rationale: a name enumeration that silently drops or silently
  alters a name is the same silent-success shape one level down. Reversibility: **costly**.
- **D-33 (NEW)** — the multi-line double-quoted scalar gets a DECIDED answer rather than staying
  unpinned (the round-3 reviewer's "same class, unpinned" note). Plain line folding keeps the
  existing space join, which reproduces YAML's folding for the ordinary case; a YAML backslash
  line-continuation survives the space join as a backslash-followed-by-space sequence, which is not
  on the allowlist and therefore refuses. The behavior is recorded in the module header as decided,
  and both halves carry a case. Reversibility: **reversible**.
