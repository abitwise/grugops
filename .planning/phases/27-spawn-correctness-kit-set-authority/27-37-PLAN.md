## The partition, stated once

```
schema        = the 9 plugin-root component surfaces CLAUDE.md's manifest section documents
covered       = { skills }        covered by listPluginSkillAdapters, folded into SPAWN_GRANT_SCAN
exempt        = { hooks }         named, reasoned, bounded by two live assertions
forbidden     = schema - covered - exempt     the remaining 7

assert |schema| == 9, two-sided
assert |forbidden| + |covered| + |exempt| == |schema|, and the three buckets are pairwise disjoint
```

A member added to the schema without landing in exactly one bucket fails red. That is what makes the
partition a derivation rather than a list with a comment.

## The `hooks/` exemption, and why it is an exemption rather than a fold

`hooks/` is bounded by two assertions rather than forbidden, because relocating a CLAUDE.md-mandated safety
surface to satisfy a guard rule is the guard bending the product. The bound:

1. Every frontmatter-bearing member of `hooks/` is inside `SPAWN_GRANT_SCAN`. Vacuous today — the
   directory holds **zero** markdown files — so the gate prints the measured zero rather than a coverage
   claim.
2. The directory carries **zero** markdown adapters. Live today, and this is the assertion that fails
   closed the moment a markdown adapter appears in it.

The exemption's shape is copied from `DISTRIBUTION_PAIR_EXEMPT` (`check-foundation-guards.ts:1381`), the one
legitimate divergence this repository already records by name with its reason.
