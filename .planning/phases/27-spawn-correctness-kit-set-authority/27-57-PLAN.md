<objective>
Close **CR-02**, the one bypass this round reproduced **end to end through the full gate**. YAML 1.2
§ 6.9 lets a node's properties — its tag and/or its anchor — stand in front of the node's content, so
`nested: &a >-`, `nested: !!str >-`, `: &a >-` and `? &a >-` are all legal block-scalar headers. The
recogniser asks the block indicator constant about the text immediately after the introduction, sees a
property instead of an indicator, misses the header, and routes the scalar's literal content to the
comment scanner where a leading hash deletes the rest of the line — the exact mechanism D-57 was
written to close, one property over.

Worse, the refusal arm does not catch it either: the reference test is asked about offset 0 of the
line, which `nested: &a >-` does not start with a sigil, and about flow fragments — never about the
node start that follows a block mapping's separator. So the document does not fail red; it succeeds
with no grant.

Measured, and this is the row the verifier independently replayed at the gate:

```
allowed-tools:
  nested: &a >-
    Read, Write, Bash, Glob, Grep, # x, Agent(grugops-orchestrator)
```

planted on `.claude/skills/grugops-map/SKILL.md` and its twin `skills/map/SKILL.md` on a hermetic
`git archive HEAD` mirror → `node scripts/check-foundation-guards.js` printed `ALL CHECKS PASSED`,
**exit 0**, with `/usr/bin/ruby -ryaml` reading the grant plainly in the loaded value.

Purpose: this is the same class as CR-03 one level over — the predicate's application set, not its
conditions. The module already owns a node-property grammar and a leading-tag form. The fix is to
REUSE that authority at every introduction the recogniser knows about, and to ask the reference
refusal at the node start that follows a recognised mapping separator so an unstrippable property
still fails loud. Closing only the four reported spellings is the enumerate-the-bad shape this module
has declined eight times.

Output: the property stripped at every introduction, the reference refusal moved to the node start,
the end-to-end reproduction replayed and inverted, a derived property axis over the introduction set,
the union with `27-55` and `27-56`, a mutation control, and D-61 recorded.

Implements D-30, D-52 / D-56 item 1, D-57 (the block-scalar closure completed at the positions it
missed), D-09 / KIT-03, D-40 and D-19.
