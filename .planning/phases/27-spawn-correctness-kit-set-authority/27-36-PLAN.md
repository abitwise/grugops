## The rule, stated once — total by construction

```
payload        = "---" at the opening position; "---" or "..." at the closing position
declared class = [ \t] — the ONE class, and the ONLY thing permitted after the payload
run            = the leading run of code points that render no glyph of their own
rest           = the line with that run removed

verdict:
  rest does NOT begin with any payload            -> not-a-delimiter   (keyless SUCCESS, untouched)
  run == 0 AND everything after the payload is
      in the declared class                       -> legal
  otherwise (rest begins with a payload, and the
      line is not exactly the legal spelling)     -> refuse, naming the offending code point
```

The invisible class appears **once**, and only to compute `run` — that is, only to decide **where the
delimiter begins**. It never decides what may follow the payload. That inversion is round 5's defect and it
is deleted rather than patched.
