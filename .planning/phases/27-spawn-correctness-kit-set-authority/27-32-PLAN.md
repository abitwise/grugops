<objective>
Close the three install-surface findings: **WR-02** (the corrected marker pair is still a
hand-maintained literal with no forcing function — CR-04's root cause, untouched), **WR-03** (the
recorded justification for the surviving duplicate walk is now false, in a file round 3 edited three
times), and **IN-03** (the reversal documentation still presents a dry-run preview that now exits 1
and prints nothing).

Purpose: WR-02 is CR-04 with a different filename waiting to happen. Round 3 corrected which file the
marker names; it did not add the thing whose absence let a marker naming a deleted file survive about
a hundred commits — **nothing asserts that the file the guard names exists in the real repository.**
All three shipped fixtures manufacture their own stub, so every assertion is about the predicate over
a fixture and all of them stay green if the real file moves. This repository's terminal lesson is
*derive the set, assert the count*; here the set is two hand-written strings duplicated across two
files with neither.

Output: one exported marker set with a real-repository existence assertion behind it, a rationale
comment that is true, the equality case both walk-site headers promise, and a reversal section that
matches the binary's behavior.

## Decisions this plan implements

- **D-31** — round 4 closes all eight round-3 findings; this plan owns WR-02, WR-03 and IN-03.
- **D-37 (NEW)** — the source-marker pair becomes ONE exported constant, `SOURCE_MARKERS`, plus a
  shared predicate `hasSourceMarkers`, in `install/kit-source.ts`; both binaries import it and
  neither keeps a literal. It names `install/install.js` and `agent-factory/VERSION` — the RUNTIME
  artifact rather than the TypeScript source, because the compiled artifact is the file whose presence
  wherever the uninstaller can run is already guaranteed, while the source file is present only
  because this repository happens to commit both. The forcing function is a case asserting every
  entry exists over the real repository root, importing the constant. Rationale: the pair as it stands
  is a hand-synced byte-identical literal in two files — the exact drift class D-28 deleted for the
  derivation helpers, sitting untouched twenty lines away. Reversibility: **reversible**.
- **D-38 (NEW)** — WR-03's comment is amended to D-28's layout-decoupling rationale, and the equality
  contract it appeals to becomes a CASE rather than a promise. Because D-36 makes the two walk sites
  answer a cycle differently by design, the equality is expressed in two parts: strict member equality
  over the non-cycle two-path fixture, and same-path-named refusal over the cycle fixture.
  Reversibility: **reversible**.
