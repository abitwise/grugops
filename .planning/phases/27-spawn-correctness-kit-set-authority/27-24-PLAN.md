<objective>
Close CR-01, the fail-open at the centre of this round. `scripts/frontmatter.ts` refuses a bare `&`
or `*` at a node start, but a YAML **tag** is a legal node property that may stand in front of an
anchor or a collection — and a tagged node walks straight past the refusal into the flattened-string
arm. Measured against the committed parser before any edit:

`hasSpawnGrant` over a document carrying a tagged anchor on `_t` and a tagged alias on
`allowed-tools` returns `{"ok":true,"value":false}`, and `grantedAgentNames` returns
`{"ok":true,"value":[]}` — the module header's own named failure ("reading `*t` as the plain
two-character string `*t` is the silent no-grant arm") reached by adding two characters. The same
document with a bare sigil is correctly refused. Planted on a skill adapter, the whole gate printed
`ALL CHECKS PASSED`, exit 0.

This is shared machinery. `guard_wr05` (SPAWN-04) and the KIT-03 oracle's grant-closure read both
resolve through `startsWithReference()`, so one honest fix closes both halves of the gap. It is also
the same fail-open this milestone already closed once, returning in a new spelling — so the remedy is
not a special case for the reported serializer but the tag axis enumerated at every application point
the refusal applies at, with the pins raised to hold it.

This is the phase tracer for round 3: one defect closed completely — source fixed, committed `.js`
rebuilt, freshness green, adversarial axis enumerated, and the aggregator proven red end-to-end on
the unguarded surface — establishing the RED-before / GREEN-after proof pattern the four expansion
plans follow.

Purpose: one honest reading of "is this node a reference", at the node's real start.
Output: a parser that refuses a tagged reference, a rebuilt committed `.js`, an enumerated tag axis
with raised pins, and an aggregator case that would go green again if the refusal regressed.
</objective>
