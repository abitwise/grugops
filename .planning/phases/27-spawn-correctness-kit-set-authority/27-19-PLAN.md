<objective>
Close CR-02: the KIT-03 referential-integrity oracle builds set 2 from FILENAMES and set 3 from the
coordinator's frontmatter GRANT — two namespaces, never asserted equal. Claude Code takes agent
identity only from frontmatter, and this file says so itself twice. The review renamed one adapter's
`name:` value on a hermetic mirror and the oracle printed `17 roles == 17 adapters == 17 grant-closure
names` over a tree whose coordinator grants a name no installed agent carries — the milestone's
founding defect, reproduced with its own oracle green.

Two answers to one predicate is this project's first named systemic failure class, and here the
WEAKER answer is the one wired into CI: `coordinator-resolution-precheck.ts` resolves the closure by
frontmatter name and correctly fails on the same mirror, but it is a human-invoked precheck. This
plan names the authority (D-09's set equality is over agent NAMES) and makes the filename comparison
legal by asserting the mapping it silently assumed.

Purpose: the equality D-09 claims must hold over the members the platform actually loads.
Output: the mapping assertion, a rebuilt committed `.js`, and fixtures that can express the mismatch.
</objective>
