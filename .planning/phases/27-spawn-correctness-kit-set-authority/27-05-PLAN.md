<objective>
Bring `agent-factory/roles/orchestrator.md` back under its warn tier and correct every surface that
advertises a superseded Claude Code nesting depth or a withdrawn platform claim about concurrency.

This is the ordering step the ROADMAP makes load-bearing: the trim lands **before** any spawn text is
touched. The file sits at 7562 bytes against a 7570-byte fail tier and a 7165-byte warn tier, so the
two-tier guard has effectively collapsed to a single fail tier with eight bytes of room — and a warn
does not fail the build, which is exactly why it sat there unnoticed.

The trim budget is larger than it first looks, and sizing it wrong is the most likely way this plan
fails. Two other corrections land in the same file and both are net-positive in bytes: replacing the
depth claim with one that names the tuning environment variable is longer than what it replaces, and
correcting the false claim about width adds more. Plan `27-06` then adds a frontmatter key to this
same file. So the acceptance measurement is taken **after** the corrections, not after the trim, and
this plan targets 7100 bytes rather than 7165 to leave that later key its room.

The relocation trap is recorded and closed rather than used. The role-switch protocol file is not in
the guarded role set and has no byte ceiling, so moving text there would shrink this file by putting
bytes where nothing measures them — constraint-gaming of exactly the shape this milestone exists to
fix. Bytes come from tightening prose in place.

On the spawn sentence: the instruction already exists in Responsibility 4 and is currently keyed on
the host CLI's name. Under D-04 it becomes keyed on whether the spawn tool is available, which is the
same signal on all five hosts and satisfies the milestone decision that no runtime version-detection
code is required. The full three-tier announcement vocabulary does **not** go in this file — it belongs
to the coordinator adapter body and is authored into the packaging template in plan `27-06`, where the
guard in plan `27-08` asserts it. Duplicating it here would spend bytes in the one file that cannot
afford them.

Purpose: a byte ceiling eight bytes from failing is not a working control, and four documents currently
advertise a platform contract that changed three times in twenty patch releases.
Output: a trimmed role file, a capability-keyed spawn instruction, and corrected depth and width facts
across the surfaces that carry them.
</objective>
