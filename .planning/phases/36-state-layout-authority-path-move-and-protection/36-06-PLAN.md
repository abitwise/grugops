<objective>
Move grugops's own state to memory-bank/plans/ and flip every tooling reader of that state to the authority in one green
commit (D-12, D-13 step 2 readers half; LAYOUT-02, LAYOUT-05).

The repository move is coupled to its readers: the validator's CI self-check, the board tracer and the corpus test read
the repository's own board, and the validator and board tests read the fixture trees. The fixture trees cannot move in a
separate green commit: scripts/validate.test.ts runs the validator directly on each fixture tree, and the board tests
read board-snapshot through FIXED_SUBPATHS, so the fixture moves, the repository move and the reader flip are one
connected change. So this plan is one atomic flip: the `git mv` of the repository state (D-12, by hand, Phase 38's
migrate not used) and of every fixture tree's state directory (D-08), the reader table, the model's message prefix, the
validator, the corpus and the check-banned-claims root entry, which would otherwise name a directory that no longer
exists. Plans 36-04 and 36-05 already made the board tests follow the table, so they stay green across the flip.

This plan holds only the flip, so the executor starts it with a full context (scope revision, 2026-10-21). The trace
tools, the remaining prose and the re-sealed fixture notes follow in plan 36-07: none of them is read by a test or gate
that the flip turns red (the trace tools' tests use scratch roots, and the golden is regenerated here).

Purpose: the repository dogfoods the v3 layout and its validator and gates pass on it (LAYOUT-05).
Output: moved repository and fixture state, readers on the authority, golden regenerated.
</objective>
