half of LAYOUT-02).

plant and expect hand-spelled pre-v3 paths (about 300 sites across seven files), and the board tracer reads the
repository's own board. If plan 36-04 flipped the table and moved the repository with those tests unconverted, it would

values, so every test stays green here and stays green when the values change. It also converts the path-agnostic
example strings in five other test files to the new spelling. No production behavior changes in this plan.
