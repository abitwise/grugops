(D-13 step 2, expand half of LAYOUT-02).

repository's own board. If plan 36-06 flipped the table and moved the repository with those tests unconverted, it would

still holds its pre-v3 values, so every test stays green here and stays green when the values change; plan 36-05
converts the dashboard and model tests and the path-agnostic examples. The conversion is split across two plans to keep
each within one executor's context budget (scope revision, 2026-10-21). No production behavior changes in this plan.
