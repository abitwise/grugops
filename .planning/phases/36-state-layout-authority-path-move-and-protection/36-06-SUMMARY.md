## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The board-corpus no-op mirror could not load board-model.js**
- **Found during:** Task 1
- **Issue:** `mirrorWithNoOpStripper` copies board-model.js alone into a temp dir. Its new `../install/state-layout.js` import then failed with ERR_MODULE_NOT_FOUND, and four corpus control cases failed.
- **Fix:** The mirror now keeps the repository layout: `<tmp>/scripts/board-model.js` beside a copy of `<tmp>/install/state-layout.js`. This is the pattern plan 36-02 recorded.
- **Files modified:** scripts/board-corpus.test.ts
- **Committed in:** 78ef0688

**2. [Rule 3 - Blocking] The presence-sentence derivation and the contract table**
- **Found during:** Task 1
- **Issue:** board-model.test.ts derives the presence templates from `presenceActual`'s source and turns every `${...}` into a hole. `${TICKETS_REL}` therefore became a hole, while the measured sentence carried the path. Three cases failed: derived vs named inputs, contract row count, and contract set equality. The contract's presence table in agent-factory/contracts/board.md still spelled `plans/tickets/`.
- **Fix:** The derivation has a `LAYOUT_CONSTANTS` map holding `{ TICKETS_REL }`, which writes the constant's value for that one identifier. Every other substitution is still a hole. The three sentence rows in the presence table, and one line of prose in the same section that describes `stem`, now spell `memory-bank/plans/tickets/`. The rest of the contract is plan 36-08's.
- **Files modified:** scripts/board-model.test.ts, agent-factory/contracts/board.md
- **Committed in:** 78ef0688

**3. [Rule 3 - Blocking] The published-substitution census pin**
- **Found during:** Task 1
- **Issue:** `PUBLISHED_SUBSTITUTION_COUNT` counts substitutions at positions a human reads as a finding. The five new `${TICKETS_REL}` substitutions moved the measured count from 86 to 91. That failed the pin and the three 32.1-13 mutation controls that compare against it. The ownership equality itself passed: every new substitution is built through `spelled`.
- **Fix:** The pin is now 91, with a dated comment saying which sentences landed and why. Its own comment calls this a decision, and it is the one the plan specifies.
- **Files modified:** scripts/board-model.test.ts
- **Committed in:** 78ef0688
