# 999.1 — Installer adversarial e2e lane (idea)

Captured 2026-10-04 during phase 33.1 gap round 3, by human decision: the per-plan red-team is
stopped for 33.1 and parked here as a future improvement to the end-to-end testing flow.

## What the red-team was

An orchestrator-run step, not a repo or GSD gate. After each 33.1 gap plan landed, a read-only
agent:

- drove the committed `install/install.js` and `install/uninstall.js` with `node` in scratch git
  repos and scratch `HOME` / `GRUGOPS_HOME` dirs;
- tried to make them lose or overwrite user data (defect class DC-2), or to ask a predicate in one
  arm but not its sibling;
- reported only breaks it reproduced, each with a repro script, the defect class and the smallest
  fix.

## Why it stalled delivery

- **No bound on the input space.** It covered path spellings, symlinks, macOS firmlinks, bind
  mounts, Windows drive forms, and forged ledger or kit-home records. Every fix added code that the
  next round then attacked.
- **No likelihood bar.** Every reproduced case was treated as in scope.
- **Every finding became work.**
  - The plan 36 red-team found 1 break, which became plan 37 Task 4 (about 2h).
  - The plan 37 red-team found 3 more.
  - Phases 30–32 followed the same pattern.
- **Not flaky.** Its repros were deterministic. What was missing was scope, a fixed corpus and
  triage, not stability.

## Shape of the future lane (to refine in discuss-phase)

1. **Fixed scenario corpus.** Enumerate scenarios as data:
   - install / re-install / `--update` / uninstall sequences;
   - hand copies and hand links;
   - swapped directories;
   - kit home overlapping the target;
   - malformed and forged records;
   - DRY_RUN vs real.

   Every scenario is a vitest e2e case that runs the committed `.js`.
2. **Severity × likelihood triage.** Agree the bar before a finding can block a plan. For example,
   data loss on a common path blocks; exotic spellings (`/System/Volumes/Data/...`, `subst`,
   junctions) are logged as known issues.
3. **Periodic, not per plan.** Run adversarial exploration once per phase or milestone, time-boxed.
   Its new repros go into the corpus as candidate rows. A human triages them, and they never
   become in-scope work on their own.
4. **Reuse the existing work.**
   - `.planning/phases/33.1-phase-33-leftovers-guard-bypasses-first/33.1-round3-replay.mjs`
     (10 replay cases);
   - the plan 37 red-team scripts `p1`..`p10` (in the session scratchpad; copy them in before they
     are lost).

  compare dev+inode ancestor chains instead of path strings.

  backup. Accepted by the human under D-31 item 14 (2026-10-04).

  removes the file install put there. The human chose "gate the unlink on the ledger carry"
  (2026-10-04). Where it lands (plan 38 or later) is pending.
